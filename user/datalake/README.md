# 화면 구성과 데이터 찾기

> AX-DataLake 에 모인 업무 데이터를 찾고, 테이블의 설명·열·미리 보기·시점 이력을 봅니다. 운영 매뉴얼 같은 문서 조각도 찾습니다. **대상**: 분석가, 데이터 엔지니어. **메뉴**: 한눈에 보기 · 데이터 › 카탈로그 · 데이터 › 문서 찾기(엔지니어·관리자에게는 문서 수집).

AX-DataLake 는 웹 화면입니다. 관리자가 알려 준 주소(예 `http://<서버>:8790`)로 들어가 관리자가 만들어 준 계정으로 로그인합니다.

## 화면 구성

<figure><img src="img/datalake/u-home.png" alt="AX-DataLake 분석가 한눈에 보기 — 왼쪽 메뉴(한눈에 보기, 분석 묶음, 데이터 묶음과 문서 찾기, 관리 › 내 API 키), 위 머리띠의 이름·소속·역할, '데이터에 무엇이든 물어보세요' 질문 칸과 확인된 질문 '시스템별 장애 건수', 내 대시보드 2개, 최근 분석(저장된 분석이 없습니다), 아래 볼 수 있는 테이블 12개 안내"><figcaption>분석가로 로그인한 한눈에 보기. 역할에 따라 왼쪽 메뉴와 첫 화면이 달라집니다.</figcaption></figure>

| 영역 | 하는 일 |
|---|---|
| 왼쪽 메뉴 | **한눈에 보기**, **분석**(AI 분석 · 대시보드 · 저장된 분석 · 객체 분석), **데이터**(카탈로그 · 객체 탐색 · 계보 · SQL 작업창 · 문서 찾기), **관리**(내 API 키) |
| 위 머리띠 | 지금 화면 제목, 내 이름, 소속(예 `HD01`), 역할(**분석가** · **데이터 엔지니어** · **관리자**), **테마**, **비밀번호 바꾸기**, **로그아웃** |

역할마다 보이는 메뉴가 다릅니다.

| 메뉴 | 분석가 | 데이터 엔지니어 | 관리자 |
|---|---|---|---|
| 한눈에 보기 · 분석(AI 분석 · 대시보드 · 저장된 분석 · 객체 분석) · 카탈로그 · 객체 탐색 · 계보 · SQL 작업창 · 문서 찾기(엔지니어·관리자에게는 **문서 수집**) · 내 API 키 | ○ | ○ | ○ |
| 지표·차원 · 수집(파일 수집 · 원본 연결 · 실시간 수집 · 문서 → 표(AI)) · 거버넌스 | — | ○ | ○ |
| 사용자 · 감사 기록 · AI 모델 | — | — | ○ |

> **참고** 분석가는 관리자가 **조회 권한**을 준 테이블만 봅니다. 개인정보 열은 가려져 보이고(예 `010-****-5678`), 행 제한이 걸린 테이블은 내 소속의 행만 보입니다. 이 규칙은 화면·SQL·API·AI 질문·에이전트 어디서 읽어도 똑같습니다. 관리자 쪽 설정은 [거버넌스](/admin/datalake/governance.md)에 있습니다.

## 한눈에 보기

분석가의 한눈에 보기는 묻고 다시 여는 곳입니다.

| 카드 | 내용 |
|---|---|
| **데이터에 무엇이든 물어보세요** | 질문을 쓰고 **질문하기**를 누르면 AI 분석으로 갑니다. 아래 `확인된 질문 — 바로 답합니다:` 꼬리표를 누르면 그 질문을 바로 묻습니다 |
| **내 대시보드** | 내가 만들었거나 나에게 공유된 대시보드. **모두 보기**로 대시보드 목록을 엽니다 |
| **최근 분석** | 내가 저장했거나 공유받은 분석. 없으면 `저장된 분석이 없습니다` 와 **AI 분석으로 묻기** 버튼이 보입니다 |
| 아래 안내 줄 | 볼 수 있는 테이블 수와 카탈로그·SQL 작업창으로 가는 링크 |

엔지니어·관리자의 한눈에 보기에는 **볼 수 있는 테이블**(테이블 수 / 스키마 수), **최근 시점(스냅샷)**, **저장 용량**, **실시간 수집**, **내 최근 조회**(직접 쓴 SQL 과 성공·거부·오류 — 누르면 SQL 작업창에 들어감), **테이블 등급**(공개 · 내부 · 대외비 · 기밀)과 **최근 파일 수집** 카드가 나옵니다([AX-DataLake 관리 개요](/admin/datalake/README.md)).

## 카탈로그 — 테이블 찾기

<figure><img src="img/datalake/u-catalog.png" alt="카탈로그 — 왼쪽 hr·ito·ops 스키마 트리에서 hr.staff 를 고른 모습, 오른쪽에 대외비 등급·태그, SQL 로 열기·차트로 보기·계보 보기 버튼, 행·파일·담당, 행 제한 안내, 열 탭에 name·rrn·phone 열의 '부분 가림(나에게 가려짐)' 표시"><figcaption>분석가가 본 <code>hr.staff</code>. 개인정보 열에 '나에게 가려짐'이, 위에 행 제한 안내가 보입니다.</figcaption></figure>

| 영역 | 하는 일 |
|---|---|
| **테이블** 칸 | 스키마별 트리. 뷰는 `뷰` 꼬리표가 붙습니다 |
| `이름·설명·태그로 찾기` | 입력하면 트리를 바로 거릅니다 |
| 테이블 머리 | `스키마.테이블`, 등급, 태그, 설명 |
| **SQL 로 열기** | `SELECT * … LIMIT 100` 을 SQL 작업창에 넣고 실행합니다 |
| **차트로 보기** | `SELECT * FROM 스키마.테이블` 을 SQL 작업창의 **차트** 탭으로 엽니다 |
| **계보 보기** | 이 테이블을 고른 상태로 계보 화면을 엽니다 |
| 요약 표 | **행**, **파일**(소량이면 '소량이라 카탈로그 안에 보관'), **담당**, **설명 고친 때** |
| 탭 | **열** · **미리 보기** · **시점 이력** · **바뀐 행** |

엔지니어·관리자에게는 **설명 고치기**, **AI 설명 초안** 버튼이 더 보입니다([AX-DataLake 관리 개요](/admin/datalake/README.md)).

### 테이블 찾고 보기

1. 왼쪽 메뉴 **카탈로그**를 누릅니다.
2. 찾기 칸에 이름·설명·태그의 일부(예 `장애`, `개인정보`)를 넣습니다.
3. 트리에서 테이블을 누릅니다. 오른쪽에 상세가 열립니다.
4. **열** 탭에서 열 이름, 타입, 설명, **보호**를 봅니다.

| 보호 칸 | 뜻 |
|---|---|
| `부분 가림` · `전체 가림` · `해시` · `비움` | 그 열에 걸린 가림 방식 |
| `…(나에게 가려짐)` | 내 역할에서는 가린 값으로 보입니다 |
| 비어 있음 | 가림 없음 |

### 미리 보기와 시점 조회

1. **미리 보기** 탭을 누릅니다. 최신 상태의 앞부분이 나옵니다. 가려진 열은 가린 값으로 보입니다.
2. 과거 모습을 보려면 위 선택 칸(`지금 모습`)에서 시점(`#번호 · 시각`)을 고릅니다. `시점 #12 의 모습(시점 조회)` 으로 바뀝니다.
3. 선택 칸의 X 를 누르면 다시 최신 상태입니다.

<figure><img src="img/datalake/u-catalog-preview.png" alt="hr.staff 미리 보기 탭 — 이름 홍*동, 주민등록번호 900101-1******, 전화 010-****-5678 처럼 가려진 값과 HD01 행만 보이는 표"><figcaption>미리 보기. 분석가에게는 가린 값과 내 소속 행만 보입니다.</figcaption></figure>

### 시점 이력과 바뀐 행

레이크 테이블은 바뀔 때마다 **시점(스냅샷)** 이 남아, 언제 무엇이 바뀌었는지 되짚을 수 있습니다.

1. **시점 이력** 탭에서 **시점 번호**, **시각**, **변경**(테이블 생성 · 행 추가 · 행 삭제 · 구조 변경 · 파일 정리 등)을 봅니다.
2. 줄 끝의 **이 시점 보기**를 누르면 미리 보기 탭이 그 시점으로 열립니다.
3. 두 시점 사이에 바뀐 행을 보려면 **바뀐 행** 탭에서 `시점 [ ] 부터 [ ] 까지` 에 번호를 넣고 **보기**를 누릅니다.

| 바뀐 행의 구분 | 뜻 |
|---|---|
| `insert` | 추가된 행 |
| `update_preimage` / `update_postimage` | 수정 전 / 수정 후 |
| `delete` | 삭제된 행 |

<figure><img src="img/datalake/u-catalog-history.png" alt="ito.incident 시점 이력 탭 — 시점 번호 12, 시각, 변경 '테이블 생성, 행 추가', 이 시점 보기 버튼"><figcaption>시점 이력. 이 시점 보기로 그때의 모습을 엽니다.</figcaption></figure>

> **주의** 보관 기간(기본 30일)이 지난 시점은 매일 파일 정리 때 지워져 시점 조회가 되지 않습니다.

## 문서 찾기 — 문서 조각 찾기

운영 매뉴얼·절차서·장애 보고서 같은 문서도 레이크에 조각(테이블)으로 들어 있습니다. 개인정보는 레이크에 쓰기 **전에** 가려져 있습니다. 메뉴 이름은 분석가에게 **문서 찾기**, 엔지니어·관리자에게 **문서 수집**이며 같은 화면입니다.

<figure><img src="img/datalake/u-documents.png" alt="문서 수집 화면(데이터 엔지니어) — 위에 문서 묶음 표(E2E 운영·영업 문서, 운영 매뉴얼, 운영·영업 문서)와 오른쪽 끝에 고정된 실행·파일 올리기 버튼과 ⋯, 아래 문서 찾기에서 운영 매뉴얼을 '계정 잠금 해제'로 찾은 조각 2건과 제목 경로"><figcaption>문서 찾기. 결과마다 문서 제목 > 제목 경로와 파일 이름·조각 번호가 근거로 붙습니다.</figcaption></figure>

1. 왼쪽 메뉴 **문서 찾기**(엔지니어·관리자는 **문서 수집**)를 누릅니다. 위 표에 내가 볼 수 있는 **문서 묶음**이 나옵니다.
2. 아래 **문서 찾기**에서 **문서 묶음**을 고릅니다.
3. 찾을 말(예 `사원 조회에 퇴사자가 같이 나와요`)을 넣고 **찾기** 또는 `Enter`.
4. 결과에서 `[1] 문서 제목 > 제목 경로`, 파일 경로·조각 번호(`#5`), 본문 앞부분을 봅니다. 오른쪽 꼬리표 **낱말** / **의미**는 어떤 검색으로 찾았는지입니다.

> **참고** 문서 묶음이 보이지 않으면 그 조각 테이블의 조회 권한이 없는 것입니다. 관리자에게 요청합니다. 조각 테이블은 보통 레이크 테이블이라 SQL 로도 봅니다: `SELECT title, heading, text FROM docs.ops_manual WHERE text ILIKE '%급여 배치%'`.

## 내 API 키

BI 도구·스크립트·AI 에이전트를 레이크에 붙일 때 씁니다. 키는 **내 권한**(역할·소속·가림 규칙) 그대로 움직입니다. 만드는 법은 [AX-DataLake 관리 개요](/admin/datalake/README.md)에 있습니다.

## 자주 묻는 질문

| 질문 | 답 |
|---|---|
| 테이블이 하나도 안 보여요 | 분석가는 권한을 받은 테이블만 봅니다. 관리자에게 조회 권한을 요청합니다 |
| 행이 너무 적게 보여요 | 행 제한이 걸린 테이블입니다(상세 위 안내). 내 소속의 행만 보입니다 |
| 가린 값의 원문이 필요해요 | 원문을 보는 역할은 관리자가 정합니다. 업무상 필요하면 관리자에게 요청합니다 |
| 화면이 이상하게 멈췄어요 | 새 판이 올라간 직후일 수 있습니다. 새로 고침(`F5`)합니다 |
