# 로그인과 화면 공통 사용법

> 세 웹 제품(AX Platform · PMS-X · AX-DataLake)에 로그인하고, 비밀번호를 바꾸고, 화면 위쪽의 공통 기능(검색·알림·테마)을 쓰는 법입니다. **대상**: 모든 사용자.

## 로그인

제품마다 계정이 따로 있습니다. 관리자가 알려 준 주소를 브라우저(Edge·Chrome 최신판)로 열고 아이디·비밀번호를 넣은 뒤 **로그인**을 누르세요.

<figure><img src="img/common/login-platform.png" alt="AX Platform 로그인 화면 — 왼쪽 제품 소개(LLM 게이트웨이·MCP 허브·사용량·비용·현업 창구), 오른쪽에 로그인 ID·비밀번호 칸과 로그인 버튼"><figcaption>AX Platform 로그인 화면. PMS-X·AX-DataLake 도 아이디·비밀번호를 넣는 같은 방식입니다.</figcaption></figure>

| 제품 | 로그인 칸 | 사내 계정(AD·SSO) |
|---|---|---|
| AX Platform | **로그인 ID** · **비밀번호** | 회사가 켜 두었으면 사내 AD 비밀번호로 그대로 로그인되고, SSO 를 쓰면 로그인 칸 아래에 **사내 SSO 로그인** 같은 버튼이 보입니다. 처음 로그인하면 계정이 저절로 만들어집니다 |
| PMS-X | **아이디** · **비밀번호** | AD 비밀번호를 쓰는 회사도 있지만 계정은 관리자가 먼저 등록해 둬야 합니다 |
| AX-DataLake | 아이디 · 비밀번호 | 로컬 계정만 씁니다 |

<figure><img src="img/common/login-pmsx.png" alt="PMS-X 로그인 화면 — 아이디·비밀번호 칸"><figcaption>PMS-X 로그인 화면.</figcaption></figure>

### 로그인이 안 될 때

| 화면에 보이는 글 | 할 일 |
|---|---|
| 아이디 또는 비밀번호가 올바르지 않습니다 | 대소문자·한/영 전환을 확인하고 다시 넣습니다 |
| 계정이 잠겼습니다 | 비밀번호를 5번 틀리면 잠깁니다. AX Platform 은 15분 뒤 저절로 풀리고, PMS-X 는 관리자에게 잠금 해제를 요청합니다 |
| 라이선스가 유효하지 않습니다(PMS-X) | 관리자에게 알립니다 — 시스템 관리자만 로그인할 수 있는 상태입니다 |
| 화면이 열리지 않음 | 사내망(VPN)에 붙어 있는지, 주소·포트가 맞는지 확인하고 관리자에게 알립니다 |

## 처음 로그인하면 비밀번호부터 바꾸세요

관리자가 준 처음 비밀번호는 바로 바꿉니다. 바꾸면 다른 PC·브라우저에 로그인해 둔 것은 끊어집니다.

| 제품 | 어디서 |
|---|---|
| AX Platform | 오른쪽 위 **비밀번호 바꾸기** (좁은 화면에서는 **⋯** 안) |
| PMS-X | 오른쪽 위 내 이름 › **비밀번호 변경** |
| AX-DataLake | 오른쪽 위 **비밀번호 바꾸기** |

<figure><img src="img/common/platform-password.png" alt="AX Platform 비밀번호 바꾸기 창 — 지금 비밀번호·새 비밀번호·새 비밀번호 확인 칸, 닫기·바꾸기 버튼"><figcaption>AX Platform 의 비밀번호 바꾸기 창.</figcaption></figure>

1. **지금 비밀번호**를 넣습니다.
2. 새 비밀번호를 두 번 넣습니다. AX Platform 은 **8자 이상, 영문·숫자·특수문자 중 2종 이상**이어야 합니다.
3. **바꾸기**를 누르면 끝입니다.

> **참고** 사내 AD·SSO 로 로그인하는 계정은 이 화면에서 바꾸지 않습니다. 회사 계정 비밀번호를 바꾸는 방법을 따르세요.

## 공통 기능

### 검색 (Ctrl+K)

AX Platform 과 PMS-X 는 어느 화면에서든 **Ctrl+K**(Mac 은 ⌘K)로 검색 창을 엽니다.

- AX Platform: 화면·탭 이름과 내 대화·에이전트·문서·MCP 도구를 찾습니다. ↑↓ 로 고르고 Enter 로 이동, Esc 로 닫습니다. 예전 메뉴 이름(관측, Insight 등)으로 찾아도 지금 화면으로 데려갑니다.
- PMS-X: 요구사항·WBS·이슈·결함·변경 요청·테스트·산출물·회의록·서비스 요청·지식 문서·화면·테이블·컬럼·DB 오브젝트를 찾습니다.

### 알림

머리띠의 종 모양을 누르면 사람 손이 필요한 일(승인 요청·연결 문제·창구 접수)과 내 요청의 결과가 나옵니다. 숫자는 아직 안 읽은 건수입니다. 항목을 누르면 그 화면으로 갑니다.

### 테마

**테마**에서 화면 색을 고릅니다(어두운 화면 포함). 내 브라우저에만 저장되고 다른 사람에게는 영향이 없습니다.

### 좁은 화면·휴대폰

AX Platform 을 폭이 좁은 화면(태블릿 세로·휴대폰)에서 열면 왼쪽 메뉴가 숨고 왼쪽 위 **☰** 를 눌러 엽니다. 테마·비밀번호·로그아웃은 오른쪽 위 **⋯** 안에 있습니다. 현업 창구 화면은 휴대폰에 맞춰져 있습니다.

### 로그아웃

공용 PC 에서는 다 쓴 뒤 꼭 **로그아웃**하세요. 로그인은 일정 시간 쓰지 않으면 다시 하도록 바뀝니다.
