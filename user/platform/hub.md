# MCP 허브 — 내 도구 쓰기

> 에이전트·채팅·IDE 가 쓰는 업무 도구(PMS-X 업무 지식, AX-NAVI 코드 색인, 데이터레이크, 문서 검색, 고객 ITSM, 런북 등)를 한 주소로 모은 곳입니다. 사용자는 내가 쓸 수 있는 도구를 확인하고, **시험**으로 직접 불러 보고, 내 **호출 기록**을 봅니다. **대상**: 모든 사용자. **메뉴**: 왼쪽 메뉴 › AI 통제 › MCP 허브(탭: **개요 · 연결 · 내 도구 · 호출 기록**).

MCP(Model Context Protocol)는 AI 가 외부 도구를 부르는 표준 방식입니다. 허브는 누가 어떤 도구를 쓸 수 있는지 정책으로 거르고, 위험한 도구는 사람 승인을 받게 하고, 모든 호출을 기록합니다.

> **참고** 관리자·감사자에게는 **서버 · 도구 승인 · 정책** 탭이 더 보입니다. [MCP 허브 · 정책 · 승인](/admin/platform/hub.md) 참고. 승인 요청은 왼쪽 메뉴 **승인함**에 모입니다.

## 연결 · 내 도구 탭

<figure><img src="img/platform/u-hub-connect.png" alt="연결 · 내 도구 탭 — 접힌 '연결하기' 칸, 아래 서버별 도구 카드(PMS-X 업무 지식 · 18개), 도구마다 제목·이름(pmsx__crud 등)·조회/쓰기 꼬리표·설명·입력값 꼬리표(필수는 *)·시험 단추"><figcaption>내가 쓸 수 있는 도구 목록. 도구마다 시험 단추가 있습니다.</figcaption></figure>

| 영역 | 하는 일 |
|---|---|
| **연결하기** (접힌 칸) | Claude Code·AX-NAVI·사내 에이전트에 허브를 등록하는 설정 예시 |
| 서버별 카드 | 서버 이름 · 도구 수 · 서버 설명 |
| 도구 줄 | **도구 제목**, 도구 이름(`서버__도구`), **조회**(읽기만) / **쓰기**(데이터를 바꿈), 설명, **입력값**(파란색 `*` 는 꼭 넣어야 하는 값), **시험** 단추 |

쓸 수 있는 도구가 없으면 *쓸 수 있는 도구가 없습니다 — 관리자에게 정책을 확인해 달라고 하세요.*가 나옵니다.

### 도구 시험하기

<figure><img src="img/platform/u-hub-trial.png" alt="시험 호출 창 — 제목 '시험 호출 — 화면 × 테이블 CRUD 표', 도구 이름과 설명, 입력값 JSON 입력칸({ &quot;screenId&quot;: &quot;&quot; }), 실행 단추"><figcaption>시험 호출 창. 필수 입력값 칸이 미리 채워져 있습니다.</figcaption></figure>

1. 도구 줄의 **시험**을 누릅니다.
2. 입력값을 JSON 으로 채웁니다. 예: `{"screenId": "HR0101"}`. 무엇을 넣을지 모르면 같은 서버의 목록 도구(예: **프로젝트 목록**)부터 시험해 ID 를 얻으세요.
3. **실행**을 누릅니다.
4. 아래에 결과가 나옵니다. 실패하면 빨간 글로 나옵니다.

> **주의** 시험은 *진짜 호출*입니다. **쓰기** 도구(예: **지식 문서 등록**)는 실제 데이터를 바꿉니다. 승인 정책이 걸린 도구는 승인 요청이 만들어지고, 관리자가 승인한 뒤 같은 입력값으로 다시 **실행**해야 실행됩니다. 입력값이 JSON 이 아니면 *입력값이 올바른 JSON 이 아닙니다.*가 뜹니다.

### 내 도구를 Claude Code 에 등록하기

AX-NAVI IDE 를 쓰면 로그인할 때 자동으로 등록되므로 이 과정이 필요 없습니다. IDE 없이 Claude Code 만 쓸 때:

1. [LLM 게이트웨이 › 내 키](/user/platform/gateway.md)에서 **MCP 허브 도구(mcp)** 권한으로 키를 발급합니다.
2. **연결하기** 칸을 펼쳐 예시를 봅니다.
3. 프로젝트 폴더에서 한 번 등록합니다.

```bash
claude mcp add --transport http hnix-ax <플랫폼 주소>/mcp --header "Authorization: Bearer <mcp 권한 hx- 키>"
```

팀이 함께 쓰는 설정이면 `.mcp.json` 에 같은 주소를 넣고, 키는 환경 변수(`HNIX_AX_KEY`)로 둡니다(예시가 칸 안에 있습니다).

> **참고** 등록하면 Claude Code 에서도 이 목록의 도구를 그대로 쓰고, 모든 호출이 정책 검사를 거쳐 호출 기록에 남습니다.

## 호출 기록 탭

<figure><img src="img/platform/u-hub-calls.png" alt="호출 기록 탭 — 새로 고침 단추, 표에 시각·사용자·호출한 곳(자동 실행 · 모니터링 경보, 웹 화면, 현업 창구 · e2e-help, e2e-smoke)·도구(제목과 서버)·입력 항목(이름과 크기)·결과(성공·차단)·응답 크기·시간"><figcaption>내 도구 호출 기록. 흐름·트리거·IDE 에서 부른 것도 함께 나옵니다.</figcaption></figure>

| 칸 | 뜻 |
|---|---|
| **시각 · 사용자** | 부른 때와 사람(사용자는 내 호출만 봄) |
| **호출한 곳** | 어디서 불렀는지 — 웹 화면(화면·채팅), 자동화 흐름, 자동 실행, 현업 창구, IDE 이름/버전 |
| **도구** | 부른 도구(제목과 서버) |
| **입력 항목** | 입력값 이름과 크기. 값은 저장하지 않습니다 |
| **결과** | **성공 · 오류 · 차단**. 오류·차단에 마우스를 올리면 이유 |
| **응답 · 시간** | 결과 크기와 걸린 시간 |

**새로 고침**으로 다시 읽습니다. 입력값과 결과 본문은 개인정보·소스 코드가 들어갈 수 있어 저장하지 않습니다.

## 자주 묻는 질문

**Q. 결과가 '차단'입니다.**
정책에서 내 역할·워크스페이스에 그 도구를 허용하지 않은 경우입니다. 필요하면 관리자에게 정책을 요청하세요.

**Q. 같은 도구가 어제는 됐는데 오늘은 안 보입니다.**
외부 서버의 도구가 바뀌면 관리자가 다시 승인할 때까지 막힙니다. 관리자에게 알려 주세요.
