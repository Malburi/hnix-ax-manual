# 워크스페이스 채팅

> 사내 모델에게 묻고, 문서 검색의 매뉴얼을 근거로 답을 받고, 필요하면 MCP 허브 도구(PMS-X·AX-NAVI·데이터레이크 등)를 내 권한으로 쓰게 하는 대화 화면입니다. **대상**: 모든 사용자. **메뉴**: 왼쪽 메뉴 › 내 작업 › 워크스페이스 채팅.

## 화면 구성

<figure><img src="img/platform/u-chat.png" alt="워크스페이스 채팅 — 왼쪽 대화 목록과 새 대화 단추, 가운데 질문과 답(근거 문서 [1]~[5] 목록, 복사·다시 생성·문서로 저장), 아래 입력칸·마이크·보내기, 오른쪽 모델 고르기·근거 문서함 체크·도구 목록"><figcaption>계정 잠김 문의에 운영 매뉴얼을 근거로 답한 대화. 오른쪽에서 모델·문서함·도구를 고릅니다.</figcaption></figure>

| 영역 | 하는 일 |
|---|---|
| 왼쪽 — **새 대화** · 대화 목록 | 대화 제목, 쓴 모델 별칭, 마지막 시각. 줄을 누르면 열고, **삭제**로 지웁니다 |
| 가운데 — 대화 | 내 질문(오른쪽 말풍선)과 답(왼쪽). 답 아래에 **근거 문서**, 모델·토큰, 👍·👎, **복사 · 다시 생성 · 문서로 저장** |
| 가운데 아래 — 입력칸 | 질문을 적고 **보내기**(또는 Ctrl+Enter). 마이크 단추가 보이면 말로 물을 수 있습니다 |
| 오른쪽 — **모델** | 답할 모델 별칭(예: `hnix-local — 사내 로컬 — 기밀 데이터용`) |
| 오른쪽 — **근거 문서함** | 답할 때 찾아볼 문서함(괄호 안은 문서 수) |
| 오른쪽 — **도구** | 내 권한으로 쓸 수 있는 MCP 허브 도구를 서버별로 묶어 보여 줍니다(예: PMS-X 업무 지식 0/18). **쓰기** 표시는 데이터를 바꾸는 도구입니다 |
| 오른쪽 맨 아래 | 이 대화의 누적 토큰(입력 / 출력) |

> **참고** 대화는 **나만** 봅니다. 마지막 대화 뒤 보관 기간(기본 30일, 관리자가 바꿀 수 있음)이 지나면 지워집니다.

## 묻고 답 받기

1. **새 대화**를 누릅니다(대화가 하나도 없으면 바로 입력해도 새 대화가 시작됩니다).
2. 오른쪽에서 **모델**을 고릅니다. 기밀 자료를 다루면 사내 로컬 모델을 고르세요.
3. 매뉴얼을 근거로 답을 받고 싶으면 **근거 문서함**에 체크합니다.
4. 도구가 필요하면 **도구**에서 고릅니다. 서버 이름 줄의 체크칸은 그 서버 도구를 한꺼번에 켜고 끕니다.
5. 질문을 적고 **보내기**를 누릅니다. 답은 글자가 쌓이듯 흘러나옵니다. 근거를 찾는 동안은 *근거 문서 ○개를 찾았습니다 — 답을 쓰는 중*이 보입니다.

> **참고** 모델·문서함·도구를 바꾸면 지금 대화에 바로 저장됩니다. 다음에 이 대화를 열어도 같은 설정입니다.

빈 대화에는 예시 질문 단추(예: *야간 배치가 실패하면 먼저 무엇을 확인해야 하나요?*)가 보입니다. 누르면 입력칸에 채워집니다.

## 근거 문서 확인하기

- 답 본문의 **[1]** 같은 번호를 누르면 아래 **근거 문서** 목록에서 그 항목이 펼쳐지고 화면이 그리로 갑니다.
- 각 근거는 **[번호] 문서 제목 — 소제목 · 문서함 이름**으로 보이고, 펼치면 실제로 찾은 문서 조각이 나옵니다.
- 근거에 없는 내용을 지어낸 것 같으면 👎 를 누르고 무엇이 아쉬웠는지 적어 주세요(선택).

## 도구를 쓰게 하기

도구를 켜면 모델이 필요할 때 도구를 부르고, 그 결과가 대화 중간에 **도구 · 이름 · 결과** 꼬리표로 나옵니다.

| 꼬리표 | 뜻 |
|---|---|
| **성공** | 도구가 결과를 돌려줌 — **결과 보기**를 펼쳐 원문 확인 |
| **오류** | 도구가 실패함 |
| **거부** | 정책에서 이 도구를 막음 |
| **승인 대기** | 사람 승인이 필요한 도구 — 답 아래 **승인함 열기** 링크 |

> **주의** 도구는 항상 **내 권한**으로 돌고, 승인 정책이 걸린 도구는 관리자가 승인한 뒤에만 실행됩니다. 승인이 나면 같은 질문을 다시 보내 실행하세요. [대시보드와 승인함](/user/platform/dashboard.md) 참고.

## 답 다루기

| 단추 | 하는 일 |
|---|---|
| **복사** | 답 글을 클립보드로 복사 |
| **다시 생성** | 마지막 답을 지우고 같은 질문으로 다시 받습니다(마지막 답에만 보임) |
| **문서로 저장** | 이 답과 근거 목록을 문서함에 문서로 넣습니다. 다음부터 채팅·현업 창구·에이전트가 근거로 씁니다 |
| 👍 · 👎 | 도움이 됐는지 남깁니다. 👎 를 누르면 의견 칸이 열립니다. 모은 피드백은 [AI 사용 현황](/user/platform/usage.md) › 품질 · 지연에 나옵니다 |

### 답을 문서로 저장하기

1. 답 아래 **문서로 저장**을 누릅니다.
2. **문서함**을 고르고 **문서 제목**을 고칩니다.
3. **저장**을 누릅니다(그만두려면 **취소**).

> **참고** 문서함이 하나도 없으면 **문서로 저장**이 눌리지 않습니다. 그 문서함의 워크스페이스 구성원(쓰기 권한)이어야 저장됩니다.

## 말로 묻기

관리자가 게이트웨이에 음성 인식 모델을 연결해 두면 입력칸 옆에 마이크 단추가 보입니다.

1. 마이크를 누르고 말합니다. 단추에 녹음 시간이 흐릅니다.
2. 다시 누르면 녹음이 멈추고 말이 글로 바뀌어 입력칸에 들어갑니다(최대 녹음 시간은 단추에 마우스를 올리면 보입니다).
3. 글을 확인하고 **보내기**를 누릅니다.

> **참고** 브라우저가 마이크 사용을 물으면 **허용**하세요.

## 자주 묻는 질문

**Q. 도구 목록에 필요한 도구가 없습니다.**
허브 정책상 내 역할·워크스페이스에 허용된 도구만 보입니다. 관리자에게 정책을 요청하세요.

**Q. 근거 문서함에 아무것도 없습니다.**
내가 속한 워크스페이스에 문서함이 없는 경우입니다. [문서 검색](/user/platform/docs.md)에서 문서함을 만들거나 관리자에게 요청하세요.
