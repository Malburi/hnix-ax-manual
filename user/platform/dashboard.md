# 대시보드와 승인함

> 로그인하면 처음 보는 화면입니다. 오늘 내 AI 사용량과 확인할 일을 한눈에 보고, 내가 낸 승인 요청의 결과를 **승인함**에서 확인합니다. 머리띠의 **검색**(Ctrl+K)과 **알림** 종도 여기서 함께 설명합니다. **대상**: 로그인한 모든 사람(역할 사용자 기준). **메뉴**: 왼쪽 메뉴 › 대시보드 / 승인함.

## 화면 구성

<figure><img src="img/platform/u-dashboard.png" alt="사용자 대시보드 — 위쪽에 '안녕하세요, 이개발님'과 바로 가기 단추, 큰 칸 셋(오늘 AI 요청 1건, 승인 대기 4건, 오늘 도구 호출 0건 — 최근 8일 막대), 왼쪽 아래 '지금 확인할 일', 오른쪽 아래 세부 지표 여섯 칸"><figcaption>사용자로 로그인한 대시보드. 날짜 옆에 '내 사용 현황'이라고 나오며 내 기록만 셉니다.</figcaption></figure>

| 영역 | 하는 일 |
|---|---|
| 인사말 · 날짜 | **안녕하세요, ○○○님**과 오늘 날짜. 사용자는 **내 사용 현황**, 관리자·감사자는 **플랫폼 전체 운영 현황**으로 표시됩니다 |
| 바로 가기 | **LLM 게이트웨이 · MCP 허브 · 워크스페이스 채팅 · AI 사용 현황** 으로 바로 갑니다(관리자에게는 **현업 창구**가 더 보입니다) |
| 큰 칸 셋 | **오늘 AI 요청**(어제 이 시각 대비·최근 8일 막대, 토큰, 사내 모델 비율) · **승인 대기** · **오늘 도구 호출**(오류 건수). 칸을 누르면 해당 화면으로 갑니다 |
| 지금 확인할 일 | 승인 대기, 도구 호출 오류처럼 손이 필요한 일만 줄로 나옵니다. 줄을 누르면 해당 화면으로 갑니다. 없으면 **지금 확인할 일이 없습니다.** |
| 세부 지표 | 오늘 0시부터 센 **토큰 · 게이트웨이 비용 · 전체 AI 사용 · 정책 차단 · 개인정보 처리 · 도구 호출**. 처리할 일이 있는 칸만 색이 들고 0건은 흐리게 보입니다 |
| 맨 아래 | 플랫폼 버전(예: HNIX AX v0.9.2) |

### 세부 지표 칸의 뜻

| 칸 | 무엇을 세나 | 누르면 |
|---|---|---|
| **토큰** | 오늘 내 게이트웨이 요청의 토큰 합 | AI 사용 현황 › 사용량 · 비용 |
| **게이트웨이 비용** | 외부 모델을 쓴 비용. 사내 모델만 썼으면 **$0.00 — 모두 사내 모델 — 비용 없음** | LLM 게이트웨이 › 요청 로그 |
| **전체 AI 사용** | 게이트웨이 밖에서 쓴 Claude Code·AX-NAVI 사용 기록까지 합친 건수 | AI 사용 현황 |
| **정책 차단** | 게이트웨이 규칙과 MCP 허브 정책에 막힌 건수(게이트웨이 · 도구로 나눠 표시) | AI 사용 현황 › 품질 · 지연 |
| **개인정보 처리** | 모델로 나가기 전에 개인정보를 가리거나 막은 요청 | LLM 게이트웨이(관리자 탭) |
| **도구 호출** | 오늘 MCP 허브 도구 호출 수와 오류 수 | MCP 허브 › 호출 기록 |

> **참고** 사용자의 **승인 대기** 칸은 *내가 낸 요청 중 아직 결정되지 않은 것*입니다. 칸 아래에 "내 요청이 관리자 승인을 기다립니다", 지금 확인할 일에 "내 요청 N건이 승인을 기다립니다"로 나옵니다. 결정은 관리자가 하므로 기다리면 되고, 결정되면 알림 종으로 알려 줍니다.

> **주의** **개인정보 처리** 칸을 누르면 게이트웨이의 **개인정보 보호** 탭으로 가는데, 이 탭은 관리자에게만 보입니다. 사용자에게는 빈 내용이 보일 수 있으니 **개요** 탭을 누르세요.

## 승인함 — 내 요청의 결과 보기

에이전트·채팅이 부른 도구, 런북 실행 요청, 자동화 흐름의 **사람 확인** 단계 중 승인 정책에 걸린 것이 모두 승인함에 쌓입니다. 사용자는 **내가 요청한 것**만 보고, 결정(승인·반려)은 관리자가 합니다.

<figure><img src="img/platform/u-approvals.png" alt="사용자 승인함 — 맨 위 안내 '내가 요청한 승인과 결과입니다', 대기/전체 단추에서 전체 선택, 표에 요청 시각·요청자·도구(플랫폼 상태 확인 · 런북, 서비스 요청 상세 · PMS-X 업무 지식, 자동화 흐름 — 사람 확인 등)·입력 항목·요청 경로·상태(대기·실행됨·만료)·처리 기한·결정 칸"><figcaption>사용자의 승인함(전체 보기). 관리자가 남긴 결정 사유가 '결정' 칸에 보입니다.</figcaption></figure>

| 칸 | 뜻 |
|---|---|
| **대기 / 전체** | 아직 결정 안 된 것만 / 지난 것까지 모두 |
| **요청 · 요청자** | 요청한 때와 사람 |
| **도구** | 부른 도구의 제목과 서버. **자동화 흐름 — 사람 확인**은 자동화 흐름의 사람 확인(`flows__confirm`), 서버가 **런북**이면 런북 실행입니다 |
| **입력 항목** | 넘긴 입력값의 *이름*만 보입니다. 입력값은 결정 전까지만 보관합니다 |
| **요청 경로** | 어디서 불렀는지 — 웹 화면, IDE 이름·버전, `자동화 실행 …○○○○○○`(흐름·에이전트 실행 번호 끝자리) |
| **상태** | **대기 · 승인 · 반려 · 실행됨 · 만료** |
| **처리 기한** | 아직 결정되지 않은 것의 기한(요청 후 하루) |
| **결정** | 결정한 사람 · 시각 · 사유 |

### 승인된 뒤에 실행하기

1. 승인함에서 상태가 **승인**으로 바뀐 것을 확인합니다(알림 종에도 **승인됨 — 도구 이름**이 옵니다).
2. 처음 요청한 곳에서 **같은 입력값으로 다시** 부릅니다. 예: 런북은 런북 화면 **내 실행 요청**의 **[실행]**, 에이전트는 실행 결과의 **이어서 실행**.
3. 승인은 하루 동안, 같은 입력값으로 **한 번만** 쓸 수 있습니다. 실행하면 상태가 **실행됨**으로 바뀝니다.

> **참고** 자동화 흐름의 사람 확인은 다시 부를 필요가 없습니다. 승인되면 흐름이 저절로 이어지고, 반려되면 흐름의 '거부' 갈래로 갑니다.

> **주의** 기한(하루)이 지나면 **만료**가 됩니다. 다시 요청하세요. 내가 요청한 것은 내가 결정할 수 없습니다(관리자도 자기 요청은 다른 관리자가 결정).

- **새로 고침** — 표를 다시 읽습니다.
- 왼쪽 메뉴 **승인함** 옆 빨간 숫자는 *내가 결정해야 할* 대기 건수라서, 결정 권한이 없는 사용자에게는 나오지 않습니다. 관리자의 결정 방법은 [MCP 허브 · 정책 · 승인](/admin/platform/hub.md)을 보세요.

## 알림 종

머리띠의 **알림**을 누르면 최근 7일 알림이 펼쳐집니다. 1분마다 새로 확인하고, 안 읽은 건수가 종 위에 숫자로 붙습니다.

<figure><img src="img/platform/u-dashboard-bell.png" alt="알림 창 — '알림 최근 7일 · 1분마다 새로 봅니다', 모두 읽음 단추, 본문 '확인할 일이 없습니다.'"><figcaption>알림 창. 사용자에게는 내 승인 요청이 결정됐을 때 알림이 옵니다.</figcaption></figure>

| 사용자에게 오는 알림 | 누르면 |
|---|---|
| **승인됨 — 도구 이름** (결정한 사람 · 사유 · "같은 호출을 다시 하면 실행됩니다") | 승인함 |
| **반려됨 — 도구 이름** (결정한 사람 · 사유) | 승인함 |

- 줄을 누르면 그 화면으로 가고 읽음으로 바뀝니다. **모두 읽음**은 지금 목록을 모두 읽음으로 합니다.
- 읽음 표시는 이 브라우저에만 남습니다. 다른 PC에서는 다시 새 알림으로 보입니다.
- 관리자에게는 승인 요청, MCP 서버·모델 연결 문제, 현업 창구에서 담당자에게 넘긴 질문도 옵니다.

## 통합 검색 (Ctrl+K)

어느 화면에서나 **Ctrl+K**(Mac 은 ⌘K)를 누르거나 머리띠의 **검색**을 누르면 검색 창이 뜹니다.

<figure><img src="img/platform/u-dashboard-search.png" alt="통합 검색 창 — 입력칸에 '게이트웨이', 화면 묶음 아래 LLM 게이트웨이 · 내 키 · 모델 별칭 · 요청 로그 항목, 아래쪽 '↑↓ 고르기 · Enter 이동 · Esc 닫기'"><figcaption>'게이트웨이'로 찾은 결과. 탭까지 바로 갈 수 있습니다.</figcaption></figure>

1. 화면 이름이나 찾을 이름을 적습니다.
2. **↑ ↓**로 고르고 **Enter**로 이동합니다. **Esc**로 닫습니다.

| 결과 묶음 | 무엇이 나오나 |
|---|---|
| **화면** | 내가 열 수 있는 화면과 탭(예: **LLM 게이트웨이 · 내 키**, **MCP 허브 · 연결 · 내 도구**) |
| **내 대화** | 워크스페이스 채팅의 내 대화 제목 |
| **에이전트** | 내가 쓸 수 있는 에이전트 |
| **문서** | 문서 검색의 문서 제목(누르면 그 문서함이 열림) |
| **MCP 도구** | 허브 도구 이름 |

> **참고** 검색은 **이름·제목만** 찾습니다. 문서 *내용*은 [문서 검색](/user/platform/docs.md) 화면의 검색으로 찾으세요. 관리자에게는 현업 창구·런북·사용자도 검색됩니다.

## 자주 묻는 질문

**Q. 대시보드 숫자가 동료와 다릅니다.**
사용자는 *내 기록만* 셉니다. 관리자·감사자는 전체를 봅니다.

**Q. 승인함 옆에 숫자가 안 나옵니다.**
그 숫자는 결정 권한이 있는 관리자에게만 나옵니다. 내 요청의 결과는 승인함 표와 알림 종으로 확인하세요.
