# 문서 검색 — 매뉴얼 찾기·올리기

> 운영 매뉴얼·절차서를 문서함에 올려 두고, 질문이나 낱말로 찾습니다. 여기 올린 문서는 채팅·현업 창구·에이전트가 답의 근거로 씁니다. 고친 버전을 다시 올리면 **새 버전으로 바꾸기**로 옛 내용을 정리합니다. **대상**: 모든 사용자(올리기는 워크스페이스 구성원, 남이 올린 문서 지우기는 워크스페이스 관리자). **메뉴**: 왼쪽 메뉴 › AI 통제 › 문서 검색.

RAG(Retrieval-Augmented Generation)는 *문서를 찾아 근거로 붙여 답을 만드는 방식*을 말합니다.

## 화면 구성

<figure><img src="img/platform/u-docs-list.png" alt="문서 검색 화면 — 위쪽 검색칸·문서함 고르기·검색 단추, 위 안내 줄, 왼쪽 문서함 카드(운영 매뉴얼 · 기본 워크스페이스 · 문서 5 · 이전 버전 10 · 의미 검색(hnix-embed) · 사내), 오른쪽 문서 표(제목·조각·크기·상태·올린 사람, 최신 문서 앞 '이전 버전 N개' 꼬리표)와 빠진 의미 색인 채우기·문서 올리기 단추 — 남이 올린 문서라 삭제 단추가 없음"><figcaption>'운영 매뉴얼' 문서함을 고른 모습. 같은 파일을 다시 올린 옛 문서에는 '이전 버전' 표시가 붙습니다.</figcaption></figure>

| 영역 | 하는 일 |
|---|---|
| 맨 위 검색 | 질문이나 낱말로 문서 조각을 찾습니다. 오른쪽 칸에서 문서함 하나로 좁힐 수 있습니다(비우면 **모든 문서함**) |
| 왼쪽 **문서함** | 내가 볼 수 있는 문서함. 한 줄에 **워크스페이스 · 문서 수 · 검색 방식(의미 검색(별칭) 또는 키워드만) · 데이터 등급**(공개·사내·기밀·제한). 문서 수 옆에 같은 이름의 옛 문서 수(**이전 버전 N**)도 나옵니다. **새 문서함**으로 만듭니다 |
| 오른쪽 **문서 — 문서함 이름** | 고른 문서함의 문서 표와 **빠진 의미 색인 채우기 · 문서 올리기**(워크스페이스 관리자에게는 **문서함 삭제**도) |

### 문서 표의 칸

| 칸 | 뜻 |
|---|---|
| **제목** | 문서 제목과 원래 파일 이름. 같은 이름의 옛 문서가 있으면 최신 문서 앞에 **이전 버전 N개** 꼬리표가 붙고, 왼쪽 ▸ 로 펼치면 옛 문서(**이전 버전** 꼬리표)가 보입니다 |
| **조각** | 의미 검색용으로 변환된 조각 수 / 전체 조각 수(예: 36/36). 조각은 문서를 찾기 좋게 나눈 단위입니다 |
| **크기** | 파일 크기 |
| **상태** | **검색 가능**(키워드·의미 검색 모두) · **키워드만**(의미 검색용 변환이 덜 됨) · **오류**(마우스를 올리면 이유) |
| **올린 사람** | 올린 사람 · 날짜 시각 |
| **삭제** | 그 문서를 지웁니다(확인 창이 뜸). **내가 올린 문서**에만 보입니다 — 워크스페이스 관리자·시스템 관리자는 모든 문서에 보입니다 |

## 문서 찾기

<figure><img src="img/platform/u-docs.png" alt="문서 검색 결과 — 검색칸에 '급여 마감 전날 무엇을 확인하나요', 아래 '키워드 + 의미 검색(RRF) · 벡터 엔진 sqlite-vec', 결과마다 문서 제목 > 소제목, 문서함·키워드 순위·의미 순위 꼬리표와 본문 조각"><figcaption>질문으로 찾은 결과. '급여-마감-점검표 › 1. 마감 전날'이 키워드·의미 모두 1위입니다.</figcaption></figure>

1. 맨 위 칸에 질문(예: *급여 배치 실패하면 어떻게 해?*)이나 낱말을 적습니다.
2. 필요하면 오른쪽에서 문서함을 고릅니다.
3. **검색**(또는 Enter)을 누릅니다.
4. 결과는 문서 조각 8개까지 나옵니다. 각 결과에 **문서 제목 › 소제목**, 문서함, **키워드 ○위 · 의미 ○위** 꼬리표가 붙습니다.

| 결과 위 안내 | 뜻 |
|---|---|
| **키워드 + 의미 검색(RRF)** | 낱말 일치와 뜻 비슷함을 함께 따져 순위를 합쳤습니다(RRF = 순위 합치기 방식) |
| **키워드 검색** | 의미 검색을 쓰지 않는 문서함이라 낱말 일치만 봤습니다 |
| 노란 안내 | 일부 문서함의 의미 검색이 안 됐다는 등 주의 사항 |

> **참고** 찾은 게 없으면 *찾은 문서가 없습니다*가 나옵니다. 다른 낱말로 묻거나, 아래 문서함에 문서가 올라가 있는지 확인하세요.

## 문서 올리기

1. 왼쪽에서 문서함을 고릅니다.
2. **문서 올리기**를 누르고 파일을 고릅니다. 여러 개를 한 번에 고를 수 있습니다.
3. 올리기가 끝나면 파일마다 *조각 ○개, 의미 색인 ○개* 같은 알림이 뜨고 표에 나옵니다.

| 올릴 수 있는 형식 | |
|---|---|
| 글 | txt · md · html · csv · json · xml · sql · log · properties |
| 소스 코드 | java · js · ts · py |
| 문서 | Word(docx) · PDF · 한글(hwp · hwpx) |

> **주의** 스캔한 이미지 PDF 는 글자가 없어 받지 않습니다. 글자 인식(OCR)을 거친 PDF 나 원본 문서를 올리세요. 암호가 걸린 PDF·한글 문서, 배포용 한글 문서도 읽지 못합니다. EUC-KR 로 저장된 글 파일은 그대로 올려도 됩니다.

## 새 버전으로 바꾸기 — 고친 문서를 다시 올릴 때

같은 파일 이름이 이미 문서함에 있으면 올리기 전에 묻습니다.

1. **문서 올리기**로 고친 파일을 고릅니다.
2. **같은 이름의 문서가 있습니다** 창이 뜹니다.
3. 고릅니다.

| 단추 | 결과 |
|---|---|
| **새 버전으로 바꾸기** | 새 파일을 올리고 같은 이름의 옛 문서를 지웁니다. 알림에 *새 버전으로 바꿈(이전 버전 ○개 정리)*. 검색·답변 근거에 옛 내용이 섞이지 않습니다 |
| **따로 추가** | 옛 문서를 그대로 두고 하나 더 올립니다. 옛 문서에는 **이전 버전** 꼬리표가 붙습니다 |
| 창 닫기(Esc) | 올리지 않습니다 |

> **주의** **이전 버전** 꼬리표가 붙은 문서는 옛 내용이 답변 근거에 섞일 수 있습니다. 필요 없으면 **삭제**하세요.

## 빠진 의미 색인 채우기

의미 검색을 쓰는 문서함에서 상태가 **키워드만**인 문서가 있으면(올릴 때 모델 서버가 잠시 멈췄던 경우 등) **빠진 의미 색인 채우기**를 누릅니다. *문서 ○개, 조각 ○개 의미 색인* 알림이 뜨고 상태가 **검색 가능**으로 바뀝니다. 의미 색인은 문서 조각을 뜻 비교가 되는 숫자로 바꾸는 일입니다.

## 새 문서함 만들기

1. 왼쪽 **문서함**의 **새 문서함**을 누릅니다.
2. 칸을 채웁니다.

| 칸 | 넣는 것 |
|---|---|
| **이름** | 예: 인사시스템 운영 매뉴얼 |
| **워크스페이스** | 이 문서함을 볼 사람들의 워크스페이스 |
| **의미 검색 모델** | 의미 검색에 쓸 모델 별칭. 비우면 키워드 검색만 |
| **데이터 등급** | **공개 · 사내 · 기밀 · 제한(사내 모델만)**. 비우면 워크스페이스 기본값. 제한 등급 문서는 사내 모델로만 보내집니다 |
| **설명** | 무엇을 담는지 |

3. **만들기**를 누릅니다.

> **참고** 문서함 만들기와 문서 올리기는 그 워크스페이스의 **구성원·워크스페이스 관리자**가 합니다(**보기만**은 검색만). 남이 올린 문서를 지우거나 새 버전으로 바꾸기, **문서함 삭제**는 워크스페이스 관리자·시스템 관리자만 합니다 — 버튼도 그 사람에게만 보입니다. 구성원이 아니면 권한 오류가 납니다. 등급·보관 규칙 같은 관리는 [문서함 관리](/admin/platform/docs.md)를 보세요.

> **주의** **문서함 삭제**는 문서함과 그 안의 문서를 모두 지웁니다. 되돌릴 수 없습니다.
