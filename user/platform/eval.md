# 에이전트 평가

> 에이전트(또는 자동화 흐름)의 결과를 **시험 문항 세트**로 채점하고, 지시문·모델·도구를 바꾼 뒤 이전 평가와 **비교**하는 화면입니다. 내 에이전트를 고칠 때마다 돌려 나빠진 곳이 없는지 확인하세요. **대상**: 모든 사용자(세트를 고치는 것은 대상을 만든 사람과 관리자). **메뉴**: 왼쪽 메뉴 › 에이전트·자동화 › 평가.

> **참고** 관리자에게는 **평가** 메뉴 위에 **에이전트 평가 / 모델 평가** 묶음 탭이 보입니다. 모델 별칭끼리 견주는 **모델 평가**는 관리자 화면입니다([AI 사용 현황 · 생산성 보고서 · 모델 평가](/admin/platform/observe.md)). 사용자는 에이전트 평가만 바로 열립니다.

| 영역 | 하는 일 |
|---|---|
| **에이전트 / 자동화 흐름** | 평가할 대상의 종류 |
| 대상 고르기 · 세트 고르기 | 대상과 평가 세트(세트 이름 · 문항 수) |
| **새 세트 · 가져오기** | 내가 만든 대상일 때만 보입니다 |
| **내보내기** | 세트를 JSON 파일로 받습니다 |
| **세트 지우기** | 세트와 실행 기록을 모두 지웁니다(고칠 수 있을 때만) |
| **평가 실행** | 세트의 모든 문항을 지금 설정으로 돌립니다 |
| 탭 | **문항 ○ · 실행 결과 · 비교** |

에이전트 화면의 **평가** 단추나 실행 결과의 **평가 문항으로 저장**으로 오면 대상이 골라진 채 열립니다.

## 평가 세트 만들기 (내 에이전트·흐름)

1. 대상을 고르고 **새 세트**를 누릅니다.
2. **세트 이름**(예: 기본 회귀, 장애 문의)을 넣고 **만들기**를 누릅니다.
3. **문항** 탭 위쪽에서 세트 설정을 정합니다.

| 칸 | 뜻 |
|---|---|
| **세트 이름 · 설명** | 무엇을 지키려는 세트인지 |
| **동시 실행** | 문항을 몇 개씩 함께 돌릴지(1~3) |
| **기본 심판 모델** | '모델 채점' 항목에 쓸 모델 |
| **승인 필요로 멈춤** | 승인이 필요한 단계에 닿은 문항을 **통과로 봄 / 실패로 봄** |

4. **문항 추가**로 문항을 넣고(아래), **세트 저장**을 누릅니다. 저장 전에는 *저장하지 않은 변경이 있습니다.*가 보입니다.

> **참고** JSON 파일로 받은 세트는 **가져오기**로 다시 넣을 수 있습니다.

### 문항 넣기

<figure><img src="img/platform/u-eval-case.png" alt="문항 c1 창 — id·이름·가중치, 입력(에이전트에게 보낼 문장), 확인 항목 세 줄(써야 하는 도구 pmsx__srs, 정규식 SR-\d{4}, 턴(단계) 상한 4 턴 이하), 닫기 단추"><figcaption>문항 하나. 확인 항목이 모두 맞아야 통과합니다(보기 전용이라 '닫기'만 보임).</figcaption></figure>

1. **문항 추가**를 누릅니다(있는 문항은 줄 끝 **보기**).
2. **id**(비우면 자동) · **이름** · **가중치**를 넣습니다.
3. **입력**에 에이전트에게 보낼 문장을 적습니다. 흐름이면 입력값을 JSON 객체로 적습니다.
4. 아래 **+ 항목** 단추로 확인 항목을 더합니다.

| 확인 항목 | 통과 조건 |
|---|---|
| **답에 포함 / 답에 미포함** | 답에 그 글자가 있다 / 없다(대소문자 무시 선택) |
| **정규식** | 답이 정규식에 맞는다(예: `SR-\d+`) |
| **써야 하는 도구 / 쓰면 안 되는 도구** | 그 도구를 썼다 / 안 썼다(`pmsx__*` 처럼 묶어 쓸 수 있음) |
| **도구 호출 상한** | 도구를 ○회 이하로 불렀다 |
| **턴(단계) 상한** | ○턴(흐름은 ○단계) 이하 |
| **시간 상한** | ○초 이하 |
| **모델 채점** | 채점 기준을 글로 적으면 심판 모델이 0~1 점을 매깁니다. **통과 기준** 점수 이상이면 통과 |

5. **넣기**를 누르고, 다 넣었으면 **세트 저장**.

> **참고** 점수는 확인 항목 점수의 평균(모델 채점은 0~1)이고, 세트 점수는 가중치를 반영한 평균입니다.

**실행에서 문항 만들기**: 에이전트·흐름 실행 결과의 **평가 문항으로 저장**을 누르면, 그 실행의 입력과 쓴 도구로 문항 초안이 열리고 실제 답이 함께 보입니다. 답을 보며 확인 항목을 고쳐 **넣기**합니다.

## 평가 실행하기

1. 대상과 세트를 고릅니다.
2. **평가 실행**을 누릅니다. **실행 결과** 탭으로 바뀌고 진행 막대(완료 문항/전체)가 보입니다.
3. 멈추려면 **멈추기**를 누릅니다.

> **주의** 평가는 **내 권한으로 실제 실행**합니다. 문항마다 에이전트가 실제로 돌고 토큰을 씁니다. 승인이 필요한 단계에 닿으면 승인 요청을 만들지 않고 그 문항을 멈춥니다.

## 실행 결과 보기

| 영역 | 뜻 |
|---|---|
| 왼쪽 **실행 기록** | 실행 시각 · 상태(**실행 중**이면 진행 수, **완료 · 실패 · 멈춤**) · 통과율 · 점수. 줄을 누르면 오른쪽에 열립니다 |
| 요약 칸 | **통과율**(통과 문항/전체) · **평균 점수** · **평균 지연**(p95) · **토큰** · **승인 필요** · **실행 오류** |
| **평가한 설정** | 그때의 모델·도구·최대 턴·지시문 앞부분(흐름은 판) |
| 결과 표 | **결과**(통과·실패·승인 필요·실행 오류) · **문항** · **점수** · **확인 항목**(✓ 맞은 것, ✗ 틀린 것과 이유) · **지연 · 턴 · 토큰 · 쓴 도구** · **디버거** |

- **통과 못한 문항만**에 체크하면 실패한 것만 봅니다.
- **디버거**를 누르면 그 문항의 실제 실행을 [실행 디버거](/user/platform/agents.md)로 보고, **에이전트 화면에서 열기**로 옮겨 갈 수 있습니다.
- 다른 사람이 돌린 평가는 답 본문과 디버거가 보이지 않습니다.
- **지우기**는 그 실행 기록을 지웁니다.

## 이전 평가와 비교하기

1. 결과 위의 **이전과 비교**를 누르거나 **비교** 탭을 엽니다.
2. **비교할 실행**과 **기준(이전)**을 고릅니다. 기준을 비우면 바로 앞 실행과 비교합니다.

| 영역 | 뜻 |
|---|---|
| 위 칸 | **통과율 · 평균 점수 · 평균 지연 · 토큰** 차이(+는 늘어남), 문항별 **좋아짐 · 나빠짐 · 같음** 수 |
| **바뀐 설정** | 두 실행 사이에 바뀐 모델·도구·지시문 등. *없음*이면 같은 설정으로 다시 돈 것 — 모델 답의 흔들림을 볼 수 있습니다 |
| 문항 표 | **변화**(좋아짐·나빠짐·같음·새 문항·빠진 문항) · **이전 · 지금**(결과·점수·지연) · **점수 차이 · 지연 차이** |

> **참고** 같은 세트를 두 번 이상 실행해야 비교할 수 있습니다. 두 실행 사이에 문항이 바뀌었으면 노란 안내가 나옵니다.
