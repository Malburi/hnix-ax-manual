# LLM 게이트웨이 — 내 키와 모델

> 사내의 모든 AI 호출이 지나는 관문입니다. 사용자는 여기서 내 앱·스크립트·Claude Code 가 쓸 **내 키(hx- 키)**를 발급하고, 쓸 수 있는 **모델 별칭**을 확인하고, 내 **요청 로그**를 봅니다. **대상**: 모든 사용자. **메뉴**: 왼쪽 메뉴 › AI 통제 › LLM 게이트웨이(탭: **개요 · 내 키 · 모델 별칭 · 요청 로그**).

LLM(Large Language Model)은 대화형 AI 모델을 말합니다. 게이트웨이는 요청이 모델로 나가기 전에 개인정보를 가리고, 규칙에 따라 모델을 고르고, 비용과 기록을 남깁니다.

> **참고** 관리자·감사자에게는 **개인정보 보호 · 경로 규칙 · 예산 · 모델 연결** 탭이 더 보입니다. 이 설정은 [LLM 게이트웨이 설정](/admin/platform/gateway.md)을 보세요.

## 개요 탭

<figure><img src="img/platform/u-gateway.png" alt="게이트웨이 개요 — 위에 개요·내 키·모델 별칭·요청 로그 탭, 여섯 상자 흐름(앱·IDE·에이전트 → 개인정보 보호 → 경로 규칙·예산(통제 지점) → 모델 별칭 → 모델 연결 → 요청 로그·사용량), '오늘 내 요청' 여섯 칸(요청·토큰·비용·개인정보 처리·정책 차단·평균 응답), 모델 별칭 오늘 많이 쓴 순, 시작하기 안내, 아래 시험 호출 칸"><figcaption>사용자의 개요 탭. '오늘'은 내 요청만 셉니다.</figcaption></figure>

| 영역 | 하는 일 |
|---|---|
| 흐름 그림 | 요청이 지나는 순서를 상자로 보여 줍니다. **앱 · IDE · 에이전트**(내 키 수), **모델 별칭**, **요청 로그 · 사용량** 상자의 **열기**를 누르면 해당 탭으로 갑니다. **설명 보기**로 긴 설명을 펼칩니다 |
| 오늘 | 오늘 0시부터 내 요청의 **요청**(성공·실패·차단) · **토큰** · **비용**(사내 모델은 0원) · **개인정보 처리** · **정책 차단** · **평균 응답** |
| **모델 별칭 — 오늘 많이 쓴 순** | 별칭별 건수·토큰과 **쓸 수 있는 별칭** 목록(의미 검색용·음성 인식 같은 종류 표시) |
| **시작하기** | 내 키를 만들고 주소와 키만 바꾸면 기존 코드가 게이트웨이를 거친다는 예시. **내 키 만들기** 단추 |
| **시험 호출** | 문장 하나를 실제로 보내 어떻게 처리되는지 봅니다 |

### 시험 호출 해 보기

1. **모델 별칭**을 고릅니다. 필요하면 **데이터 등급**(공개·사내·기밀·제한(사내 모델만))도 고릅니다.
2. 보낼 문장을 적습니다. 전화번호 같은 값을 넣어 보면 모델로 나가기 전에 어떻게 가려지는지 볼 수 있습니다.
3. **보내기**를 누릅니다.
4. 오른쪽에 결과가 나옵니다.

| 결과 줄 | 뜻 |
|---|---|
| **요청한 별칭** · 등급 | 내가 고른 별칭과 데이터 등급 |
| **개인정보** | 찾아서 가린 종류와 건수(없으면 *찾은 것 없음*) |
| **경로** | 경로 규칙 때문에 다른 별칭으로 바뀌었으면 표시 |
| **보낸 곳** | 실제로 간 모델 서버·모델과 **사내 / 외부** |
| **폴백** | 첫 모델이 실패해 다음 모델로 넘어간 경로 |
| **걸린 시간** | 초 · 토큰 · 비용 |
| **모델로 나간 문장** | 개인정보를 가린 뒤 실제로 나간 글 |
| **답** 또는 빨간 안내 | 모델의 답, 또는 막힌 이유(예산·경로 규칙·개인정보 차단) |

> **주의** 시험 호출도 실제 요청과 똑같이 기록·집계됩니다. 진짜 개인정보는 넣지 마세요.

## 내 키 탭 — 키 발급과 폐기

<figure><img src="img/platform/u-gateway-keys.png" alt="내 키 탭 — 안내 문장, 폐기된 키도 보기 체크, 키 발급 단추, 표에 이름(AX-NAVI IDE · ms · MCP 허브 등)·키(가림)·권한(허브 도구·사용 기록 수집·LLM 호출)·허용 모델(전체)·데이터 등급(워크스페이스 기본)·분당 한도(제한 없음)·최근 사용·상태(사용 중)와 폐기 단추, 아래 연결 방법 칸"><figcaption>내 키 목록. IDE 가 로그인할 때 만든 키도 여기 나옵니다(키 값은 가려서 찍었습니다).</figcaption></figure>

hx- 키는 게이트웨이를 부를 때 쓰는 *가상 키*입니다. 모델 회사의 진짜 키는 사용자에게 나가지 않습니다.

| 칸 | 뜻 |
|---|---|
| **이름** | 어디에 쓰는 키인지 |
| **키** | 앞부분만 보입니다(`hx-…`) |
| **권한** | **LLM 호출**(`llm`) · **사용 기록 수집**(`ingest`) · **허브 도구**(`mcp`) · **외부 플랫폼 호출**(`a2a`, 외부 플랫폼이 공개 에이전트를 부를 때) |
| **허용 모델** | 이 키로 부를 수 있는 별칭(비우면 **전체**) |
| **데이터 등급** | 이 키 요청의 등급(**워크스페이스 기본** = 워크스페이스 기본값) |
| **분당 한도** | 1분에 부를 수 있는 횟수 |
| **최근 사용 · 상태** | 마지막 사용 시각, **사용 중 / 폐기**. 폐기한 키는 숨겨지며, 위의 **폐기된 키도 보기**를 켜면 함께 보입니다 |

### 키 발급하기

1. **키 발급**을 누릅니다.
2. **가상 키 발급** 창을 채웁니다.

| 칸 | 넣는 것 |
|---|---|
| **이름** | 예: 내 노트북 Claude Code |
| **권한** | 하나 이상. 모델만 쓰면 **LLM 호출(llm)**, MCP 허브 도구를 쓰면 **MCP 허브 도구(mcp)** |
| **허용 모델** | 비우면 전체 |
| **데이터 등급** | **워크스페이스 기본값** 또는 **공개 (public) · 사내 (internal) · 기밀 (confidential) · 제한(사내 모델만) (restricted)** |
| **분당 한도** | 비우면 제한 없음 |

3. **발급**을 누릅니다.
4. 맨 위 초록 칸에 키 원문이 **한 번만** 나옵니다. 바로 복사해 안전한 곳에 둡니다.

> **주의** 키 원문은 다시 볼 수 없습니다. 메신저·메일로 보내거나 화면을 찍어 공유하지 마세요. **조직 수집(ingest_org)** 권한은 관리자만 발급할 수 있습니다.

### 키를 코드에 넣기

아래 **연결 방법** 칸에 예시가 있습니다. 주소와 키만 바꾸면 됩니다.

```bash
# OpenAI SDK·사내 앱
OPENAI_BASE_URL=<플랫폼 주소>/v1
OPENAI_API_KEY=<발급한 hx- 키>

# Anthropic SDK·Claude Code
ANTHROPIC_BASE_URL=<플랫폼 주소>
ANTHROPIC_API_KEY=<발급한 hx- 키>
```

> **참고** AX-NAVI IDE 를 쓰면 키를 손으로 만들 필요가 없습니다. 로그인하면 IDE 가 알아서 받습니다. [내 연결 설정](/user/platform/setup.md) 참고.

### 키 폐기하기

쓰지 않거나 새어 나간 키는 줄 끝 **폐기** → *이 키를 폐기할까요? 되돌릴 수 없습니다.*에서 확인합니다. 상태가 **폐기**로 바뀌고 그 키로 오는 요청은 막힙니다.

## 모델 별칭 탭

<figure><img src="img/platform/u-gateway-models.png" alt="모델 별칭 탭 — 표에 별칭(hnix-code·hnix-embed·hnix-local·hnix-smart·voice-stt)·종류(대화·의미 검색용·음성 인식)·대상 모델(앞에서부터 시도, 실패 시 다음)·설명·사용"><figcaption>모델 별칭. 초록 꼬리표는 사내 로컬 모델입니다.</figcaption></figure>

앱·IDE·에이전트는 실제 모델 이름 대신 **별칭**(예: `hnix-smart`)만 알면 됩니다. 실제 모델과 순서는 관리자가 바꿉니다.

| 칸 | 뜻 |
|---|---|
| **별칭** | 부를 때 쓰는 이름 |
| **종류** | 대화 · 의미 검색용(문서 검색용) · 음성 인식 · 음성 합성 |
| **대상(앞에서부터 시도 → 실패 시 다음)** | 실제 모델. 여러 개면 앞 모델이 실패할 때 다음으로 넘어갑니다(폴백). **초록** = 사내 로컬 |
| **설명 · 사용** | 용도와 켜짐 여부 |

> **참고** 사용자에게는 모델 이름만 보이고, 어느 서버인지와 **별칭 추가**·수정은 관리자에게만 보입니다.

## 요청 로그 탭

<figure><img src="img/platform/u-gateway-requests.png" alt="요청 로그 탭 — 전체 결과 고르기와 새로 고침, 표에 시각·사용자·API(embeddings·openai·스트림)·모델(별칭 → 실제 모델)·결과(성공 200)·입력/출력·비용·지연(첫 토큰)·개인정보·폴백"><figcaption>내 요청 로그. 사용자는 내 요청만 봅니다.</figcaption></figure>

| 칸 | 뜻 |
|---|---|
| **시각 · 사용자** | 요청한 때와 사람 |
| **API** | openai · anthropic · embeddings 등 부른 형식. **스트림**이면 꼬리표 |
| **모델** | 별칭 → 실제 모델 |
| **결과** | **성공 · 오류 · 차단**과 HTTP 상태 번호. 오류·차단에 마우스를 올리면 이유 |
| **입력/출력** | 토큰 수(K = 천) |
| **비용 · 지연(첫 토큰)** | 비용(사내 모델 $0.00), 걸린 시간(괄호는 첫 글자가 나올 때까지) |
| **개인정보** | 가린 개인정보 종류·건수 |
| **폴백** | 다른 모델로 넘어간 횟수(마우스를 올리면 경로) |

- 위 오른쪽 **전체 결과**에서 **성공 · 오류 · 차단**으로 거르고, **새로 고침**으로 다시 읽습니다.
- 요청·응답 본문은 저장하지 않습니다. 사용량·결과·개인정보 탐지 건수만 남습니다.

## 자주 묻는 질문

**Q. 요청이 '차단'으로 끝났습니다.**
마우스를 올려 이유를 보세요. 예산 초과, 경로 규칙(예: 제한 등급 데이터를 외부 모델로 보내려 함), 개인정보 차단이 대표적입니다. 규칙은 관리자가 정합니다.

**Q. 비용이 0원입니다.**
사내 로컬 모델은 0원으로 셉니다.
