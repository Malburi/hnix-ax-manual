# 업무 자동화

> 정해진 순서·분기·반복·사람 확인을 그림으로 그려 두고 그대로 실행하는 기능입니다. 에이전트는 모델이 다음 할 일을 정하지만, 흐름은 **설계한 길만** 가므로 결과를 미리 알 수 있습니다. 사용자는 공개된 흐름을 **시험 실행**하고, **실행 기록**을 보고, 내 흐름을 만들어 공유를 요청할 수 있습니다. **대상**: 모든 사용자. **메뉴**: 왼쪽 메뉴 › 에이전트·자동화 › 업무 자동화(탭: **목록 · 편집기 · 실행 기록**).

## 화면 구성 — 목록 탭

| 칸 · 단추 | 뜻 |
|---|---|
| **이름** | 흐름 이름과 설명 |
| **단계** | 노드 수와 들어 있는 노드 종류(아이콘에 마우스를 올리면 이름) |
| **버전** | 저장할 때마다 1씩 오르는 버전 번호(`v1`) |
| **공개** | **나만 · 공유 요청 중 · 공개**(꺼져 있으면 **꺼짐**도 붙음) |
| **열기** | 편집기 탭에서 엽니다(남의 흐름은 보기 전용) |
| **실행 기록** | 이 흐름의 실행만 모아 봅니다 |
| **평가** | [에이전트 평가](/user/platform/eval.md)에서 이 흐름을 채점합니다 |
| **새 흐름** | 템플릿·말로 만들기·빈 흐름 중에서 골라 내 흐름을 새로 만듭니다(아래 '새 흐름 만들기') |

모델은 게이트웨이, 도구는 MCP 허브, 사람 확인은 승인함을 거치며 **실행한 사람 권한**으로 돕니다.

| 노드 상자 줄 | 단계 종류 — **AI에게 묻기 · 시스템 조회·실행(도구) · 에이전트에게 맡기기 · 조건에 따라 나누기 · 목록 하나씩 반복 · 사람 확인(승인) · 값 정하기 · 끝 · 시작**. 끌어다 놓거나 눌러서 더합니다(내 흐름일 때만) |

## 시험 실행하기

<figure><img src="img/platform/u-flows-testrun.png" alt="시험 실행 창 — 안내 문장, 입력칸 '제목 * title', '내용 body', 접힌 '추가 입력 (JSON)', '자세히 기록 (이번 실행) — 본문을 개인정보를 가려 7일 보관' 체크, 취소·실행 단추"><figcaption>시험 실행 창. 시작 노드에 정한 입력 변수가 칸으로 나옵니다.</figcaption></figure>

1. 목록에서 **열기**로 흐름을 엽니다.
2. **시험 실행**을 누릅니다.
3. 입력칸을 채웁니다. 빨간 `*` 는 꼭 넣어야 합니다. 목록·객체는 JSON 으로 씁니다(예: `["web01","web02"]`). 그 밖의 값은 **추가 입력 (JSON)**에 넣습니다.
4. 단계 본문까지 보려면 **자세히 기록 (이번 실행)**에 체크합니다.
5. **실행**을 누릅니다. 내 흐름에 저장하지 않은 변경이 있으면 먼저 저장합니다.
6. 캔버스 아래에 결과가 나옵니다. 각 노드에도 이번 실행의 결과가 표시됩니다.

| 상태 | 뜻 |
|---|---|
| **실행 중** | 도는 중 |
| **승인 대기** | **사람 확인** 노드에서 멈춤 — 승인함에서 관리자가 결정하면 저절로 이어 갑니다 |
| **완료 · 실패 · 취소** | 끝남. 실패면 빨간 칸에 이유 |

> **주의** 시험 실행도 *진짜 실행*입니다. 흐름 안의 쓰기 도구는 실제 데이터를 바꿉니다. 실행한 사람은 자기 흐름의 사람 확인을 스스로 결정할 수 없습니다. 기다리는 동안 멈추려면 결과 칸의 **취소**를 누릅니다.

결과 칸 아래에는 실행 디버거가 나옵니다. 보는 법은 [에이전트 실행과 내 에이전트](/user/platform/agents.md)의 '실행 디버거' 절과 같습니다. 결과 칸을 치우려면 **닫기**.

'보기'를 누르면 아래에 그 실행의 출력과 디버거가 열립니다.</figcaption></figure>

| 칸 | 뜻 |
|---|---|
| **시작 · 흐름** | 시작 시각, 흐름 이름과 버전 |
| **경로** | **화면 · REST · MCP · 자동 실행 · 평가** — 어디서 실행됐는지 |
| **실행한 사람 · 입력** | 실행한 사람과 입력값 |

## 새 흐름 만들기

목록의 **새 흐름**을 누르면 *새 흐름 — 어디서 시작할까요?* 창이 열립니다. 빈 캔버스 대신 세 가지 중 하나에서 시작합니다. 어느 것을 골라도 편집기에 **저장 안 된 새 흐름**으로 열리고, **저장**을 눌러야 남습니다.

<figure><img src="img/platform/u-flows-gallery.png" alt="새 흐름 — 어디서 시작할까요? 창. 위 말로 만들기 칸(매주 월요일 PMS-X 처리 기한 현황과 처리 중인 서비스 요청을 읽어 운영보고 초안을 만들고, 팀장이 확인하게 해 줘), AI 모델 고르기·초안 만들기 단추와 안내, 아래 준비된 흐름에서 시작 — 서비스 요청 분류·처리, 경보 → 진단 → 사람 확인, 주간 운영보고 초안, 문서 찾아 답 초안 카드(필요한 것 꼬리표와 이걸로 시작 단추)와 빈 흐름에서 시작 카드"><figcaption>[새 흐름]을 누르면 나오는 창 — 위는 말로 만들기, 아래는 준비된 흐름(템플릿)</figcaption></figure>

| 시작하는 곳 | 언제 |
|---|---|
| **준비된 흐름에서 시작** (템플릿) | 비슷한 일이 이미 있을 때. 고쳐 쓰면 가장 빠릅니다 |
| **말로 만들기** | 하고 싶은 일을 글로 쓰면 AI가 단계 초안을 그려 줍니다 |
| **빈 흐름에서 시작** | 시작 → 끝만 있는 캔버스에 직접 그릴 때 |

### 템플릿에서 시작하기

| 템플릿 | 하는 일 | 필요한 것 |
|---|---|---|
| **서비스 요청 분류·처리** | 새 서비스 요청을 AI가 분류해 장애는 담당 에이전트, 문의는 지식 문서 검색 → 답변 초안으로 처리안을 만들고 담당자 확인 뒤 끝냄 | AI 모델, 장애 담당 에이전트, 지식 문서 검색 |
| **경보 → 진단 → 사람 확인** | 모니터링 경보를 받아 진단 에이전트가 원인 후보를 정리하고(실패하면 AI가 간단 진단) 운영자가 확인 | AI 모델, 진단 에이전트, 웹훅 자동 실행(선택) |
| **주간 운영보고 초안** | PMS-X 처리 기한 현황과 처리 중·새로 접수된 서비스 요청을 읽어 AI가 주간 운영보고 초안을 씀 | AI 모델, PMS-X 연결, 예약 자동 실행(선택) |
| **문서 찾아 답 초안** | 질문으로 지식 문서를 찾아 AI가 근거를 밝힌 답 초안을 쓰고 담당자가 확인 | AI 모델, 지식 문서 검색 |

1. 카드의 **이걸로 시작**을 누릅니다.
2. 편집기에 그 흐름이 열립니다. 모델·에이전트 칸에는 내가 쓸 수 있는 첫 모델·에이전트가 미리 들어 있으니, 단계를 눌러 맞는 것으로 바꿉니다.
3. 이름을 고치고 **저장**합니다.

> **참고** 카드에 *내게 보이지 않는 도구: …* 가 나오면 열 수는 있지만 그 도구가 연결되어야 실행됩니다. *쓸 수 있는 에이전트가 없습니다* 가 나오면 에이전트를 먼저 만들거나 그 단계를 바꾸세요.
> **참고** 편집기 머리의 **템플릿 불러오기**도 같은 창을 엽니다. 이미 그린 캔버스가 있으면 바꿀지 한 번 묻고, 저장하기 전까지는 원래 버전이 그대로 있습니다.

### 말로 만들기

<figure><img src="img/platform/u-flows-draft.png" alt="말로 만들기로 열린 저장 안 된 초안 — 이름 '운영보고 초안 작성', 실행 가능·저장 안 됨 꼬리표, 캔버스에 시작 → 데이터 조회(도구) → 서비스 요청 조회(도구) → 보고 초안 작성(AI에게 묻기) → 팀장 확인(사람 확인) → 끝, 거부되면 거부됨 끝, 오른쪽 흐름 설정에 AI가 쓴 설명과 '고칠 곳이 없습니다'"><figcaption>위 문장으로 만든 초안. 단계를 눌러 내용을 확인하고 고친 뒤 저장합니다.</figcaption></figure>

1. **말로 만들기** 칸에 하고 싶은 일을 적습니다. 무엇을 읽고, 무엇을 만들고, 누가 확인하는지까지 적으면 좋습니다. 예: *매주 월요일 PMS-X 처리 기한 현황과 처리 중인 서비스 요청을 읽어 운영보고 초안을 만들고, 팀장이 확인하게 해 줘*
2. 필요하면 **AI 모델**을 고릅니다(비우면 첫 번째 모델).
3. **초안 만들기**를 누릅니다. 사내 작은 모델은 1분쯤 걸릴 수 있습니다.
4. 편집기에 초안이 열립니다. *초안을 열었습니다 — 단계를 눌러 내용을 확인하고 저장하세요.* 가 뜨면 바로 쓸 수 있는 상태이고, *고칠 곳 ○군데가 남아 있습니다* 가 뜨면 빨간 표시가 있는 단계를 눌러 고칩니다.
5. 단계마다 도구 입력값, AI에게 물을 글, 확인할 내용을 읽어 보고 고친 뒤 **저장**합니다.

| 알아 둘 것 | 내용 |
|---|---|
| 쓰는 도구·에이전트 | AI는 **내게 보이는** 도구·에이전트만으로 그립니다. 목록에 없는 이름을 쓰면 고칠 곳으로 표시됩니다 |
| 만드는 단계 | 위에서 아래로 차례로 도는 단계만 만듭니다 — 시스템 조회·실행(도구), AI에게 묻기, 에이전트에게 맡기기, 사람 확인(승인), 값 정하기, 끝 |
| 갈래 · 반복 | 사내 작은 모델도 견디도록 **조건에 따라 나누기**와 **목록 하나씩 반복**은 만들지 않습니다. 필요하면 편집기에서 노드 상자로 더합니다(빠진 단계가 있으면 그렇게 알려 줍니다) |
| 쓰기 도구 | 시스템을 바꾸는 도구 앞에는 사람 확인을 두게 하고, 사람 확인의 '거부'는 *거부됨* 끝으로 잇습니다 |
| 저장 | 초안은 저장되지 않습니다. 모델 호출은 내 권한·예산으로 게이트웨이를 거칩니다 |

### 단계 그리기

노드 상자를 캔버스로 끌어다 놓거나 눌러서 더하고, 노드 오른쪽 점을 끌어 다음 노드 왼쪽 점에 잇습니다. 지우려면 누르고 **Delete**.

| 단계 | 하는 일 |
|---|---|
| **시작** | 실행할 때 받을 입력값을 정합니다 |
| **AI에게 묻기** | AI 모델(게이트웨이)에 묻고 답을 값으로 담습니다 |
| **시스템 조회·실행(도구)** | 업무 시스템을 조회하거나 실행합니다(MCP 허브 도구, 내 권한으로) |
| **에이전트에게 맡기기** | 만들어 둔 에이전트에게 일을 맡기고 결과를 받습니다 |
| **조건에 따라 나누기** | 값을 비교하거나 AI가 골라 갈래로 나눕니다 |
| **목록 하나씩 반복** | 목록의 항목마다 안쪽 단계를 실행합니다 |
| **사람 확인(승인)** | 승인함에 올리고 사람이 결정할 때까지 기다립니다(승인 / 거부 갈래) |
| **값 정하기** | 글이나 앞 단계 값으로 새 값을 만듭니다 |
| **끝** | 흐름의 결과(출력)를 정합니다 |

### 변수 넣기

<figure><img src="img/platform/u-flows-varpick.png" alt="서비스 요청 분류·처리 템플릿에서 '답변 초안'(AI에게 묻기) 단계를 고른 편집기 — 오른쪽 설정 칸의 AI에게 물을 글 옆 변수 넣기를 눌러 펼친 목록: title — 시작 입력 · 제목, body — 시작 입력 · 내용, category — 유형 분류의 답, category.type, category.summary, hits — 지식 문서 검색의 결과"><figcaption>[변수 넣기]는 이 단계까지 선으로 닿는 값만 보여 줍니다.</figcaption></figure>

앞 단계의 결과를 글에 넣을 때 `{{이름}}` 을 외워 쓰지 않아도 됩니다.

1. 단계를 눌러 오른쪽 설정 칸을 엽니다.
2. 글을 쓰는 칸(AI에게 물을 글, 지시문, 도구 입력값, 맡길 일, 확인할 사람에게 보일 내용, 값, 결과로 낼 글) 이름 옆 **변수 넣기**를 누릅니다.
3. 목록에서 값을 고르면 커서 자리에 `{{이름}}` 이 들어갑니다(칸을 한 번도 누르지 않았으면 끝에 붙습니다).

- 목록에는 **시작 입력**과, 선을 거슬러 이 단계까지 닿는 **앞 단계의 결과**만 나옵니다. 각 줄 오른쪽에 어디서 온 값인지(예: *유형 분류의 답 · type*) 보입니다. 아무것도 없으면 *앞 단계와 선으로 이으세요*.
- **목록 하나씩 반복** 안쪽 단계에서는 지금 항목, `loop.number`(몇 번째), `loop.count`(전체 수)도, **사람 확인** 뒤에서는 승인했는지·결정한 사람·결정 사유도 고를 수 있습니다.
- 조건에 따라 나누기의 비교할 변수, 반복의 목록 변수 칸에는 **고르기**가 같은 일을 합니다(괄호 없이 이름만).
- 설정 칸 맨 아래 *쓸 수 있는 변수* 줄에도 같은 목록이 보입니다.

### 저장 · 버전 · 공유

1. 오른쪽 **검증**에 *고칠 곳이 없습니다*가 나오면 **저장**합니다. 이번 버전 메모를 남기면 **버전 기록**에 보입니다.
2. **버전 기록**에서 이전 버전을 **불러오기**해 되돌릴 수 있습니다.
3. 팀과 함께 쓰려면 흐름 설정의 **누가 쓰나**에서 **공유 요청**을 고르고 저장합니다. 관리자가 승인하면 **공개**가 됩니다.

단계 설정의 자세한 내용은 [업무 자동화 · 런북 등록](/admin/platform/automation.md)을 보세요. 자동 실행(예약·웹훅으로 깨우기)은 관리자만 붙일 수 있습니다.

> **주의** **흐름 지우기**(흐름 설정 맨 아래)는 흐름과 실행 기록, 연결된 자동 실행을 함께 지웁니다.
