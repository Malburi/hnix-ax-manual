# 자동화 흐름

> 정해진 순서·분기·반복·사람 확인을 그림으로 그려 두고 그대로 실행하는 기능입니다. 에이전트는 모델이 다음 할 일을 정하지만, 흐름은 **설계한 길만** 가므로 결과를 미리 알 수 있습니다. 사용자는 공개된 흐름을 **시험 실행**하고, **실행 기록**을 보고, 내 흐름을 만들어 공유를 요청할 수 있습니다. **대상**: 모든 사용자. **메뉴**: 왼쪽 메뉴 › 에이전트·자동화 › 자동화 흐름(탭: **목록 · 편집기 · 실행 기록**).

## 화면 구성 — 목록 탭

<figure><img src="img/platform/u-flows.png" alt="자동화 흐름 목록 탭 — 안내 문장, 새 흐름 단추, 표에 이름(서비스 요청 분류·처리와 설명)·노드(9개 · 모델 질문·조건 분기·에이전트 실행·도구 호출·변수 정하기·사람 확인)·판 1·공개·고친 때와 열기·실행 기록·평가 단추"><figcaption>목록 탭. 공개된 흐름과 내가 만든 흐름이 나옵니다.</figcaption></figure>

| 칸 · 단추 | 뜻 |
|---|---|
| **이름** | 흐름 이름과 설명 |
| **노드** | 노드 수와 들어 있는 노드 종류 |
| **판** | 저장할 때마다 1씩 오르는 판 번호 |
| **공개** | **나만 · 공유 요청 중 · 공개**(꺼져 있으면 **꺼짐**도 붙음) |
| **열기** | 편집기 탭에서 엽니다(남의 흐름은 보기 전용) |
| **실행 기록** | 이 흐름의 실행만 모아 봅니다 |
| **평가** | [에이전트 평가](/user/platform/eval.md)에서 이 흐름을 채점합니다 |
| **새 흐름** | 내 흐름을 새로 만듭니다 |

모델은 게이트웨이, 도구는 MCP 허브, 사람 확인은 승인함을 거치며 **실행한 사람 권한**으로 돕니다.

## 편집기 탭 — 흐름 보기

<figure><img src="img/platform/u-flows-editor.png" alt="흐름 편집기 — 위에 흐름 이름·판 1·실행 가능 꼬리표, 판 기록·시험 실행 단추, 노드 상자 줄(모델 질문·도구 호출·에이전트 실행·조건 분기·반복·사람 확인·변수 정하기·끝·시작), 가운데 캔버스에 시작→유형 분류→유형별 갈래→장애 담당 에이전트/지식 문서 검색/기타 안내→담당자 확인→처리안 확정/거부됨 흐름, 오른쪽 흐름 설정(설명·누가 쓰나·사용·자세히 기록·검증·REST 주소)"><figcaption>공개 흐름 '서비스 요청 분류·처리'를 연 모습. 남의 흐름은 고칠 수 없고 시험 실행만 됩니다.</figcaption></figure>

| 영역 | 하는 일 |
|---|---|
| 머리 | 흐름 이름, **판 ○**, 검증 결과(**실행 가능 · 주의 ○ · 고칠 곳 ○**), **저장 안 됨**(고친 뒤), **예시 불러오기 · 판 기록 · 시험 실행 · 저장** |
| 노드 상자 줄 | 끌어다 놓거나 눌러서 노드를 더합니다(내 흐름일 때만) |
| 캔버스 | 노드와 선. 오른쪽 아래 **＋ · － · 맞춤 · 정렬** |
| 오른쪽 칸 | 노드를 누르면 그 노드 설정, 빈 곳을 누르면 **흐름 설정**(설명·누가 쓰나·사용·자세히 기록·검증) |

흐름 설정 아래에 IDE·Claude Code 에서 부르는 법(MCP 도구 `flows__run`)과 다른 시스템이 부르는 REST 주소가 나옵니다.

## 시험 실행하기

<figure><img src="img/platform/u-flows-testrun.png" alt="시험 실행 창 — 안내 문장, 입력칸 '제목 * title', '내용 body', 접힌 '추가 입력 (JSON)', '자세히 기록 (이번 실행) — 본문을 개인정보를 가려 7일 보관' 체크, 취소·실행 단추"><figcaption>시험 실행 창. 시작 노드에 정한 입력 변수가 칸으로 나옵니다.</figcaption></figure>

1. 목록에서 **열기**로 흐름을 엽니다.
2. **시험 실행**을 누릅니다.
3. 입력칸을 채웁니다. 빨간 `*` 는 꼭 넣어야 합니다. 목록·객체는 JSON 으로 씁니다(예: `["web01","web02"]`). 그 밖의 값은 **추가 입력 (JSON)**에 넣습니다.
4. 단계 본문까지 보려면 **자세히 기록 (이번 실행)**에 체크합니다.
5. **실행**을 누릅니다. 내 흐름에 저장하지 않은 변경이 있으면 먼저 저장합니다.
6. 캔버스 아래에 결과가 나옵니다. 각 노드에도 이번 실행의 결과가 표시됩니다.

| 상태 | 뜻 |
|---|---|
| **실행 중** | 도는 중 |
| **사람 확인 대기** | **사람 확인** 노드에서 멈춤 — 승인함에서 관리자가 결정하면 저절로 이어 갑니다 |
| **완료 · 실패 · 취소** | 끝남. 실패면 빨간 칸에 이유 |

> **주의** 시험 실행도 *진짜 실행*입니다. 흐름 안의 쓰기 도구는 실제 데이터를 바꿉니다. 실행한 사람은 자기 흐름의 사람 확인을 스스로 결정할 수 없습니다. 기다리는 동안 멈추려면 결과 칸의 **취소**를 누릅니다.

결과 칸 아래에는 실행 디버거가 나옵니다. 보는 법은 [에이전트 실행과 내 에이전트](/user/platform/agents.md)의 '실행 디버거' 절과 같습니다. 결과 칸을 치우려면 **닫기**.

## 실행 기록 탭

<figure><img src="img/platform/u-flows-runs.png" alt="실행 기록 탭 — '내가 실행한 흐름'과 새로고침, 표에 시작·흐름(판)·경로(화면·트리거)·실행한 사람·입력·상태(완료·실패)·단계·토큰·보기, 아래 고른 실행의 상세(완료, 흐름 이름, 판·시각·토큰, 새로고침·평가 문항으로 저장 단추, 출력 본문)"><figcaption>실행 기록. '보기'를 누르면 아래에 그 실행의 출력과 디버거가 열립니다.</figcaption></figure>

| 칸 | 뜻 |
|---|---|
| **시작 · 흐름** | 시작 시각, 흐름 이름과 판 |
| **경로** | **화면 · REST · MCP · 트리거 · 평가** — 어디서 실행됐는지 |
| **실행한 사람 · 입력** | 실행한 사람과 입력값 |
| **상태 · 단계 · 토큰** | 결과, 지나간 단계 수, 토큰 |
| **보기** | 아래에 상세를 엽니다 |

- 사용자는 **내가 실행한 흐름**만 봅니다(관리자는 전체).
- 목록 탭에서 **실행 기록**을 눌러 왔으면 *흐름 ○○ 의 실행*만 보입니다. **모두 보기**로 풀어 줍니다.
- 상세의 **새로고침**은 도는 중인 실행을 다시 읽고, **평가 문항으로 저장**은 이 실행으로 평가 문항 초안을 만듭니다.

## 내 흐름 만들기(간단히)

1. 목록의 **새 흐름**을 누릅니다. 편집기에 **시작 → 끝**만 있는 흐름이 열립니다.
2. 처음이면 **예시 불러오기**를 눌러 *서비스 요청 분류 → 담당 배정 → 사람 확인* 예시를 봅니다.
3. 노드 상자를 끌어다 놓고, 노드 오른쪽 점을 끌어 다음 노드 왼쪽 점에 잇습니다. 지우려면 누르고 **Delete**.

| 노드 | 하는 일 |
|---|---|
| **시작** | 입력 변수를 정합니다 |
| **모델 질문** | 게이트웨이 모델에 묻고 결과를 변수에 |
| **도구 호출** | MCP 허브 도구를 내 권한으로 |
| **에이전트 실행** | 만들어 둔 에이전트에게 맡김 |
| **조건 분기** | 값을 비교하거나 모델로 분류해 갈래로 |
| **반복** | 목록을 하나씩 돌며 안쪽 길을 실행 |
| **사람 확인** | 승인함에서 결정할 때까지 멈춤(승인 / 거부 갈래) |
| **변수 정하기** | 템플릿으로 값 만들기 |
| **끝** | 결과(출력 템플릿) |

4. 오른쪽 **검증**에 *고칠 곳이 없습니다*가 나오면 **저장**합니다. 이번 판 메모를 남기면 **판 기록**에 보입니다.
5. **판 기록**에서 옛 판을 **불러오기**해 되돌릴 수 있습니다.
6. 팀과 함께 쓰려면 흐름 설정의 **누가 쓰나**에서 **공유 요청**을 고르고 저장합니다. 관리자가 승인하면 **공개**가 됩니다.

노드 설정의 자세한 내용은 [자동화 흐름 · 런북 등록](/admin/platform/automation.md)을 보세요. 트리거(예약·웹훅으로 자동 실행)는 관리자만 붙일 수 있습니다.

> **주의** **흐름 지우기**(흐름 설정 맨 아래)는 흐름과 실행 기록, 연결된 트리거를 함께 지웁니다.
