# 에이전트 실행과 내 에이전트

> 에이전트는 지시문·모델·도구를 갖춘 AI 도우미로, 할 일을 받으면 스스로 도구를 골라 쓰며 답을 만듭니다. 이 화면에서 공개된 에이전트를 실행하고, **실행 디버거**로 단계를 살피고, **내 에이전트**를 직접 만들어 쓰다가 팀에 **공유 요청**을 합니다. **대상**: 모든 사용자. **메뉴**: 왼쪽 메뉴 › 에이전트·자동화 › 에이전트.

## 화면 구성

<figure><img src="img/platform/u-agents-run.png" alt="사용자 에이전트 화면 — 맨 위 에이전트 카드 목록(전체 2·함께 쓰는 것 1·외부 1 거르기, 구매팀 LangGraph 에이전트·SM 운영 도우미 카드와 실행하기·평가 단추)과 오른쪽 위 에이전트 추가 단추, 아래 왼쪽 에이전트 실행 칸(SM 운영 도우미 고름, 평가, 설명, 모델 hnix-local, 내가 쓸 수 있는 도구 꼬리표, 입력칸, 자세히 기록, 실행), 오른쪽 빈 실행 결과, 맨 아래 실행 기록"><figcaption>카드의 [실행하기]로 SM 운영 도우미를 고른 모습</figcaption></figure>

| 영역 | 하는 일 |
|---|---|
| **에이전트 추가** | 오른쪽 위. 사용자는 **직접 만들기**로 내 에이전트를 만듭니다(아래 '내 에이전트 만들기') |
| 거르기 | **전체 · 내 것 · 함께 쓰는 것 · 외부** — 해당하는 것이 있을 때만 보입니다. 에이전트가 7개 이상이면 이름·설명으로 찾는 칸도 나옵니다 |
| 카드 | 화면 이름, 꼬리표(**외부 · 내 것 · 나만 · 공유 요청 중 · 꺼짐 · A2A 공개**), 부르는 이름, 하는 일, 모델·도구 요약(외부는 *외부 호출 한 번으로 답합니다*), 최근 실행 |
| 카드 단추 | **실행하기**(아래 실행 칸에 고르고 입력칸으로) · **수정**(내 것만) · **평가** |
| **에이전트 실행** | 고른 에이전트(고르는 칸에서 바꿔도 됨)의 설명, 모델, **내가 쓸 수 있는 도구**(노란 것은 쓰기 도구), 입력칸, **자세히 기록 (이번 실행만)**, **실행** |
| **실행 결과** | 상태, 턴·토큰·시각, 답, 👍·👎, **평가 문항으로 저장**, 실행 디버거 |
| **실행 기록** | 지난 실행(시작·에이전트·입력·상태·모델 호출·토큰(입력/출력)·**보기**)과 **새로 고침** |

> **참고** 관리자에게는 카드의 **자동 실행**(웹훅·예약·감시로 저절로 실행) 단추와 템플릿 설치·외부 에이전트 연결이 더 보입니다. 자동 실행으로 돈 실행은 실행 기록에 **자동 실행** 꼬리표로 나옵니다. 설정은 [에이전트 · 자동 실행 관리](/admin/platform/agents.md)를 보세요.

## 에이전트 실행하기

1. 쓸 에이전트 카드의 **실행하기**를 누릅니다. 아래 **에이전트 실행** 칸에 그 에이전트가 골라지고 입력칸으로 갑니다.
2. 설명과 **내가 쓸 수 있는 도구**를 확인하고, 입력칸에 할 일을 적습니다. 예: *퇴사자 관련 서비스 요청을 찾아 처리 방향을 정리해 줘.*
3. 문제를 자세히 살펴야 하면 **자세히 기록 (이번 실행만)**에 체크합니다(아래 '자세히 기록' 참고).
4. **실행**을 누릅니다. 끝날 때까지 결과가 저절로 새로 고쳐집니다.

| 상태 | 뜻 |
|---|---|
| **실행 중** | 아직 도는 중 |
| **완료** | 답이 나옴 |
| **실패** | 오류로 멈춤 — 빨간 칸에 이유 |
| **승인 대기** | 승인 정책이 걸린 도구에 닿아 멈춤 |
| **취소** | 멈춤 |

> **참고** 에이전트는 **실행한 사람의 권한**으로 돕니다. 지시문에 적힌 도구라도 내게 보이지 않는 도구는 쓰지 못합니다.

같은 에이전트는 IDE 채팅·Claude Code 에서도 MCP 도구 `agents__run`(카드에 보이는 부르는 이름을 넣어)으로 부를 수 있습니다.

### 승인 대기에서 이어서 실행하기

1. 결과에 *승인 요청 ○○ 이(가) 결정되면 이어서 실행할 수 있습니다.*가 나옵니다.
2. **승인함 열기**로 상태를 확인합니다. 관리자가 승인하면 알림 종에도 **승인됨**이 옵니다.
3. 에이전트 화면의 **실행 기록**에서 그 실행을 **보기**로 열고 **이어서 실행**을 누릅니다.

## 실행 디버거 — 단계 살펴보기

<figure><img src="img/platform/u-agents-debugger.png" alt="실행 결과 카드 — 완료, sm-helper·턴 2·토큰, 답 본문, 이 결과가 도움이 됐나요 👍👎와 평가 문항으로 저장, 단계 3·모델 2·도구 1·처리 2.79초·토큰 요약과 오류 없음 단추, 모델 hnix-local → 도구 pmsx__srs(들여 씀) → 모델 hnix-local 막대, 아래 '단계를 누르면 자세한 내용이 나옵니다' 칸"><figcaption>실행 기록에서 지난 실행 하나를 '보기'로 연 실행 결과 카드(모델 → 도구 → 모델)</figcaption></figure>

실행 결과 아래에 실행 한 건의 단계가 폭포처럼 그려집니다.

| 부분 | 뜻 |
|---|---|
| 맨 위 요약 | 단계 수 · 모델 단계 · 도구 단계 · 처리 시간 · 토큰 |
| 색 | **모델**(파랑) · **도구**(초록) · **승인 대기**(주황) · **오류·거부**(빨강) |
| **첫 오류로 가기 (n)** | 첫 오류 단계로 바로 갑니다. 오류가 없으면 **오류 없음** |
| 단계 줄 | 종류 · 이름 · 막대(언제 시작해 얼마나 걸렸는지) · 걸린 시간. 모델 단계 아래 그 턴의 도구 단계가 들여 쓰여 나옵니다 |
| **⋯ ○초 기다림** | 승인 대기처럼 오래 비어 있던 시간은 줄여 그리고 이렇게 표시합니다 |
| 단계 상세 | 단계를 누르면 아래에 **시작**(실행 시작 + 몇 초) · **지연** · **토큰** · **요약** 또는 오류·거부 사유 |

- 단계를 누른 뒤 **↑ ↓** 키로 옮겨 다닐 수 있습니다.
- 모델에 보낸 메시지·답, 도구 입력값·결과 같은 **본문**은 *자세히 기록*을 켠 실행에서만 보입니다. 꺼져 있으면 *자세히 기록을 켜면 본문이 보입니다…* 안내가 나옵니다.

### 자세히 기록

| 켜는 곳 | 범위 |
|---|---|
| 실행할 때 **자세히 기록 (이번 실행만)** | 이번 실행 하나 |
| 에이전트 수정 창 **고급 › 자세히 기록** | 그 에이전트의 모든 실행(체크칸이 *에이전트 설정으로 켜짐*으로 바뀜) |

- 본문은 개인정보를 가린 뒤 보존 기간(기본 7일) 동안만 남깁니다. 상세에 **개인정보 가림** 표시와 가린 값의 종류가 보입니다.
- 본문은 실행한 사람과 관리자·감사자만 봅니다. 문제를 찾을 때만 켜세요.

## 결과 남기기

- 👍·👎 — *이 결과가 도움이 됐나요?* 피드백. [AI 사용 현황](/user/platform/usage.md) › 품질 · 지연에 모입니다.
- **평가 문항으로 저장** — 이 실행의 입력·출력·쓴 도구로 평가 문항 초안을 만들어 [에이전트 평가](/user/platform/eval.md) 화면으로 갑니다.
- **평가** — 카드나 실행 칸의 **평가**는 그 에이전트를 평가 화면에서 엽니다.

## 내 에이전트 만들기

<figure><img src="img/platform/u-agents-add.png" alt="사용자에게 열린 에이전트 추가 창 — 흐린 '템플릿에서'(관리자가 설치합니다 — 설치되면 목록에 보입니다)와 '직접 만들기'(이름과 하는 일을 적고 쓸 도구를 고르면 AI가 지시문 초안을 써 줍니다. 처음에는 나만 씁니다) 두 상자"><figcaption>[에이전트 추가]를 누른 모습. 사용자는 '직접 만들기'를 고릅니다.</figcaption></figure>

1. 오른쪽 위 **에이전트 추가**를 누르고 **직접 만들기**를 고릅니다. *에이전트 직접 만들기* 창이 열립니다.
2. 위에서부터 채웁니다.

<figure><img src="img/platform/u-agents-new.png" alt="에이전트 직접 만들기 창 — 이름 '장애 접수 도우미', 무슨 일을 하나요(새 서비스 요청을 읽고 비슷한 과거 사례와 운영 매뉴얼로 처리 방향을 정리한다), 쓸 도구 6개 고름(PMS-X 업무 지식 3/18 펼침, 도구마다 설명과 쓰기 꼬리표), 모델 hnix-local 과 그 아래 '도구를 골랐습니다 — 도구 호출은 hnix-code 모델이 잘합니다. hnix-code로 바꾸기', 빈 지시문 칸과 AI로 지시문 초안 단추, 접힌 고급, 채울 것: 지시문, 취소·만들기"><figcaption>이름·하는 일을 적고 도구를 고른 모습. 도구 호출에 약한 모델을 고르면 바꿀 모델을 알려 줍니다.</figcaption></figure>

| 칸 | 넣는 것 |
|---|---|
| **이름** | 화면에 보일 이름. 한글로 씁니다(예: *장애 접수 도우미*) |
| **무슨 일을 하나요?** | 한 줄 설명. 카드와 평가 화면에 보이고, AI 지시문 초안의 재료가 됩니다 |
| **쓸 도구** | 내가 쓸 수 있는 도구가 서버별로 접혀 있습니다. 서버 줄을 눌러 펼치고 필요한 것만 체크합니다(서버 줄 오른쪽 체크칸은 통째로). 위 줄에 *○개 고름*이 보입니다 |
| **모델** | 쓸 모델. 도구를 골랐는데 도구 호출에 약한 모델이면 *도구를 골랐습니다 — 도구 호출은 ○○ 모델이 잘합니다* 줄이 나옵니다. **○○로 바꾸기**를 누르세요 |
| **지시문** | 역할·순서·답 형식. 아래 'AI로 지시문 초안'으로 채운 뒤 고칩니다 |
| **고급** (접힘) | **부르는 이름 (영문)**(이름을 적으면 저절로 제안, 만든 뒤에는 못 바꿈) · **직접 적은 도구 규칙**(예: `pmsx__*`) · **최대 턴**(1~30) · **사용** · **자세히 기록** · **누가 쓰나**(**나만** / **팀에 공유 요청 (관리자 승인)**) |

3. **만들기**를 누릅니다. 아직 비어 있는 칸은 창 왼쪽 아래 *채울 것: …* 에 나옵니다.
4. 카드 목록에 **내 것 · 나만** 꼬리표를 단 카드가 생깁니다. **실행하기**로 시험해 봅니다.

> **참고** 고치기는 카드의 **수정**, 지우기는 수정 창 왼쪽 아래 **지우기**입니다. 내가 만든 에이전트만 고치고 지울 수 있습니다(관리자는 모두).

### AI로 지시문 초안

<figure><img src="img/platform/u-agents-draft.png" alt="같은 창에서 모델을 hnix-code 로 바꾸고 AI로 지시문 초안을 누른 뒤 — 위에 '지시문 초안을 넣었습니다. 읽어 보고 고친 뒤 저장하세요' 알림, 지시문 칸에 역할·데이터 규칙·조회 순서·답 형식을 적은 초안"><figcaption>[AI로 지시문 초안]이 하는 일과 고른 도구로 쓴 지시문. 읽어 보고 고친 뒤 만드세요.</figcaption></figure>

1. **이름**, **무슨 일을 하나요?**, **쓸 도구**, **모델**을 먼저 정합니다.
2. 지시문 칸 위 **AI로 지시문 초안**을 누릅니다(하는 일을 적어야 눌립니다). 사내 모델이면 몇십 초 걸릴 수 있습니다.
3. 초안이 지시문 칸에 들어갑니다. 없는 도구 이름이나 맞지 않는 순서가 있으면 고칩니다.
4. 마음에 들지 않으면 다시 누릅니다. 먼저 적어 둔 지시문을 덮었으면 **이전 지시문으로 되돌리기**가 나옵니다.

> **참고** 초안은 저장되지 않고, 모델 호출은 채팅과 같이 내 권한·예산으로 게이트웨이를 거칩니다.

## 팀에 공유 요청하기

1. 내 에이전트 카드의 **수정**을 누릅니다.
2. **고급**을 펼쳐 **누가 쓰나**에서 **팀에 공유 요청 (관리자 승인)**을 고르고 **저장**합니다.
3. 카드에 **공유 요청 중** 꼬리표가 붙고, 실행 칸 노란 칸에 *공유 요청 중입니다 — 관리자가 승인하면 워크스페이스 사람들이 실행할 수 있습니다.*가 나옵니다.
4. 관리자가 **공개 승인**하면 **공개**가 되고(꼬리표가 사라짐), **돌려보내기**하면 다시 **나만**이 됩니다.

> **참고** 공개된 내 에이전트를 고치면 다시 승인을 받아야 팀에 보입니다.

## 외부 에이전트

다른 팀·다른 플랫폼에서 만든 에이전트(A2A · LangGraph 서버 · OpenAI 호환 채팅 · 일반 HTTP)는 관리자가 **에이전트 추가 › 외부 에이전트 연결**로 등록합니다. 등록된 외부 에이전트는 카드에 **외부 · ○○** 꼬리표가 붙고, 거르기의 **외부**에 모입니다. 실행하는 방법은 다른 에이전트와 같고, 실행 한 번은 외부 호출 한 번입니다.

> **참고** 연결 방법은 [에이전트 · 자동 실행 관리](/admin/platform/agents.md#외부-에이전트-연결)를 보세요.
