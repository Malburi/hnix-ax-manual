# 에이전트 실행과 내 에이전트

> 에이전트는 지시문·모델·도구를 갖춘 AI 도우미로, 할 일을 받으면 스스로 도구를 골라 쓰며 답을 만듭니다. 이 화면에서 공개된 에이전트를 실행하고, **실행 디버거**로 단계를 살피고, **내 에이전트**를 만들어 쓰다가 팀에 **공유 요청**을 합니다. **대상**: 모든 사용자. **메뉴**: 왼쪽 메뉴 › 에이전트·자동화 › 에이전트.

## 화면 구성

<figure><img src="img/platform/u-agents-run.png" alt="에이전트 화면 — 왼쪽 '에이전트 실행' 카드(외부 에이전트 가져오기·내 에이전트 만들기 단추, 에이전트 고르기 alert-triage, 평가 단추, 설명, 모델·쓸 수 있는 도구, 입력칸, 자세히 기록 체크, 실행 단추), 오른쪽 '실행 결과'(완료, 답 본문, 👍👎, 평가 문항으로 저장, 단계 6개 실행 디버거 막대와 고른 도구 단계(pmsx__srs 오류) 상세), 아래 '실행 기록' 표"><figcaption>지난 실행 하나를 '보기'로 연 모습. 오른쪽 아래가 실행 디버거입니다.</figcaption></figure>

| 영역 | 하는 일 |
|---|---|
| **에이전트 실행** 머리 | **외부 에이전트 가져오기**(서버 설정으로 켜진 경우만), **내 에이전트 만들기** |
| 에이전트 고르기 | 내가 쓸 수 있는 에이전트. 이름 뒤에 **· 외부 · 내 것 · 나만 · 공유 요청 중 · (꺼짐)**이 붙습니다. 옆에 **수정**(내 것만) · **평가** |
| 설명 · 모델 · 도구 | 고른 에이전트의 설명, 모델 별칭, **내가 쓸 수 있는 도구**(노란 것은 쓰기 도구) |
| 입력칸 · **자세히 기록 (이번 실행만)** · **실행** | 할 일을 적고 실행 |
| **실행 결과** | 상태, 턴·토큰·시각, 답, 👍·👎, **평가 문항으로 저장**, 실행 디버거 |
| **실행 기록** | 지난 실행(시작·에이전트·입력·상태·모델 호출·토큰(입력/출력)·**보기**)과 **새로 고침** |

> **참고** 관리자에게는 **ITO 기본 에이전트** 설치 단추와 에이전트별 **자동 실행**(웹훅·예약·감시로 저절로 실행) 칸이 더 보입니다. 자동 실행으로 돈 실행도 내 실행 기록에 **트리거** 꼬리표로 나옵니다. 설정은 [에이전트 · 자동 실행 관리](/admin/platform/agents.md)를 보세요.

## 에이전트 실행하기

1. 에이전트를 고릅니다. 설명과 **내가 쓸 수 있는 도구**를 확인합니다.
2. 입력칸에 할 일을 적습니다. 예: *모니터링 경보가 들어왔습니다. 원인 후보와 확인 순서를 정리하세요.*
3. 문제를 자세히 살펴야 하면 **자세히 기록 (이번 실행만)**에 체크합니다(아래 '자세히 기록' 참고).
4. **실행**을 누릅니다. 끝날 때까지 결과가 저절로 새로 고쳐집니다.

| 상태 | 뜻 |
|---|---|
| **실행 중** | 아직 도는 중 |
| **완료** | 답이 나옴 |
| **실패** | 오류로 멈춤 — 빨간 칸에 이유 |
| **승인 대기** | 승인 정책이 걸린 도구에 닿아 멈춤 |
| **취소** | 멈춤 |

> **참고** 에이전트는 **실행한 사람의 권한**으로 돕니다. 지시문에 적힌 도구라도 내게 보이지 않는 도구는 쓰지 못합니다.

같은 에이전트는 IDE 채팅·Claude Code 에서도 MCP 도구 `agents__run`(에이전트 이름을 넣어)으로 부를 수 있습니다.

### 승인 대기에서 이어서 실행하기

1. 결과에 *승인 요청 ○○ 이(가) 결정되면 이어서 실행할 수 있습니다.*가 나옵니다.
2. **승인함 열기**로 상태를 확인합니다. 관리자가 승인하면 알림 종에도 **승인됨**이 옵니다.
3. 에이전트 화면의 **실행 기록**에서 그 실행을 **보기**로 열고 **이어서 실행**을 누릅니다.

## 실행 디버거 — 단계 살펴보기

실행 결과 아래에 실행 한 건의 단계가 폭포처럼 그려집니다.

| 부분 | 뜻 |
|---|---|
| 맨 위 요약 | 단계 수 · 모델 단계 · 도구 단계 · 처리 시간 · 토큰 |
| 색 | **모델**(파랑) · **도구**(초록) · **승인 대기**(주황) · **오류·거부**(빨강) |
| **첫 오류로 가기 (n)** | 첫 오류 단계로 바로 갑니다. 오류가 없으면 **오류 없음** |
| 단계 줄 | 종류 · 이름 · 막대(언제 시작해 얼마나 걸렸는지) · 걸린 시간. 모델 단계 아래 그 턴의 도구 단계가 들여 쓰여 나옵니다 |
| **⋯ ○초 기다림** | 승인 대기처럼 오래 비어 있던 시간은 줄여 그리고 이렇게 표시합니다 |
| 단계 상세 | 단계를 누르면 아래에 **시작**(실행 시작 + 몇 초) · **지연** · **토큰** · **요약** 또는 오류·거부 사유 |

- 단계를 누른 뒤 **↑ ↓** 키로 옮겨 다닐 수 있습니다.
- 모델에 보낸 메시지·답, 도구 입력값·결과 같은 **본문**은 *자세히 기록*을 켠 실행에서만 보입니다. 꺼져 있으면 *자세히 기록을 켜면 본문이 보입니다…* 안내가 나옵니다.

### 자세히 기록

| 켜는 곳 | 범위 |
|---|---|
| 실행할 때 **자세히 기록 (이번 실행만)** | 이번 실행 하나 |
| 에이전트 설정의 **자세히 기록 (디버그)** | 그 에이전트의 모든 실행(체크칸이 *에이전트 설정으로 켜짐*으로 바뀜) |

- 본문은 개인정보를 가린 뒤 보존 기간(기본 7일) 동안만 남깁니다. 상세에 **개인정보 가림** 표시와 가린 값의 종류가 보입니다.
- 본문은 실행한 사람과 관리자·감사자만 봅니다. 문제를 찾을 때만 켜세요.

## 결과 남기기

- 👍·👎 — *이 결과가 도움이 됐나요?* 피드백. [AI 사용 현황](/user/platform/usage.md) › 품질 · 지연에 모입니다.
- **평가 문항으로 저장** — 이 실행의 입력·출력·쓴 도구로 평가 문항 초안을 만들어 [에이전트 평가](/user/platform/eval.md) 화면으로 갑니다.
- **평가** — 고른 에이전트를 평가 화면에서 엽니다.

## 내 에이전트 만들기

<figure><img src="img/platform/u-agents-new.png" alt="새 에이전트 창 — 이름(영문 소문자·숫자·하이픈), 모델 별칭, 설명, 지시문(시스템 프롬프트), 쓸 수 있는 도구(docs__search, pmsx__* 꼬리표), 최대 턴 8, 사용 켜짐, 자세히 기록(디버그) 꺼짐, 누가 쓰나(나만 / 팀에 공유 요청(관리자 승인)), 취소·저장"><figcaption>내 에이전트 만들기 창. 처음에는 '나만'으로 만들어집니다.</figcaption></figure>

1. **내 에이전트 만들기**를 누릅니다.
2. 칸을 채웁니다.

| 칸 | 넣는 것 |
|---|---|
| **이름 (영문 소문자·숫자·하이픈)** | 예: `sr-helper`. 만든 뒤에는 바꿀 수 없습니다 |
| **모델 별칭** | 쓸 모델 |
| **설명** | 무엇을 하는 에이전트인지(목록과 평가 화면에 보임) |
| **지시문 (시스템 프롬프트)** | 역할·순서·답 형식. 예: *① pmsx__similar 로 비슷한 요청을 찾고 ② docs__search 로 매뉴얼 절차를 찾아 ③ 요약 / 원인 후보 / 먼저 확인할 것 순으로 답한다* |
| **쓸 수 있는 도구** | 허브 도구 이름. `pmsx__*` 처럼 `*` 로 묶을 수 있습니다. **+** 로 추가, **×** 로 뺍니다 |
| **최대 턴** | 모델 ↔ 도구를 오가는 최대 횟수(1~30) |
| **사용** | 끄면 목록에서 (꺼짐)으로 보이고 실행할 수 없습니다 |
| **자세히 기록 (디버그)** | 모든 실행의 본문을 남길지 |
| **누가 쓰나** | **나만** / **팀에 공유 요청 (관리자 승인)** |

3. **저장**을 누릅니다. 이름·지시문·모델이 비면 눌리지 않습니다.
4. 바로 위 **에이전트 실행**에서 골라 시험해 봅니다.

> **참고** 고치기는 에이전트를 고른 뒤 **수정**, 지우기는 수정 창의 **지우기**입니다. 내가 만든 에이전트만 고치고 지울 수 있습니다(관리자는 모두).

## 팀에 공유 요청하기

1. 내 에이전트를 고르고 **수정**을 누릅니다.
2. **누가 쓰나**에서 **팀에 공유 요청 (관리자 승인)**을 고르고 **저장**합니다.
3. 에이전트 이름 뒤에 **· 공유 요청 중**이 붙고, 노란 칸에 *공유 요청 중입니다 — 관리자가 승인하면 워크스페이스 사람들이 실행할 수 있습니다.*가 나옵니다.
4. 관리자가 **공개 승인**하면 **공개**가 되고, **돌려보내기**하면 다시 **나만**이 됩니다.

## 외부 에이전트 가져오기

관리자가 켜 두었으면 **외부 에이전트 가져오기**가 보입니다. 다른 도구로 만든 에이전트(A2A · LangGraph 서버 · OpenAI 호환 채팅 · 일반 HTTP)를 플랫폼 에이전트로 등록합니다.

1. **외부 에이전트 가져오기**를 누릅니다.
2. 네 단계를 따라갑니다: **종류** → **주소·인증**(주소, 인증 없음 / Bearer 토큰 / API 키 머리글, 시간 제한, 사내 주소만 허용) → **연결 시험** → **이름·공개 범위**.
3. 저장하면 목록에 **· 외부**로 나옵니다. 실행 한 번은 외부 호출 한 번입니다.

> **주의** 비밀값(토큰·키)은 저장소에 보관되고 다시 보여 주지 않습니다. 자세한 설명은 [에이전트 · 자동 실행 관리](/admin/platform/agents.md)를 보세요.
