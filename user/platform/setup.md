# 내 연결 설정과 AX-NAVI 기기

> 내 PC 에 AX-NAVI IDE 를 설치하고 이 플랫폼에 연결하는 곳, 그리고 연결한 기기를 확인·승인·끊는 곳입니다. 개인 PC 는 **설치하고 로그인하면 끝**입니다 — 키나 환경 변수를 손으로 넣지 않습니다. **대상**: 모든 사용자. **메뉴**: 왼쪽 메뉴 › 내 작업 › 내 연결 설정(탭: **연결 설정 / 내 AX-NAVI 기기**).

## 화면 구성

<figure><img src="img/platform/u-setup.png" alt="내 연결 설정 — 위에 연결 설정·내 AX-NAVI 기기 묶음 탭, 초록 안내 '개인 PC 는 설치하고 로그인하면 끝입니다', 1 개인 PC 설치(설치 파일 받기 단추·파일 이름·SHA-256), 2 이 서버에 연결(AX-NAVI IDE 에서 열기 단추·서버 주소·복사), 3 확인(연결한 기기), 아래 'Claude 구독이 있으면' 설명과 접힌 '고급' 칸"><figcaption>연결 설정 탭. 1 → 2 → 3 순서로 따라 하면 됩니다.</figcaption></figure>

| 영역 | 하는 일 |
|---|---|
| 묶음 탭 | **연결 설정**(이 쪽) / **내 AX-NAVI 기기**(승인 코드 입력·기기 목록) |
| 초록 안내 | 로그인하면 IDE 가 사내 모델 연결·사용량 기록·MCP 허브·AX-NAVI 엔진을 이 서버에서 받아 스스로 설정한다는 설명 |
| **1 개인 PC 설치** | **개인 PC 설치 파일 ○○ 받기** 단추와 파일 이름·크기·SHA-256(파일 지문) |
| **2 이 서버에 연결** | **AX-NAVI IDE 에서 열기** 단추, 서버 주소와 **복사** |
| **3 확인** | 지금 연결된 내 IDE 기기(기기·IDE 판·마지막 사용·**연결됨**)와 **새로 고침** |
| **Claude 구독이 있으면** | 개인·회사 Claude 구독과 함께 쓰는 법 |
| **고급 — 개인 PC 설치 없이 Claude Code 만 쓰는 경우(서버·CI 등)** | 접힌 칸. 키를 발급해 직접 설정하는 법 |

## 내 PC 연결하기 — 1 · 2 · 3

1. **개인 PC 설치 파일 ○○ 받기**를 누르고, 받은 파일(`HNIX-AX-PC-Setup-<판>.exe`)을 실행합니다.
   - 관리자 권한 없이 내 계정에 설치되고, 회사 코드 서명이 된 파일입니다.
   - 설치 화면이 플랫폼 주소를 물으면 화면에 보이는 서버 주소를 넣습니다.
   - 이미 설치했으면 건너뜁니다. 새 판도 같은 방법으로 덮어 설치합니다.
2. **AX-NAVI IDE 에서 열기**를 누릅니다.
   - IDE 가 열리고 *연결할까요?*를 물으면 **연결**을 누릅니다.
   - 이어서 브라우저에 승인 화면(**내 AX-NAVI 기기** 탭)이 뜨면 IDE 의 승인 코드와 같은지 보고 **이 기기 승인**을 누릅니다.
   - 단추가 안 되면 IDE 오른쪽 아래 **AX-NAVI 연결**을 누르고 서버 주소(**복사**로 복사)를 넣습니다.
3. **확인** 칸에 내 기기가 **연결됨**으로 나오면 됐습니다(안 보이면 **새로 고침**). IDE 상태 표시줄에 **AX-NAVI · 내 이름**이 보입니다.

> **참고** 서버에 설치 파일이 없으면 1번 칸에 *서버에 설치 파일이 아직 없습니다. 관리자에게 받으세요.*가 나옵니다.

> **참고** PC 에 Claude Code 가 있으면 IDE 가 로그인할 때 Claude Code 의 사용량 전송과 MCP 허브 연결도 함께 맞춥니다. Claude Code 를 IDE 보다 나중에 깔았으면 IDE 를 한 번 다시 여세요.

IDE 쪽 화면과 자세한 설치 과정은 [AX-NAVI 설치 · 로그인 · 기기 승인](/user/axnavi/install.md)을 보세요.

## Claude 구독과 함께 쓰기

Pro·Max 개인 구독이나 회사 Team·Enterprise 좌석이 있으면 PC 에 Claude Code 를 설치하고 터미널에서 `claude` 를 한 번 실행해 로그인하세요. IDE 가 구독을 먼저 쓰고, 안 될 때만 사내 모델로 넘어갑니다.

> **주의** 구독 자격 증명(로그인·API 키)은 이 서버로 보내지도, 이 화면에 넣지도 않습니다. 서버가 여러 사람의 요청을 구독 자격으로 중계하는 것은 허용되지 않기 때문입니다.

## 고급 — IDE 없이 Claude Code 만 쓸 때

서버·CI 처럼 개인 PC 설치 없이 Claude Code 만 쓰는 경우에만 펼칩니다.

1. **고급 — …** 줄을 눌러 펼칩니다.
2. **내 터미널**에서 **PowerShell** 또는 **bash·zsh** 를 고릅니다.
3. 필요한 설정 칸에서 키를 발급합니다.

| 칸 | 단추 | 하는 일 |
|---|---|---|
| **사용량을 Insight 로** | **수집 키 발급** · **복사** | Claude Code 사용량(토큰·비용·도구 이름만, 프롬프트·응답 본문은 안 감)을 AI 사용 현황으로 보내는 설정. `~/.claude/settings.json` 에 합쳐 넣습니다 |
| **구독 없이 사내 모델로** | 모델 고르기 · **게이트웨이 키 발급** · **복사** | Claude Code 가 사내 게이트웨이의 모델을 쓰게 하는 환경 변수 |

4. 발급하면 키가 설정 글에 바로 채워집니다. **복사**해서 붙여 넣습니다.

> **주의** 키 원문은 이 화면을 떠나면 다시 볼 수 없습니다. 남에게 보내거나 화면을 찍어 공유하지 마세요. 잃어버리면 [LLM 게이트웨이 › 내 키](/user/platform/gateway.md)에서 폐기하고 새로 발급합니다.

관리자에게는 맨 아래 **관리자 — 전 직원 일괄 배포** 칸(조용히 설치 명령, AX-NAVI 조직 정책, Claude Code 관리 설정)이 더 보입니다. [개인 PC 배포 — IDE·연결](/admin/install-pc.md) 참고.

## 내 AX-NAVI 기기 탭

<figure><img src="img/platform/u-setup-devices.png" alt="내 AX-NAVI 기기 탭 — 위 카드 'AX-NAVI 기기 연결'에 승인 코드 입력칸(예: BCDF-GHJK)과 확인 단추, 아래 카드 '내 AX-NAVI 기기' 표(기기·프로그램·상태·연결·마지막 사용)"><figcaption>내 AX-NAVI 기기 탭. IDE 에서 로그인을 누르면 이 화면이 열립니다.</figcaption></figure>

### 새 기기 승인하기

IDE 나 AX-NAVI CLI 에서 로그인을 누르면 이 탭이 승인 코드를 채운 채 열립니다. 직접 열었다면 IDE 에 보이는 코드를 넣고 **확인**을 누릅니다.

1. 표에 나온 **승인 코드 · 계정 · 기기 · 프로그램 · 요청 주소 · 만료**를 확인합니다.
2. 승인 코드가 IDE 에 보이는 것과 **같은지** 꼭 봅니다.
3. **이 기기 승인**을 누릅니다. *승인했습니다 — IDE 로 돌아가세요*가 나오고 몇 초 안에 IDE 로그인이 끝납니다.
4. 내가 시작하지 않은 요청이면 **거절**을 누릅니다.

| 노란 안내 | 할 일 |
|---|---|
| *AX-NAVI 사용 허가가 없습니다.* | 관리자에게 사용 허가(좌석)를 요청합니다 |
| *기기는 ○대까지입니다.* | 아래 표에서 안 쓰는 기기를 **끊기**한 뒤 다시 승인합니다 |

### 기기 끊기

| 칸 | 뜻 |
|---|---|
| **기기** | PC 이름 · 운영체제 |
| **프로그램** | AX-NAVI IDE 또는 AX-NAVI CLI 와 판 |
| **상태** | **사용 중** / **끊김**. 끊은 기기는 기본으로 숨겨지고, 표 위 **끊은 기기도 보기**를 켜면 함께 보입니다(10대가 넘으면 쪽으로 나뉨) |
| **연결** | 처음 승인한 때 |
| **마지막 사용** | 마지막으로 쓴 때 · 주소 |

1. 끊을 기기 줄의 **끊기**를 누릅니다.
2. *이 기기의 AX-NAVI 를 잠글까요?*에서 확인합니다.
3. 그 기기의 AX-NAVI 는 바로 잠기고, 그 기기의 연결 키도 함께 꺼집니다.

> **주의** PC 를 바꾸거나 잃어버렸으면 바로 끊으세요. 다시 쓰려면 IDE 에서 로그인해 새로 승인합니다.
