# 런북 실행 요청

> 런북은 배치 재실행·캐시 비우기·서비스 재기동처럼 **미리 등록해 둔 조치**입니다. 사용자는 **점검**으로 미리 확인하고, **실행 요청**을 내고, 승인된 뒤 실행해 결과를 남깁니다. **대상**: 모든 사용자(등록·수정은 관리자). **메뉴**: 왼쪽 메뉴 › 에이전트·자동화 › 런북.

## 화면 구성

<figure><img src="img/platform/u-runbooks.png" alt="런북 화면 — 맨 위 파란 안내(실행 요청은 다른 관리자가 승인한 뒤에만 돈다, 승인 번호는 왼쪽 메뉴 승인함), 런북 표(이름 플랫폼 상태 확인 · runbook__e2e_health, 설명, 종류 HTTP, 위험도 낮음, 상태 켜짐, 실행… 단추), 아래 실행 기록 표(시각·런북·인자·사유·요청·승인·결과·소요)"><figcaption>사용자의 런북 화면. 등록·수정·삭제 단추는 관리자에게만 보입니다.</figcaption></figure>

| 영역 | 하는 일 |
|---|---|
| 맨 위 안내 | 실행 요청은 **다른 관리자가 승인한 뒤**에만 돌고, 승인 번호는 왼쪽 메뉴 **승인함**에서 본다는 설명. 런북 기능이 꺼져 있으면 노란 칸 *런북 실행이 꺼져 있습니다* |
| **런북** 표 | **이름**(제목과 도구 이름 `runbook__이름`, 실패 시 원복 런북이 있으면 함께), **설명 · 종류**(명령 / HTTP) · **위험도**(낮음·보통·높음) · **상태**(켜짐·꺼짐·명령 꺼짐) · **실행…** |
| **실행 기록** 표 | 내 실행 요청의 결과. 줄을 펼치면 출력이 보입니다 |

> **참고** 에이전트·채팅도 같은 도구(`runbook__이름`)로 실행을 요청합니다. 그 요청도 같은 승인을 거칩니다.

## 점검 — 승인 없이 미리 확인하기

점검이 준비된 런북은 실행 창에 **점검** 단추가 있습니다. 점검은 실제 조치를 하지 않고 할 수 있는 상태인지 확인만 하므로 승인 없이 바로 돕니다.

<figure><img src="img/platform/u-runbooks-run.png" alt="실행 창 '실행 — 플랫폼 상태 확인' — 사유 입력칸(승인자가 봅니다 — 예: INC-1234 야간 배치 실패), 점검·실행 요청 단추"><figcaption>실행 창. 매개변수가 있는 런북은 사유 위에 값 칸이 더 나옵니다.</figcaption></figure>

1. 런북 줄의 **실행…**을 누릅니다.
2. 매개변수 칸을 채웁니다. 선택지가 있으면 고르고, 아니면 칸에 보이는 형식대로 적습니다.
3. **점검**을 누릅니다.
4. 창 아래에 결과가 나옵니다(초록 = 성공, 빨강 = 실패). 실행 기록에는 **점검** 꼬리표로 남습니다.

## 실행 요청 → 승인 → 실행

1. **실행…**을 누르고 매개변수를 채웁니다.
2. **사유**를 적습니다. 승인자가 봅니다. 예: *INC-1234 야간 배치 실패*.
3. **실행 요청**을 누릅니다. 창에 승인 번호와 함께 *승인 대기* 안내가 파랗게 나옵니다.
4. [승인함](/user/platform/dashboard.md)에서 상태를 확인합니다. 관리자가 승인하면 알림 종에 **승인됨 — runbook__이름**이 옵니다.
5. 다시 **실행…**을 열고 **같은 값**으로 **실행 요청**을 누릅니다. 이번에는 실제로 실행되고 결과가 나옵니다.

> **주의** 승인은 **같은 인자로 한 번**, 요청 후 **하루** 안에만 쓸 수 있습니다. 값을 하나라도 바꾸면 새 승인이 필요합니다. 반려되면 알림 종과 승인함에 사유가 나옵니다.

> **참고** 실패하거나 시간이 넘으면 되돌리는 *원복 런북*이 정해진 런북은, 같은 인자·같은 승인으로 원복이 바로 돌고 실행 기록에 **원복** 꼬리표로 남습니다.

## 실행 기록 보기

| 칸 | 뜻 |
|---|---|
| **시각 · 런북** | 실행한 때와 런북. **점검 · 원복** 꼬리표 |
| **인자 · 사유** | 넣은 값과 사유 |
| **요청 · 승인** | 요청한 사람, 승인한 사람(점검은 —) |
| **결과** | **성공 · 실패 · 시간 초과 · 실행 중**과 종료 코드(HTTP 런북은 응답 번호) |
| **소요** | 걸린 시간 |

줄 왼쪽을 눌러 펼치면 실행 출력이 나옵니다. 사용자는 **내 실행**만 봅니다(관리자는 전체).

## 자주 묻는 질문

**Q. 실행… 단추가 눌리지 않습니다.**
런북이 꺼져 있거나 서버에서 런북 실행이 꺼진 경우입니다. 상태 칸의 **꺼짐 · 명령 꺼짐**을 확인하고 관리자에게 알리세요.

**Q. 런북을 새로 만들고 싶습니다.**
등록은 관리자가 합니다. [자동화 흐름 · 런북 등록](/admin/platform/automation.md)을 보세요.
