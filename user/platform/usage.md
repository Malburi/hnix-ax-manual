# AI 사용 현황

> 내가 쓴 AI 의 양과 비용, 그리고 품질(성공률·지연·정책 위반·피드백)을 보는 화면입니다. 게이트웨이를 거친 요청뿐 아니라 Claude Code·AX-NAVI 사용 기록도 함께 셉니다. **대상**: 모든 사용자(사용자는 내 기록만). **메뉴**: 왼쪽 메뉴 › 관측·보고 › AI 사용 현황(묶음 탭: **사용량 · 비용 / 품질 · 지연**).

> **참고** 관리자·감사자는 전체 사용자 기록을 보고, 묶음 탭에 **외부 AI · 자산**, 사용량 화면에 **수집 소스** 탭과 **사용자** 집계가 더 있습니다. [AI 사용 현황 · 생산성 보고서 · 모델 평가](/admin/platform/observe.md) 참고.

## 사용량 · 비용

### 요약 탭

| 영역 | 하는 일 |
|---|---|
| 기간 | **7일 · 30일 · 90일** |
| 거르기 | **프로젝트 전체 · 모델 전체 · 소스 전체**(소스 = 게이트웨이 · Claude Code · AX-NAVI · 수집기 push · OTLP · 에이전트) |
| **CSV 내보내기** | 지금 조건의 기록을 CSV 파일로 받습니다 |
| 네 칸 | **비용**(기간 합계, 단가 없는 요청은 빼고 건수 표시) · **토큰**(입력·출력·캐시) · **기록**(모델 요청·도구 기록 수) · **캐시 적중률** |
| **일별 비용 / 토큰** 그래프 | 위 오른쪽에서 **비용 · 토큰**과 **모델별 · 소스별 · 프로젝트별**을 고릅니다. 상위 5개 + 기타로 쌓아 보여 줍니다(UTC 날짜 기준) |
| **항목별 집계** | **모델 · 프로젝트 · 팀 · 작업번호(서비스 요청·변경) · 소스 · 도구** 단추로 묶는 기준을 바꿉니다. 칸: 기록 · 입력 · 캐시 읽기 · 출력 · 비용(막대) |

> **참고** 사내 로컬 모델은 0원으로 셉니다. 기간 비용이 0원이면 그래프가 저절로 **토큰**으로 바뀌고 *이 기간 비용이 0원이라… 토큰으로 보여 줍니다* 안내가 나옵니다.

> **참고** 비용 막대 옆 **단가없음 ○** 꼬리표는 단가표에 없는 모델이라 비용을 못 셌다는 뜻입니다. 관리자에게 단가 등록을 요청하세요.

### 최근 기록 탭

하나하나의 사용 기록입니다: **시각 · 소스 · 사용자 · 프로젝트 · 작업번호 · 모델·도구 · 입력/출력 · 비용**. 25건씩 넘겨 봅니다.

### 단가표 탭

모델별 단가(USD / 백만 토큰 — 입력·출력·캐시 읽기·캐시 쓰기)입니다. 비용 계산의 기준이며 사용자는 보기만 합니다(추가·수정·**비용 다시 계산**은 관리자).

### 작업번호로 나눠 보기

AX-NAVI·Claude Code 사용 기록에 서비스 요청·CR 번호가 붙어 있으면 **항목별 집계 › 작업번호(서비스 요청·변경)**로 일감별 AI 사용량을 볼 수 있습니다. 번호가 없는 기록은 빈 값으로 묶입니다.

## 품질 · 지연

<figure><img src="img/platform/u-usage-observe.png" alt="품질·지연 화면 — 안내 줄, 하루·7일·30일, '내 기록만 표시', 여섯 칸(LLM 성공률 100%, 응답 지연 p95 10.5초, 도구 성공률 98.6%, 에이전트 성공률 100%, 정책 차단 58, 사용자 만족도 -), 일별 LLM 요청(결과별 누적) 그래프, 일별 응답 지연 p95 그래프, 모델 별칭별 지연·오류 표, MCP 도구 성공률 표"><figcaption>품질 · 지연. p95 는 '느린 쪽 5%를 뺀 가장 긴 시간'입니다.</figcaption></figure>

| 영역 | 뜻 |
|---|---|
| 기간 | **하루 · 7일 · 30일**. 오른쪽에 *내 기록만 표시* |
| **LLM 성공률** | 게이트웨이 요청 중 성공 비율(요청·오류·차단 수) |
| **응답 지연 p95** | 느린 요청 기준 응답 시간(p50 = 중간값, 첫 토큰 p95) |
| **도구 성공률** | MCP 도구 호출 성공 비율(차단 제외) |
| **에이전트 성공률** | 에이전트 실행 성공 비율(승인 대기 · A2A 로 불린 수) |
| **정책 차단** | 게이트웨이 차단 + 허브 정책 차단 건수 |
| **사용자 만족도** | 👍 / (👍+👎). 피드백이 없으면 - |
| **일별 LLM 요청** | 성공·차단·오류를 쌓은 막대(UTC) |
| **일별 응답 지연 p95** | 날마다의 p95 |
| **모델 별칭별 지연·오류** | 별칭 · 요청 · 오류율 · 차단 · p50 · p95 |
| **MCP 도구 성공률** | 도구 · 호출 · 성공률 · 차단 · p95 |
| **정책 차단** | 어디서(게이트웨이·허브) · 사유·정책 |
| **에이전트 실행** | 에이전트별 실행 · 성공 · 실패 · 승인 대기 · 평균 턴 |
| **사용자 피드백** | 채팅 답변·에이전트 실행·업무 흐름 개선 결과에 단 👍·👎 집계와 **최근 의견** |

> **참고** 기간이 길어 기록이 아주 많으면 최근 10만 건만 집계하고 아래에 안내가 나옵니다.
