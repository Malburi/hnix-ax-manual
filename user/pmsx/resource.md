# 인력 편성 · 작업 배분 · 작업일지

> 프로젝트 인원을 편성하고 투입 기간으로 월 MM을 계획하며, 미배정 작업을 사람에게 배정하고, 작업일지로 실적 MM을 모읍니다. **대상**: PM·PL(편성·배분·승인), 프로젝트 구성원(작업일지). **메뉴**: 인력·공수 › 인력 풀 · 인력 편성 / 투입 계획 · 작업 배분 · 작업일지 · MM 실적·정산.

| 메뉴 | 보는 사람 | 고치는 사람 |
|---|---|---|
| 인력 풀 · 인력 편성 / 투입 계획 | 시스템 관리자·PMO·PM·PL | 시스템 관리자·PM |
| 작업 배분 | PMO·PM·PL | PM·PL (PMO는 현황만) |
| 작업일지 | 내부 인력·협력사 (본인 것) | 본인 입력, 승인은 PM·PL |
| MM 실적·정산 | PMO·PM·PL | — |

## 인력 풀

<figure><img src="img/pmsx/u-resource-pool.png" alt="인력 풀 — 성명·소속·업체·등급·보유 기술·투입 프로젝트 목록"><figcaption>인력 풀 — 보유 기술 옆 숫자는 기술 수준(1 입문 ~ 5 전문가)</figcaption></figure>

1. **이름·업체 검색**, **기술로 찾기**, **소속**(자사·협력사·고객), **등급**으로 거릅니다.
2. **목록** 탭은 사람별 보유 기술과 **투입 프로젝트**, **스킬 매트릭스** 탭은 사람 × 기술 표입니다.
3. (편집 권한) 행을 누르면 **인력 정보** 창이 열립니다. **기술 추가**로 기술과 **수준**(1~5)을 넣고 저장합니다.

## 인력 편성 / 투입 계획

<figure><img src="img/pmsx/u-resource-plan.png" alt="인력 편성(MM) 탭 — 성명·등급·역할·투입 기간과 월별 MM 표, 인원 추가·투입 기간으로 모두 채우기·저장 버튼"><figcaption>인력 편성(MM) — 인원·투입 기간·월 MM을 한 표에서. 진하게 표시된 열이 이번 달</figcaption></figure>

| 영역 | 하는 일 |
|---|---|
| 머리 버튼 | **엑셀 내보내기** · **엑셀 가져오기**(투입 계획 가져오기) |
| **계획 합계 n MM** | 표 전체 합 |
| **인원 추가** | 프로젝트 인원을 추가(사용자·프로젝트 역할·투입일·철수일) |
| **투입 기간으로 모두 채우기** | 모든 사람의 월 MM을 투입 기간으로 다시 계산 |
| 행 끝 아이콘 | ✎ **참여 정보 수정** · ✨ **투입 기간으로 MM 채우기** · 👤✕ **참여 제외** |
| **초기화 · 저장** | 표 변경 되돌리기 / 저장 |

### 인원 추가하고 MM 채우기

1. **인원 추가**를 누릅니다.
2. **사용자**(이름·아이디로 검색), **프로젝트 역할**, **투입일**, **철수일**을 넣고 **저장**합니다. 투입일·철수일은 프로젝트 기간으로 미리 채워져 있습니다.
3. 표에 그 사람이 추가되고, 투입 기간의 **영업일 비율**로 월 MM이 자동으로 채워집니다(1.0 = 한 달 전일 투입). 예: 한 달 영업일 20일 중 10일 투입이면 0.5.
4. 필요하면 칸을 눌러 직접 고칩니다(0 ~ 1.5).
5. **저장**을 누릅니다.

### 투입 기간을 바꾼 뒤 다시 채우기

1. 행의 ✎를 눌러 **투입일·철수일**을 고치고 저장하면 그 사람의 MM이 다시 채워집니다.
2. 여러 사람을 한꺼번에 다시 계산하려면 **투입 기간으로 모두 채우기** → **채우기**를 누릅니다. 이미 입력한 월 MM이 계산값으로 바뀝니다.
3. 확인하고 **저장**합니다.

> **참고** 투입일이 비어 있으면 첫 달 1일부터, 철수일이 비어 있으면 마지막 달 말일까지 투입한 것으로 봅니다. 공휴일(공통코드 HOLIDAY)과 주말은 영업일에서 빠집니다.

> **주의** **참여 제외**는 프로젝트 인원에서 빼는 일입니다. 같은 일을 **관리 › 프로젝트 관리**에서도 합니다.

### 투입 계획률(MM 기준)

<figure><img src="img/pmsx/u-resource-heatmap.png" alt="투입 계획률(MM 기준) 탭 — 인력별 월 투입 계획률, 구간별 색과 100% 초과(과배정) 칸 강조"><figcaption>투입 계획률(MM 기준) — 100%를 넘는 칸이 과배정</figcaption></figure>

1. **투입 계획률(MM 기준)** 탭을 엽니다. 월 계획 MM을 비율로 바꾼 값입니다(1.0 MM = 100%). 작업 배분 화면의 작업 배정률과는 기준이 다릅니다.
2. **월 / 주**로 단위를 바꿉니다.
3. **다른 프로젝트 배정 포함**을 켜면 그 사람이 다른 프로젝트에 배정된 양까지 합쳐 봅니다. 100%를 넘으면 과배정으로 표시됩니다.

## 작업 배분

<figure><img src="img/pmsx/u-resource-assign.png" alt="작업 배분 — 왼쪽 미배정 작업(WBS 작업·화면 분석 탭), 오른쪽 작업 배정률(작업 기준) 46주~51주"><figcaption>작업 배분 — 미배정 화면 분석 12건과 앞으로 6주 배정률</figcaption></figure>

| 영역 | 하는 일 |
|---|---|
| **미배정 작업** | **WBS 작업** · **화면 분석** 탭(숫자는 건수), **작업명·WBS 번호 검색** |
| **작업 배정률(작업 기준)** | 앞으로 6주의 주별 배정률 — 계획 기간이 겹치는 WBS 작업의 배정 비율을 더한 값. 다른 프로젝트 배정도 포함. 월 MM 기준 투입 계획률은 투입 계획 화면에서 봅니다. 고객 담당자는 일을 배정받지 않으므로 목록에 나오지 않습니다 |

1. 미배정 작업을 오른쪽 사람 행으로 끌어 놓습니다. 또는 작업 오른쪽 배정 아이콘을 누르거나 작업에서 `Enter`.
2. **작업 배정** 창에서 **담당자**와 **배정률**(10~100%)을 정합니다.
3. 배정하면 작업 기간 중 배정률이 100%를 넘을 경우 "배정하면 작업 기간 중 배정률이 최대 n%가 됩니다(100% 초과)."가 미리 보입니다.
4. **배정**을 누릅니다. 과배정이 생기면 "배정했지만 과배정 기간이 생겼습니다."가 뜹니다 — 오른쪽 작업 배정률 표를 확인하세요.

> **참고** 화면 분석 작업을 배정하면 그 화면의 분석 담당이 됩니다. 담당 일괄 배정은 [분석 진척 현황](/user/pmsx/asis.md#분석-진척-현황)에서도 합니다.

## 작업일지

<figure><img src="img/pmsx/u-resource-timesheet.png" alt="작업일지 — 내 작업일지·승인함 탭, 주 이동, 작업 대상별 요일 시간 표"><figcaption>작업일지 — 하루 단위로 기록하고 주 단위로 제출</figcaption></figure>

**내 작업일지 쓰기**

1. **인력·공수 › 작업일지**를 엽니다. 이번 주가 열려 있습니다(**이전 주 · 다음 주 · 이번 주**로 이동).
2. **작업 추가**를 누르고 **작업 대상**을 고릅니다.
   - **WBS** — **WBS 작업**에서 고름(★는 내가 담당인 작업)
   - **화면 분석** — 예: `HR0101 사원관리 분석`
   - **서비스 요청** — 예: 요청 번호
   - **기타** — 예: 주간회의·보고
3. 요일 칸에 시간을 넣습니다(0~24). 맨 아래 **합계**가 하루 12시간을 넘으면 빨갛게 표시되고 제출할 수 없습니다.
4. **저장**으로 중간 저장, 주가 끝나면 **제출**을 누릅니다.
5. 상태가 **작성 중 → 제출 → 승인**으로 바뀝니다. **반려**되면 "반려됨: (사유) — 고쳐서 다시 제출하세요."가 보입니다.

**승인함** (PM·PL)

1. **승인함** 탭에서 제출된 작업일지를 봅니다(사람·주·합계 시간).
2. **승인** 또는 **반려**를 누릅니다. 반려는 **반려 사유**를 적습니다. 반려하면 본인에게 알림이 갑니다.

> **참고** 서비스 요청 상세의 **작업일지에 입력**을 누르면 이 화면으로 옵니다.

## MM 실적·정산

<figure><img src="img/pmsx/u-resource-mm.png" alt="MM 실적·정산 — 협력사 정산 카드와 사람별 월 계획·실적 MM 표"><figcaption>MM 실적·정산 — 빨간 숫자는 계획의 90% 미만</figcaption></figure>

- **월별 계획·실적 MM**: 사람별·월별 계획과 실적, **합계**, **실적률**. 위에 `계획 n / 실적 n MM`.
- 실적은 **승인된 작업일지 시간**으로 계산합니다(168시간 = 1 MM). 승인 전 시간은 들어가지 않습니다.
- **협력사 정산**: **정산 월**을 고르면 업체별·사람별 실적 MM이 보이고, **엑셀 내보내기**로 내려받습니다.
