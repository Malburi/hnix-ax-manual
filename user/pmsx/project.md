# 프로젝트 일정 — WBS · 칸반 · 주간보고

> SI 프로젝트의 계층 WBS를 표에서 바로 고치고 간트로 일정을 조정하며, 칸반으로 일감 단계를 옮기고, 베이스라인과 비교하고, 주간보고를 만들어 제출합니다. **대상**: PM·PL(편집), 프로젝트 구성원(조회). **메뉴**: 일정 (WBS) › WBS / 간트 · 칸반 · 베이스라인 비교 · 주간보고 (SI 프로젝트에서만 보임).

## WBS / 간트 화면 구성

<figure><img src="img/pmsx/u-project-wbs.png" alt="WBS / 간트 — 위쪽 진척 요약, 도구 모음, 왼쪽 계층 표(WBS·작업명·시작·종료·기간·선행·가중치·진척·계획·준수율·담당·상태)와 오른쪽 간트 막대"><figcaption>WBS / 간트 — 왼쪽 표, 오른쪽 간트</figcaption></figure>

| 영역 | 하는 일 |
|---|---|
| 머리 버튼 | **엑셀 내보내기** · **생성·가져오기**(PM·PL) · **베이스라인 저장**(PM) |
| 진척 요약 | **계획 · 실적 · SPI · 공정준수율 · 지연 작업**, 준수 등급별 개수(양호·보통·미흡·착수지연·종료지연), **진척 S-curve** 펼치기 |
| 도구 모음 | **작업 추가 · 하위 추가** · 내어쓰기 · 들여쓰기 · 위로 · 아래로 · **선후행 · 담당자 · 삭제**, **주/월**, **베이스라인 · 크리티컬 패스** 표시, **초기화 · 저장** |
| 공정 보기 줄 | **기준일**, **백업 일시(베이스라인)**, **마일스톤** 필터, **나의 액티비티 · 종료 액티비티 숨김 · 충돌 액티비티** |
| 표 | **WBS · 작업명 · 시작 · 종료 · 기간 · 선행 · 가중치 · 진척 · 계획 · 준수율 · 담당 · 상태** |
| 간트 | 작업(진척) 막대 · 크리티컬 패스 · 베이스라인 · 마일스톤 · 기준일 선 |
| 표·간트 경계 | 세로 막대를 끌어 표 폭을 조절 |

> **참고** 표에서 바꾼 내용은 **저장**을 눌러야 서버에 반영됩니다. 저장 전에는 "저장하지 않은 변경이 있습니다"가 보이고, **초기화**로 되돌릴 수 있습니다. 저장하지 않고 다른 화면으로 가려 하면 확인 창이 뜹니다.

## WBS 만들기

1. **생성·가져오기**를 누르고 고릅니다.
   - **방법론 템플릿으로 생성** — **방법론 템플릿**과 **시작일**을 고르고 **생성**. 단계·작업·필수 산출물이 들어옵니다.
   - **엑셀에서 가져오기** — 엑셀 파일을 올리고 **검증** → **n행 반영**.
   - **MS Project XML 가져오기** — **MS Project XML 파일**을 고르고 **가져오기**.
2. **기존 WBS 지우고 새로 만들기**를 체크하지 않으면 기존 WBS 뒤에 단계가 추가됩니다.

빈 표에 엑셀·메모장 목록을 바로 붙여 넣어도 됩니다(아래 [엑셀 붙여넣기](#엑셀·메모장에서-붙여넣기)).

## 표에서 바로 고치기

| 칸 | 넣는 법 |
|---|---|
| **작업명** | 바로 입력. 마지막 행 작업명에서 `Enter`를 누르면 아래에 새 작업이 생깁니다 |
| **시작 · 종료** | 날짜 선택. 시작을 바꾸면 기간을 유지한 채 종료일이 다시 계산됩니다 |
| **기간** | 영업일 수(주말·공휴일 제외). 바꾸면 종료일이 다시 계산됩니다. `0`이면 마일스톤 |
| **선행** | 선행 작업 WBS 번호. 예: `1.2`(끝나면 시작), `1.3SS+2`(시작 2일 뒤 시작). 쉼표로 여러 개 |
| **가중치 · 진척** | 숫자 |
| **담당** | 칸의 이름이나 **+ 지정**을 눌러 프로젝트 인원 중에서 고름 |
| **상태** | **대기 · 진행 · 완료 · 막힘** |

- 상위 작업(단계)은 시작·종료·기간이 하위에서 계산되어 입력칸이 없습니다.
- `Enter`는 같은 칸의 아래 행, `Shift+Enter`는 위 행으로 갑니다. `Esc`는 칸 입력을 취소합니다.
- 선행 칸 형식은 `WBS번호[유형][±일]`입니다. 유형: **FS** 끝나면 시작 · **SS** 같이 시작 · **FF** 같이 종료 · **SF** 시작하면 종료.

| 선행 칸 오류 | 뜻 |
|---|---|
| 선행 칸에 없는 WBS 번호가 있습니다. | 번호를 확인 |
| 자기 자신을 선행 작업으로 둘 수 없습니다. | 자기 번호 제거 |
| 선후행 관계에 순환이 생겼습니다. | 순환을 없애야 저장됩니다 |

**선후행 창으로 고치기**: 행을 고르고 **선후행** → **선행 작업 · 유형 · 지연(일)**을 넣고 **선행 추가** → 닫고 **저장**.

## 여러 행 한꺼번에 편집하기

<figure><img src="img/pmsx/u-project-wbs-multi.png" alt="WBS 표에서 1.2.1~1.2.3과 2.2 네 행을 고른 상태, 도구 모음에 '4개 선택' 칩"><figcaption>Shift 클릭으로 범위, Ctrl 클릭으로 한 행씩 더해 4개 행을 고른 상태</figcaption></figure>

1. 행의 WBS 번호를 누르면 그 행이 선택됩니다.
2. `Shift`+클릭은 마지막으로 고른 행부터 범위를, `Ctrl`+클릭은 한 행씩 더하거나 뺍니다. 도구 모음에 **n개 선택**이 보입니다(✕로 해제).
3. 고른 행에 한 번에 적용합니다.

| 하고 싶은 일 | 버튼 | 키 |
|---|---|---|
| 들여쓰기(한 단계 아래로) | 들여쓰기 아이콘 | `Alt+Shift+→` |
| 내어쓰기(한 단계 위로) | 내어쓰기 아이콘 | `Alt+Shift+←` |
| 위·아래로 이동 | 위로 / 아래로 | `Alt+Shift+↑` / `Alt+Shift+↓` |
| 같은 담당자 지정 | **담당자** → "담당자 — 작업 n개에 같이 지정" | — |
| 삭제(하위 작업 포함) | **삭제** | — |

4. **저장**을 누릅니다.

> **참고** 키는 MS Project와 같습니다. 칸에 입력 중이어도 `Alt+Shift+화살표`를 누르면 입력이 먼저 반영되고 구조가 바뀝니다.

## 엑셀·메모장에서 붙여넣기

1. 엑셀이나 메모장에서 작업 목록을 여러 줄 복사합니다.
2. WBS 표의 **작업명 칸**을 누르거나(그 행 아래에 들어감), 빈 표를 누르고 `Ctrl+V`를 누릅니다.
3. "붙여 넣은 작업을 추가했습니다. 확인 후 저장하세요."가 뜨면 확인하고 **저장**합니다.

| 붙여 넣는 줄 모양 | 처리 |
|---|---|
| 줄 앞의 탭(엑셀에서 비워 둔 앞 칸) 또는 공백 2개 | 한 단계 하위 작업 |
| 첫 칸이 `1.2.1` 같은 WBS 번호 | 번호의 깊이로 단계를 정함 |
| 날짜 칸 1~2개 (`2026-11-02`, `2026.11.02`) | 시작일 · 종료일 |
| 작업명 뒤의 숫자 | 기간(영업일) |
| 날짜·기간이 없음 | 고른 행의 시작일(없으면 오늘)부터 5영업일 |

> **참고** 첫 줄이 0단계가 되도록 맞추고, 한 번에 두 단계 이상 깊어지지 않게 다듬어 넣습니다.

## 간트에서 일정 바꾸기

- 막대를 끌면 일정이 이동하고, 양 끝을 끌면 기간이 바뀝니다. 키보드는 막대에서 `←/→`(이동), `Shift+←/→`(기간).
- **주/월**로 눈금을 바꿉니다. **베이스라인**을 켜면 막대 아래에 저장한 계획이, **크리티컬 패스**를 켜면 그 경로가 강조됩니다.
- 표와 간트는 위아래 스크롤이 함께 움직입니다. 경계 막대를 끌거나 경계에서 `←/→`로 표 폭을 바꿉니다(브라우저에 기억).

## 공정준수율 보기

| 항목 | 뜻 |
|---|---|
| **기준일** | 계획 진척을 계산할 날짜(비우면 오늘) |
| **백업 일시(베이스라인)** | 비교할 베이스라인(기본 **최신 베이스라인**) |
| **계획 · 준수율** 열 | 기준일의 계획 진척과 실적 대비 준수율. 100% 이상 양호, 95% 이상 보통, 95% 미만 미흡, 착수지연·종료지연 |
| **충돌 액티비티** | 선후행 관계와 일정이 맞지 않는 작업만 보기(달력일 기준) |

필터를 켜면 **필터 해제** 버튼이 생깁니다.

## 베이스라인 저장과 비교

1. WBS 화면에서 **베이스라인 저장**(PM)을 누릅니다.
2. **베이스라인 이름**(예: 설계 단계 재계획 승인본)을 넣고 저장합니다. 지금 WBS 일정이 그대로 저장됩니다.
3. **일정 (WBS) › 베이스라인 비교**를 엽니다.

<figure><img src="img/pmsx/u-project-baseline.png" alt="베이스라인 비교 — 베이스라인 선택, 종료 지연·앞당김·최대 지연 칩, 작업별 베이스라인과 현재 계획·시작/종료 차이 표"><figcaption>베이스라인 비교</figcaption></figure>

4. **베이스라인**을 고릅니다. 위에 **종료 지연 n건 · 앞당김 n건 · 최대 지연 n일**이 보입니다.
5. **변경된 작업만**을 켜면 날짜가 달라진 작업만 남습니다. 표의 **시작 차이(일) · 종료 차이(일)**와 **비교** 막대로 확인합니다.

## 칸반

<figure><img src="img/pmsx/u-project-kanban.png" alt="칸반 — 작업·이슈·결함·변경요청 유형 칩, 업무 칩(분석·설계·구현·시험·이행), 등록·진행·보류·검토·완료 열과 카드"><figcaption>칸반 — WBS 작업·이슈·결함·변경요청을 한 보드에서</figcaption></figure>

| 영역 | 하는 일 |
|---|---|
| **조회** · **내 일감만** | 제목 검색, 내 담당만 |
| 유형 칩 | **작업 · 이슈 · 결함 · 변경요청** 보이기/숨기기 |
| 업무 칩 | **전체 · 분석 · 설계 · 구현 · 시험 · 이행 · 업무 미지정** |
| 열 | 프로젝트 워크플로우 단계(기본 등록 · 진행 · 보류 · 검토 · 완료). 어느 단계에도 없는 상태는 **미분류** 열 |
| 카드 | 유형·번호·기한, 제목, 담당, 상태, 업무 |

1. 카드를 다른 열로 끌어 놓으면 단계(상태)가 바뀝니다. 키보드는 카드에서 `Alt+←/→`.
2. 카드를 누르거나 `Enter`를 누르면 **일감 상세** 패널이 열립니다 — 담당자·계획일자·현재상태·업무·처리 이력·산출물·상세·댓글, **원본 화면**으로 이동.

| 끌어 놓을 수 없을 때 | 뜻 |
|---|---|
| 이 단계에는 이 유형의 일감을 둘 수 없습니다. | 그 열에 해당 유형 상태가 없음 |
| 현재 상태에서 이 단계로 옮길 수 없습니다 (전이 규칙). | 결함·변경요청은 정해진 순서로만 |
| 담당자를 먼저 지정해야 옮길 수 있습니다. | 담당 지정 후 다시 |

**워크플로우 설정** (시스템 관리자·PM·PL): 칸반 열이 될 단계(순서·단계명·색)와 단계마다 유형별 상태를 정합니다. 단계는 20개까지, **기본값으로**로 되돌립니다.

## 주간보고

<figure><img src="img/pmsx/u-project-weekly.png" alt="주간보고 생성 창 — 보고 주 선택"><figcaption>주간보고 생성 — 보고 주의 아무 날이나 고르면 월요일 기준으로 만듭니다</figcaption></figure>

1. **일정 (WBS) › 주간보고**에서 **주간보고 생성**(PM·PL)을 누릅니다.
2. **보고 주**를 고르고 **생성**을 누릅니다. WBS·작업일지·이슈·리스크·MM에서 초안이 자동으로 채워집니다.
3. 왼쪽 목록에서 보고서를 열고 고칩니다.

| 보고서 영역 | 내용 |
|---|---|
| 요약 | 계획 · 실적 · **전주 대비** · **투입 MM(실적/계획)** · **As-Is 분석 확정** |
| **총평** | 이번 주 진행 상황과 주요 사항(직접 작성) |
| **금주 실적 · 차주 계획** | WBS 작업(번호·작업명·담당·진척)과 **비고** 칸 |
| **주요 이슈 · 주요 리스크(9점 이상)** | 자동 집계 |

4. **저장**으로 중간 저장, **제출**로 확정합니다. 제출하면 더 이상 고칠 수 없습니다.
5. **엑셀 내보내기**에서 **기본 양식** 또는 **고객사 템플릿**으로 내려받습니다.

> **주의** 같은 주의 보고서는 하나만 만들 수 있습니다("해당 주 보고서가 이미 있습니다.").
