# PMS-X 화면 구성과 역할

> PMS-X(1.3.13)에 로그인해 프로젝트를 고르고, 내 역할에 맞는 메뉴로 일을 시작합니다. **대상**: PMS-X를 쓰는 모든 사람(PM·PL·분석 담당·개발자·품질 담당·운영 담당·협력사·고객). **메뉴**: 상단 바 · 왼쪽 메뉴 · 홈.

PMS-X는 SI(구축)와 SM(운영) 프로젝트를 한곳에서 관리하는 웹 시스템입니다. 레거시 화면의 버튼이 어떤 함수·API·SQL·테이블로 이어지는지 보여 주는 **As-Is 분석**과, 일정·인력·품질·서비스 요청을 같은 화면 자산에 묶어 관리합니다.

## 로그인

<figure><img src="img/pmsx/u-readme-login.png" alt="PMS-X 로그인 화면 — 아이디·비밀번호 입력칸과 로그인 버튼"><figcaption>로그인 화면</figcaption></figure>

1. 관리자가 알려 준 PMS-X 주소를 브라우저(Chrome·Edge)로 엽니다.
2. **아이디**와 **비밀번호**를 넣고 **로그인**을 누릅니다. 회사 계정(LDAP·AD)으로 연동된 경우에는 회사 계정 비밀번호를 씁니다.
3. 고객 역할만 가진 계정은 **고객 요청 창구**로, 나머지는 **홈**으로 들어갑니다.

| 화면에 보이는 말 | 뜻과 할 일 |
|---|---|
| 아이디 또는 비밀번호가 올바르지 않습니다. | 다시 입력합니다. 대소문자를 확인하세요. |
| 로그인 5회 실패로 계정이 잠겼습니다. | 관리자에게 잠금 해제를 요청합니다. |
| 라이선스가 유효하지 않아 로그인할 수 없습니다. | 시스템 관리자에게 알립니다(이때는 시스템 관리자만 로그인할 수 있습니다). |

> **참고** 비밀번호는 오른쪽 위 이름 › **비밀번호 변경**에서 바꿉니다. 9자 이상이고 영문·숫자·특수문자 중 3종류를 섞어야 합니다.

## 화면 구성

<figure><img src="img/pmsx/u-readme-home.png" alt="PMS-X 홈 — 상단 바의 프로젝트 선택·검색·알림, 왼쪽 메뉴, 진척·SPI·미해결 이슈 카드"><figcaption>PM 계정으로 본 SI 프로젝트 홈</figcaption></figure>

| 영역 | 하는 일 |
|---|---|
| ☰ (메뉴 펼치기/접기) | 왼쪽 메뉴를 아이콘만 보이게 접거나 펼칩니다. ERD·화면 분석 뷰어처럼 넓은 화면은 처음부터 접혀 열립니다. |
| 프로젝트 선택 | `[SI] ○○공사 차세대 SI`처럼 유형과 이름이 보입니다. 바꾸면 메뉴와 모든 화면이 그 프로젝트 기준으로 바뀝니다. |
| 검색창 (`Ctrl K`) | 통합 검색. 두 글자 이상 넣으면 결과가 뜹니다. |
| 종 모양 | 알림. 빨간 숫자는 안 읽은 알림 수입니다. |
| **테마** | 화면 테마를 고릅니다: **선명한 업무형**(기본) · **부드러운 카드형** · **고대비 네이비** · **HNIX 아이덴티티** · **사용자 지정**. |
| 달 모양 | 밝은/어두운 테마 전환. |
| 이름 | 내 역할 확인, **알림 설정**, **비밀번호 변경**, **로그아웃**. |
| 왼쪽 메뉴 | 프로젝트 유형과 내 역할에 맞는 메뉴만 보입니다(아래 표). |

## 프로젝트 고르기

<figure><img src="img/pmsx/u-readme-project.png" alt="상단 프로젝트 선택 목록 — [SI] ○○공사 차세대 SI와 [SM] ○○공사 인사시스템 운영(SM)"><figcaption>프로젝트 선택 — 내가 참여한 프로젝트만 보입니다</figcaption></figure>

1. 상단 왼쪽 **프로젝트** 칸을 누릅니다.
2. 일할 프로젝트를 고릅니다. 고른 프로젝트는 다음에 로그인해도 기억됩니다.

> **참고** 프로젝트가 목록에 없으면 아직 그 프로젝트의 참여 인원이 아닙니다. PM에게 인원 추가를 요청하세요. 화면에 "상단에서 프로젝트를 먼저 선택하세요."가 보이면 프로젝트를 고르면 됩니다.

### SI와 SM에 따라 달라지는 메뉴

| 메뉴 | SI 프로젝트 | SM 프로젝트 |
|---|---|---|
| 일정 (WBS) — WBS / 간트 · 칸반 · 베이스라인 비교 · 주간보고 | 보임 | 안 보임 |
| 산출물·추적성 › 감리 체크리스트, 품질 › 테스트 | 보임 | 안 보임 |
| 운영 — 서비스 요청 · 장애 · 문제 · 변경·배포 등(SM 프로젝트는 맨 위 홈·공지사항 바로 아래에 펼쳐져 보임) | 안 보임 | 보임 |
| 관리 › 처리 기한 정책·업무 캘린더 | 안 보임 | 보임 |

## 역할별로 보이는 메뉴

프로젝트 역할은 PM이 **관리 › 프로젝트 관리**에서 정합니다. 역할 이름은 화면에 프로젝트 관리자(PM) · 파트 리더(PL) · 분석 담당 · 개발자 · 품질 담당 · 운영 담당 · 협력사 · 고객 담당자로 보입니다.

| 메뉴 | PM·PL | 분석 담당·개발자·품질 담당 | 운영 담당 | 협력사 | 고객 담당자 |
|---|---|---|---|---|---|
| 홈 · 공지사항 · 프로젝트 위키 | ○ | ○ | ○ | ○ | 고객 요청 창구만 |
| As-Is 분석 (화면 분석 뷰어 등) | ○ | ○ | ○ | 허용된 시스템·메뉴만 | — |
| 일정 (WBS) › 주간보고 | ○ | — | — | — | — |
| 인력·공수 › 인력 풀 · 인력 편성 / 투입 계획 · 작업 배분 · MM 실적·정산 | ○ | — | — | — | — |
| 인력·공수 › 작업일지 | ○ | ○ | ○ | ○ | — |
| 운영 (SM 프로젝트) | ○ | ○ | ○ | — | — |
| 관리 › 프로젝트 관리 · 감사 로그 · 라이선스·시스템 정보 | PM만 | — | — | — | — |
| 관리 › 방법론 템플릿 · 공통코드·용어 · 엑셀 양식 연결 | PM만(방법론·공통코드·용어는 조회만) | — | — | — | — |
| 관리 › 처리 기한 정책·업무 캘린더 (SM) | PM만 | — | 조회 | — | — |
| 오른쪽 위 이름 › 알림 설정 | ○ | ○ | ○ | ○ | — |

<figure><img src="img/pmsx/u-readme-home-op.png" alt="운영 담당 계정으로 본 SM 프로젝트 홈 — 운영 현황·응답 기한 준수율·만료 임박 자산·정기 작업·열린 경보·문제 후보 카드와 맨 위의 운영 메뉴"><figcaption>운영 담당 계정의 SM 프로젝트 홈 — 처리 기한 준수율과 진행 중 요청</figcaption></figure>

> **참고** 메뉴가 보여도 버튼은 역할에 따라 다릅니다. 예를 들어 WBS 편집은 PM·PL, 분석 화면 **확정**은 PM·PL, 작업일지 **승인함**은 PM·PL만 씁니다. 권한이 없는 작업을 하면 "이 작업을 할 권한이 없습니다."가 나옵니다.

> **참고** 사용자 계정·시스템 역할·프로젝트 생성은 관리자 일입니다. [PMS-X 관리 개요](/admin/pmsx/README.md)를 보세요.

## 홈

홈 오른쪽 위에서 보기를 바꿉니다.

| 보기 | 보이는 것 |
|---|---|
| **PM** | 진척(실적)·계획 대비 차이, 일정 성과 지수(SPI), 미해결 이슈·결함, 이번 달 투입 공수(M/M), 공지사항, 진척 곡선, 다가오는 마일스톤, 주요 리스크, 산출물 현황, As-Is 분석 확정, 공정현황·업무별 공정준수율, 이슈현황, 일감진척현황, 일감진행추이 |
| **고객** | PM 보기에서 이번 달 MM 카드·공지사항·공정현황(일감 보드)을 뺀 요약. 고객 담당자에게 보여 줄 때 씁니다 |
| **포트폴리오** | 시스템 관리자·PMO만. 전체 프로젝트의 진척·위험 상태. 행을 누르면 그 프로젝트로 이동 |

SM 프로젝트의 홈 첫 카드는 **운영 현황**(이번 달 처리 기한 준수율 · 진행 중 요청 · 처리 기한 임박 · 지금 기한 초과(미종료 전체) · 진행 중 장애)입니다. 옆에 **이번 달 응답 기한 준수율 · 만료 임박 자산 · 오늘 남은 정기 작업 · 열린 경보 · 문제 후보** 카드가 붙습니다. 카드의 **자세히**를 누르면 해당 화면으로 갑니다.

## 통합 검색

1. 상단 검색창을 누르거나 `Ctrl K`를 누릅니다.
2. 두 글자 이상 입력합니다(예: `TB_EMP`, `급여`).
3. 결과를 고르면 해당 화면으로 갑니다.

| 결과 종류 | 열리는 화면 |
|---|---|
| 요구사항 · WBS · 이슈 · 결함 · 변경요청 · 산출물 · 회의록 · 테스트 | 각 메뉴 화면 |
| 테이블 · 컬럼 | As-Is 분석 › 테이블 정의서(그 테이블 선택) |
| DB 오브젝트(프로시저·트리거 등) | As-Is 분석 › DB 오브젝트 |
| 화면 | As-Is 분석 › 화면 분석 뷰어(그 화면) |
| 서비스 요청 · 지식 문서 | 운영 › 서비스 요청 · 지식 문서 |

> **참고** 검색창은 화면 폭이 좁으면 숨겨집니다. 화면 안의 버튼·함수까지 찾으려면 [화면 분석 뷰어의 검색](/user/pmsx/asis.md#화면-찾기)을 씁니다.

## 알림

<figure><img src="img/pmsx/u-readme-notify.png" alt="종 모양을 눌러 연 알림 목록 — 처리 기한 초과 알림들과 모두 읽음·설정 버튼"><figcaption>알림 목록 — 누르면 해당 화면으로 이동</figcaption></figure>

1. 상단 종 모양을 누릅니다.
2. 알림을 누르면 관련 화면이 열리고 읽음으로 바뀝니다.
3. **모두 읽음**으로 한꺼번에 읽음 처리합니다.
4. **설정**을 누르면 **알림 설정** 화면으로 갑니다.

### 받을 알림 정하기

<figure><img src="img/pmsx/u-readme-notify-settings.png" alt="알림 설정 화면 — 받는 곳(화면 알림·메일·메신저 웹훅)과 알림 받을 일 목록"><figcaption>오른쪽 위 이름 › 알림 설정 — 내 알림만 바뀝니다</figcaption></figure>

1. 오른쪽 위 이름을 눌러 **알림 설정**을 엽니다(종 모양 알림 목록의 **설정**으로도 갑니다).
2. **받는 곳**에서 **화면 알림** · **메일** · **메신저 웹훅**을 고릅니다.
3. **알림 받을 일**에서 받을 항목을 켜고 끕니다: 작업 배정 · 검토 요청 · 승인 · 반려 · 기한 임박(이틀 전) · 기한 지남 · 결함 배정 · 이슈 상위 보고 · 작업일지 반려 · 언급 · 위키 수정.
4. **저장**을 누릅니다.

> **참고** 메일은 서버에 메일 설정이 있을 때만, 메신저 웹훅은 관리자가 사내 메신저를 등록했을 때만 갑니다. 화면 알림은 늘 종 모양에 쌓입니다.

## 엑셀 내려받기·올리기

- 대부분의 목록 화면 오른쪽 위에 **엑셀 내보내기**가 있습니다. 누르면 **기본 양식**과, 관리자가 등록한 **고객사 템플릿**이 보입니다.
- **엑셀 가져오기**가 있는 화면(WBS·투입 계획·공통코드 등)은 파일을 올리고 **검증** → **n행 반영** 순서로 넣습니다. 오류 행은 빼고 정상 행만 반영되며, 검증 후 10분이 지나면 다시 검증해야 합니다.

## 그 밖의 메뉴

이 매뉴얼의 PMS-X 쪽이 다루지 않는 메뉴의 쓰임새입니다(화면 안내 문구 기준).

| 메뉴 | 하는 일 |
|---|---|
| 공지사항 | 프로젝트 구성원에게 알리는 공지. 등록은 PM·PL·시스템 관리자 |
| 산출물·추적성 › 산출물 대장 | 단계별 산출물 등록, 검토·승인. 승인되면 연결된 WBS 작업이 완료 |
| 산출물·추적성 › 요구사항 · 추적성 매트릭스 | 요구사항을 화면·테스트·결함·변경요청과 연결하고 누락 확인 |
| 산출물·추적성 › 감리 체크리스트 (SI) | 감리 점검 항목별 대응 산출물과 준비 상태 |
| 프로젝트 위키 | 산출물·업무 지식 문서 |
| 품질 › 이슈 · 리스크 · 변경요청(CR) · 테스트 · 결함 · 회의록·의사결정 | 품질 관리. 테스트 실패 케이스에서 바로 결함 등록 |

## 자주 묻는 질문

**Q. 메뉴가 동료보다 적어요.** 프로젝트 역할이 다르거나, 다른 유형(SI/SM)의 프로젝트를 고른 상태입니다. 상단 프로젝트를 확인하고, 필요하면 PM에게 역할 변경을 요청하세요.

**Q. 고객인데 왼쪽 메뉴가 없어요.** 고객 역할만 있는 계정은 **고객 요청 창구** 한 화면만 씁니다. [고객 요청 창구](/user/pmsx/sr.md#고객-요청-창구-고객용)를 보세요.
