# 설치 · 로그인 · 기기 승인

> 개인 PC 에 AX-NAVI IDE 를 깔고, 회사 HNIX AX 플랫폼에 이 PC 를 승인받아 쓰기 시작합니다. **대상**: 개발자·운영 개발자. **메뉴**: 플랫폼 왼쪽 메뉴 › 내 연결 설정 · IDE 상태 표시줄의 AX-NAVI 항목.

AX-NAVI IDE 는 **플랫폼에서 승인받은 기기에서만** 동작합니다. 로그인하기 전에는 AI 채팅, 슬래시 명령, 변경 리뷰·보안 점검·단계 게이트가 모두 잠겨 있습니다. 로그인하면 플랫폼이 스킬·판정 엔진·사내 모델 연결을 이 PC 에 내려 주므로, 키나 환경 변수를 손으로 넣을 일이 없습니다.

## 준비

| 항목 | 기준 |
|---|---|
| 운영체제 | Windows 10/11 64비트 |
| 디스크 | 여유 2GB |
| 권한 | PC 관리자 권한은 필요 없습니다(내 계정에 설치) |
| 회사 플랫폼 | 플랫폼 주소(예 `http://ax.corp.local:8700`)와 내 계정 — 관리자에게 받습니다 |
| AX-NAVI 사용 허가 | 관리자가 플랫폼에서 나에게 허가(좌석)를 줘야 로그인됩니다 |
| 함께 있으면 좋은 것 | Git for Windows(변경 리뷰에 필요), Claude 구독(Pro·Max·Team·Enterprise) |

> **참고** Node.js, Python, AX-NAVI CLI 는 따로 깔지 않습니다. 판정 엔진은 로그인하면 플랫폼이 내려 주고, 스킬이 쓰는 Python 도 IDE 안에 들어 있습니다.

| 영역 | 하는 일 |
|---|---|
| **1 개인 PC 설치** | **개인 PC 설치 파일 〈판〉 받기** — 회사 코드 서명이 된 설치 파일(`HNIX-AX-PC-Setup-<판>.exe`)을 내려받습니다 |
| **2 이 서버에 연결** | **AX-NAVI IDE 에서 열기** — 설치된 IDE 를 열어 이 플랫폼 주소로 연결합니다. 플랫폼 주소와 **복사** 버튼도 있습니다 |
| **3 확인** | 연결한 내 기기 목록. **새로 고침**, **내 기기 관리**(내 AX-NAVI 기기 화면으로) |

## 1. 설치 파일 받기

1. 브라우저로 회사 플랫폼에 로그인합니다.
2. 왼쪽 메뉴 **내 연결 설정**을 엽니다.
3. **1 개인 PC 설치**에서 **개인 PC 설치 파일 〈판〉 받기**를 누릅니다. 브라우저가 바로 내려받습니다.

> **참고** 관리자가 설치 파일을 따로 나눠 줬다면 그 파일을 써도 됩니다. 같은 파일입니다.

## 2. 설치

`HNIX-AX-PC-Setup-<판>.exe` 를 실행합니다.

| 설치 화면 | 할 일 |
|---|---|
| 설치 위치 | 기본값 `%LOCALAPPDATA%\Programs\AX-NAVI IDE` 그대로 둡니다 |
| 추가 작업 | 바탕 화면 바로가기, 터미널 명령 `axnavi-ide`(PATH 추가) 중 원하는 것만 고릅니다 |
| 회사 플랫폼 연결 | '내 연결 설정'에 보이는 플랫폼 주소를 넣습니다. 비워 두면 IDE 를 처음 열 때 묻습니다 |

설치가 끝나면 AX-NAVI IDE 가 열립니다. 설정·확장은 `%USERPROFILE%\.axnavi-ide`, `%APPDATA%\AX-NAVI IDE` 에 따로 저장되므로 쓰던 VS Code 와 섞이지 않습니다.

> **주의** 설치 파일이나 IDE 가 실행되자마자 사라지면 사내 보안 프로그램이 막은 것입니다. 직접 예외를 걸지 말고 관리자에게 알리세요([개인 PC 배포](/admin/install-pc.md)).

## 3. 플랫폼에 연결하고 로그인

IDE 를 처음 열면 상황에 따라 오른쪽 아래에 안내가 뜹니다. 셋 중 하나로 시작하면 됩니다.

| 이렇게 보이면 | 할 일 |
|---|---|
| `AX-NAVI — <주소> 에 로그인해 이 PC 를 승인받으세요.` | **로그인**을 누릅니다 |
| `AX-NAVI 를 쓰려면 회사 HNIX AX 플랫폼에 연결하세요…` | **연결**을 누르고, 입력창에 플랫폼 주소를 넣습니다 |
| 안내를 닫았거나 놓쳤다 | 상태 표시줄 왼쪽의 **AX-NAVI 연결** 또는 **AX-NAVI 로그인**을 누릅니다 |

웹에서 시작해도 됩니다.

1. 플랫폼 **내 연결 설정** › **2 이 서버에 연결** › **AX-NAVI IDE 에서 열기**를 누릅니다.
2. IDE 가 `이 플랫폼에 연결할까요?` 와 주소를 보여 줍니다. 회사에서 안내한 주소가 맞는지 확인하고 **연결**을 누릅니다.

> **주의** 처음 보는 주소로 연결하라는 링크는 **연결**하지 마세요. 연결한 서버가 판정 엔진을 내려 주기 때문입니다. 관리자가 PC 정책으로 주소를 고정해 둔 PC 는 링크의 주소를 쓰지 않고 그 사실을 알립니다.

## 4. 브라우저에서 이 기기 승인

연결하거나 **로그인**을 누르면 IDE 알림에 승인 코드가 나오고 브라우저가 열립니다.

- IDE 알림: `AX-NAVI 로그인 — 브라우저에서 코드 BCDF-GHJK 를 확인하고 승인하세요`
- 브라우저가 열리지 않으면 알림 아래에 나오는 주소를 직접 엽니다.

1. 플랫폼에 로그인돼 있지 않으면 평소 계정으로 로그인합니다.
2. 승인 화면에서 **승인 코드**가 IDE 알림의 코드와 같은지 확인합니다. 계정, 기기 이름·운영체제, 프로그램과 판, 요청 주소, 만료 시각도 함께 보입니다.
3. **이 기기 승인**을 누릅니다. 내가 시작하지 않은 요청이면 **거절**을 누릅니다.
4. 몇 초 안에 IDE 에 `AX-NAVI 로그인 완료 — 이름(아이디) · 기기. 사내 모델·MCP 허브 설정을 받았습니다.` 가 뜹니다.
5. 처음이면 `AX-NAVI 엔진 준비 중 — 처음 한 번 플랫폼에서 받습니다` 가 잠깐 돕니다.

> **참고** 승인 코드는 **10분** 안에 승인해야 합니다. 지나면 IDE 에서 다시 로그인합니다.

> **주의** 승인 화면에 `AX-NAVI 사용 허가가 없습니다. 관리자에게 허가를 요청하세요.` 가 나오거나 **이 기기 승인** 버튼이 눌리지 않으면, 허가가 없거나 기기 수(기본 2대)를 넘은 것입니다. 허가는 관리자에게 요청하고, 기기 수는 아래 '내 기기 끊기'로 정리합니다.

### 승인 코드를 손으로 넣기

브라우저가 다른 PC 에 열렸을 때처럼 승인 화면이 바로 뜨지 않으면, 플랫폼 **내 연결 설정** › **내 AX-NAVI 기기** 탭의 **AX-NAVI 기기 연결** 칸에 승인 코드를 넣고 **확인**을 누릅니다. 같은 승인 화면이 나옵니다.

## 5. 로그인 상태 확인

<figure><img src="img/axnavi/chat-welcome.png" alt="AX-NAVI IDE 전체 화면 — 왼쪽 탐색기, 가운데 편집기와 아래 점검 결과·상세 칸, 오른쪽 AX-NAVI 채팅 첫 화면(나침이 인사와 예시 요청 버튼), 맨 아래 상태 표시줄의 리뷰 STOP과 AX-NAVI · 이개발"><figcaption>로그인한 IDE. 상태 표시줄(맨 아래 왼쪽)에 변경 리뷰 판정과 <code>AX-NAVI · 내 이름</code>이 뜹니다.</figcaption></figure>

상태 표시줄 왼쪽의 AX-NAVI 항목으로 지금 상태를 압니다. 바로 옆의 **리뷰** 항목은 변경 리뷰 버튼입니다.

| 상태 표시줄 | 뜻 | 누르면 |
|---|---|---|
| 플러그 아이콘 `AX-NAVI 연결` (노란 배경) | 플랫폼 주소가 없습니다 | 주소 입력창 |
| 자물쇠 아이콘 `AX-NAVI 로그인` (노란 배경) | 로그인 전이거나 잠겼습니다 | **로그인** · **다른 플랫폼 주소로 연결** · **상태 보기** |
| 사람 아이콘 `AX-NAVI · 내 이름` | 로그인됨 | **상태 보기** · **지금 다시 확인** · **키 다시 받기 (사내 모델·MCP 허브)** · **로그아웃** |
| 사람 아이콘 `AX-NAVI · 내 이름 (오프라인)` | 플랫폼에 잠시 닿지 않아 받아 둔 것으로 쓰는 중 | 위와 같음 |

**상태 보기**를 고르면 창에 다음이 나옵니다. 명령 팔레트(`Ctrl+Shift+P`) › **AX-NAVI: 계정·사용 허가 상태**도 같습니다.

| 줄 | 내용 |
|---|---|
| 사용 허가 | 이름 · 기기 · PC 엔진/서버 엔진 |
| 플랫폼 | 연결된 플랫폼 주소 |
| 사용자 · 기기 | 로그인 아이디, 기기 이름 |
| 엔진 | 엔진이 어디서 도는지(PC 또는 서버) |
| 토큰 만료 | 사용권 토큰 만료 시각. 오프라인이면 `…까지 캐시로 씁니다` |

> **참고** 엔진이 **서버 엔진**으로 나오면 관리자가 '서버만' 좌석으로 정한 것입니다. 이때는 단계 게이트·환경 점검과 일부 스킬을 쓸 수 없습니다([변경 리뷰와 보안 점검](/user/axnavi/review.md) 참고).

## 로그인하면 자동으로 설정되는 것

| 무엇 | 어디에 | 하는 일 |
|---|---|---|
| 사내 모델 | AI 연결 프로필 `사내 게이트웨이` | 구독이 없어도 사내 모델로 채팅·코드 작업(비용은 조직) |
| MCP 허브 `hnix-ax` | 채팅의 MCP 서버 | 지식 문서·매뉴얼·서비스 요청·에이전트를 채팅에서 도구로 |
| 사용량 기록 | 플랫폼 AI 사용 현황 | 작업 요약(시간·결과·토큰, 본문 없음) |
| 스킬·판정 엔진 | IDE 안 | `/find` 같은 스킬, 변경 리뷰·보안 점검·색인 |
| Claude Code(PC 에 있으면) | `~/.claude/settings.json`, `~/.claude.json` | 사용량 전송과 MCP 허브 `hnix-ax` — 터미널의 Claude Code 에서도 같은 도구 |

연결 키는 이 PC 의 보안 저장소에만 들어갑니다. Claude Code 쪽 자동 설정을 끄려면 설정 `axnavi.claudeCode.autoConfigure` 를 끕니다.

## 잠기는 때

| 상황 | IDE |
|---|---|
| 로그인 전 | 모델 호출, 슬래시 명령, 리뷰·점검·게이트 모두 잠김 |
| 관리자가 허가를 회수 | 토큰을 새로 받을 때(기본 1시간 안) 잠기고, 받아 둔 스킬·엔진을 지움 |
| 내가 또는 관리자가 이 기기를 끊음 | 그 기기만 잠김 |
| **AX-NAVI: 로그아웃 (이 기기 승인 지우기)** | 이 기기 승인과 받아 둔 스킬·엔진·연결을 지움 |
| 플랫폼에 오래 닿지 않음 | 플랫폼이 정한 기간(기본 3일)이 지나면 다시 닿을 때까지 잠김 |

## 내 기기 끊기

1. 플랫폼 **내 연결 설정** › **내 AX-NAVI 기기** 탭을 엽니다.
2. **내 AX-NAVI 기기** 목록에서 쓰지 않는 기기의 **끊기**를 누르고 확인합니다.
3. 그 기기의 AX-NAVI 는 바로 잠깁니다.

## 판 올리기 · 옮기기 · 지우기

| 할 일 | 방법 |
|---|---|
| 새 판으로 | 새 `HNIX-AX-PC-Setup` 을 실행해 덮어 설치합니다(주소·로그인 유지) |
| 다른 플랫폼으로 | 명령 팔레트 › **AX-NAVI: 플랫폼 주소를 바꿔 로그인** — 관리자가 주소를 고정한 PC 에서는 바뀌지 않습니다 |
| 연결 키 새로 받기 | 상태 표시줄 AX-NAVI › **키 다시 받기 (사내 모델·MCP 허브)** — 지난 키는 꺼집니다 |
| 로그아웃 | 상태 표시줄 AX-NAVI › **로그아웃** |
| 제거 | Windows '앱 및 기능' › AX-NAVI IDE |

> **주의** 예전에 손으로 넣은 환경 변수(`HNIX_AX_*`, `AXNAVI_OPENAI_*`, `AXNAVI_AUTH`)가 있으면 그 값이 먼저 쓰입니다. 새로 받은 연결을 쓰려면 지웁니다.

## 자주 묻는 질문

| 증상 | 확인 |
|---|---|
| `AX-NAVI: <주소> 에 닿지 않습니다` | 이 PC 브라우저에서 `http://<플랫폼>/healthz` 가 열리는지 봅니다. 사내망(VPN)·프록시 예외를 확인합니다. **다른 주소**로 다시 넣을 수 있습니다 |
| '사용 허가가 없습니다' | 관리자에게 AX-NAVI 허가를 요청합니다 |
| '기기는 2대까지입니다' | **내 AX-NAVI 기기**에서 안 쓰는 PC 를 끊습니다 |
| 승인 코드가 만료됨 | IDE 에서 다시 **로그인** |
| 채팅에 허브 도구가 안 보임 | 상태 표시줄 AX-NAVI › **키 다시 받기** |
| 폴더를 열었더니 점검 결과에 '제한 모드라 AX-NAVI 가 꺼져 있습니다' | 믿을 수 있는 폴더면 **이 폴더 신뢰하고 AX-NAVI 켜기**를 누릅니다 |

플랫폼 주소는 PC 공용 정책(`%ProgramData%\axnavi\policy.json` 의 `platform`) → 설정 `axnavi.platform.url` → 환경 변수 `HNIX_AX_SERVER` → 설치할 때 넣은 주소 순서로 정해집니다.
