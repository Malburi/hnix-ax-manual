# 사용자 매뉴얼 안내

> 화면을 쓰는 사람을 위한 매뉴얼입니다. 관리자가 만들어 준 계정으로 로그인한 뒤, 하고 싶은 일의 쪽을 찾아 따라 하세요. **대상**: 시스템 관리자가 아닌 모든 사용자.

## 시작 전에 받을 것

관리자에게 아래를 받으세요.

| 무엇 | 예 |
|---|---|
| 제품별 접속 주소 | 플랫폼 `http://ax.회사.local:8700`, PMS-X `http://ax.회사.local:8080` |
| 아이디와 처음 비밀번호 | 처음 로그인한 뒤 바로 바꿉니다 → [로그인과 화면 공통 사용법](/user/login.md) |
| (개발자) AX-NAVI 사용 허가 | 허가가 있어야 IDE 가 로그인됩니다 → [설치 · 로그인 · 기기 승인](/user/axnavi/install.md) |
| (PMS-X) 프로젝트 멤버 등록 | 멤버가 아니면 그 프로젝트가 보이지 않습니다 |

## 알아 두면 좋은 것

- **권한대로 보입니다.** 같은 화면이라도 역할에 따라 탭·버튼이 다릅니다. 매뉴얼에서 "관리자만" 이라고 적힌 기능은 [관리자 매뉴얼](/admin/README.md)에 있습니다.
- **AI 답은 근거와 함께 확인하세요.** 채팅·창구·에이전트의 답에는 근거 문서 번호가 붙습니다. 번호를 눌러 원문을 확인한 뒤 쓰세요.
- **개인정보는 가려져 나갑니다.** 게이트웨이가 주민번호·전화번호 같은 정보를 가린 뒤 모델에 보내고, 기밀 등급 데이터는 사내 모델로만 갑니다. 그래도 비밀번호·인증 정보는 대화에 적지 마세요.
- **내 기록은 나와 관리자만 봅니다.** 채팅 대화는 나만 보고, 사용량은 팀 단위로 묶어 보입니다(관리자·감사자는 전체).
- 화면이 매뉴얼과 다르거나 오류가 나면 화면 이름·시각·무엇을 눌렀는지 적어 관리자에게 알려 주세요.
