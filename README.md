# HNIX AX 매뉴얼

HNIX AX 제품을 **실제로 쓰는 사람**과 **설치·운영하는 관리자**를 위한 매뉴얼입니다. 화면마다 무엇이 있고, 어떤 순서로 누르면 되는지 그림과 함께 안내합니다.

> 제품 소개·시연 영상·구조 설명은 [HNIX AX 소개 사이트](https://malburi.github.io/hnix-ax-site/)에 있습니다. 이 매뉴얼은 "이 일을 하려면 어디를 누르나"에 답합니다.

## 어느 매뉴얼을 보면 되나요

| 나는 | 먼저 볼 곳 |
|---|---|
| 개발자·운영자·분석가 — 화면을 쓰는 사람 | [사용자 매뉴얼 안내](/user/README.md) → [로그인과 화면 공통 사용법](/user/login.md) |
| 현업 직원 — 시스템 사용 중 궁금한 것을 묻는 사람 | [현업 창구 — 현업 직원용](/user/platform/desk.md) |
| PM·PL — 프로젝트 일정·인력·보고를 맡은 사람 | [PMS-X 화면 구성과 역할](/user/pmsx/README.md) |
| 시스템 관리자 — 설치·계정·연동·정책을 맡은 사람 | [관리자 매뉴얼 안내](/admin/README.md) |
| 처음이라 제품 이름부터 낯설다 | [제품 구성과 역할별 길잡이](/guide.md) · [용어 모음](/glossary.md) |

## 제품과 이 매뉴얼의 판

| 제품 | 하는 일 | 판 |
|---|---|---|
| **AX Platform** | 회사의 모든 AI 호출·도구 호출이 지나는 공통 기반 — 모델 게이트웨이, MCP 허브, 에이전트, 업무 자동화, 문서 검색, 현업 창구, 사용 현황 | 0.9.2 |
| **PMS-X** | SI·SM 프로젝트 관리 — 일정·인력·서비스 요청·지식 문서, As-Is 화면·DB 분석, 인수인계 | 1.3.14 |
| **AX-NAVI IDE** | 개발자 PC 의 AI 코딩 도구 — 회사 플랫폼에 로그인해 사내 모델·도구·스킬을 씁니다 | 1.2.8 |
| **AX-DataLake** | 회사 데이터를 모아 찾고 묻는 레이크하우스 — 카탈로그·질의·온톨로지·계보·거버넌스 | 0.5.3 |

화면이 판마다 조금씩 다를 수 있습니다. 화면과 매뉴얼이 다르면 관리자에게 설치된 판을 확인하세요(각 제품 화면 아래쪽이나 관리 화면에 판이 표시됩니다).

## 매뉴얼 읽는 법

- **굵은 글자**는 화면에 보이는 버튼·메뉴·탭 이름 그대로입니다.
- `왼쪽 메뉴 › AI 사용 현황 › 품질 · 지연` 처럼 `›` 는 차례로 누르는 순서입니다.
- 그림을 누르면 크게 볼 수 있습니다(다시 누르거나 Esc 로 닫기).
- 왼쪽 위 **매뉴얼 검색** 칸에 화면 이름이나 하고 싶은 일(예: "비밀번호", "승인")을 넣으면 해당 쪽을 찾아 줍니다.
- 그림 속 이름·데이터(○○공사, 김개발 등)는 시연용 가상 데이터입니다.
