# 에이전트 · 트리거 관리

> 플랫폼 에이전트를 정의·공유 승인하고, ITO 기본 에이전트와 외부 에이전트를 들이고, 웹훅·예약·감시 트리거로 사람 대신 깨웁니다. **대상**: 시스템 관리자. **메뉴**: 에이전트·자동화 › 에이전트.

## 화면 구성

<figure><img src="img/platform/a-agents.png" alt="에이전트 화면 — 왼쪽 위 에이전트 실행 카드(ITO 기본 에이전트·외부 에이전트 가져오기·새 에이전트 버튼, 에이전트 고르기, 수정·평가), 오른쪽 실행 결과, 가운데 트리거 카드(웹훅 모니터링 경보), 아래 실행 기록 표"><figcaption>관리자에게 보이는 에이전트 화면 — 가운데 '트리거' 카드는 시스템 관리자만 보입니다</figcaption></figure>

| 영역 | 하는 일 | 권한 |
|---|---|---|
| **ITO 기본 에이전트** | 통합ITO 운영 에이전트 템플릿 설치 | 시스템 관리자 |
| **외부 에이전트 가져오기** | A2A·LangGraph·OpenAI 호환·일반 HTTP 에이전트 등록 | 설정에 따라 누구나 또는 관리자만 |
| **새 에이전트** | 지시문·모델·도구로 에이전트 정의 (사용자에게는 **내 에이전트 만들기**) | 누구나 |
| 에이전트 고르기 · **수정** · **평가** | 고른 에이전트 고치기, [에이전트 평가](/user/platform/eval.md)로 가기 | 수정은 만든 사람과 시스템 관리자 |
| 실행 결과 · 실행 기록 | 실행·결과 확인 | 누구나(관리자는 전체 실행) |
| **트리거 — 사람 대신 깨우기** | 고른 에이전트의 웹훅·예약·감시 | 시스템 관리자 |

에이전트를 실행하고 결과·단계를 보는 방법은 [에이전트 실행과 내 에이전트](/user/platform/agents.md)를 보세요.

## 에이전트 정의 · 수정

1. **새 에이전트**를 누르거나, 에이전트를 고르고 **수정**을 누릅니다.
2. 칸을 채웁니다.

| 칸 | 내용 |
|---|---|
| 이름 | 영문 소문자·숫자·하이픈(예: `sr-helper`). 만든 뒤에는 바꿀 수 없습니다 |
| 모델 별칭 | 게이트웨이의 켜진 대화 별칭 |
| 설명 · 지시문(시스템 프롬프트) | 지시문은 필수 |
| 쓸 수 있는 도구 | 허브 도구 이름 패턴(예: `pmsx__*`, `docs__search`). 기본값은 `docs__search`, `pmsx__*` |
| 최대 턴 | 1~30 |
| 사용 | 끄면 목록에 `(꺼짐)` 으로 남고 실행할 수 없습니다 |
| 자세히 기록 (디버그) | 켜면 모든 실행의 단계 본문을 개인정보를 가려 보존 기한 동안 보관 |
| 누가 쓰나 | 관리자는 **나만** · **공개 (워크스페이스)** |
| A2A 로 외부 공개 | 관리자만. 다른 플랫폼의 에이전트가 이 에이전트를 부를 수 있음 |

3. **저장**합니다. 창 왼쪽 아래 **지우기**는 에이전트와 연결된 트리거를 함께 지웁니다.

> **참고** 실행은 **실행한 사람 권한**으로 돕니다. 그 사람에게 보이지 않는 도구는 패턴에 있어도 쓰지 못하고, 승인 정책에 걸리면 멈춥니다.
> **참고** A2A 공개를 켜면 카드 주소(`…/a2a/<이름>/.well-known/agent-card.json`)가 보입니다. 부르는 쪽에는 `a2a` 권한 키가 필요하고, 키 주인 권한으로 실행됩니다.
> **참고** 자세히 기록의 보존 일수는 서버 설정 `agents.debugRetentionDays`(기본 7일)입니다. 본문은 실행한 사람과 관리자·감사자만 봅니다.

## 공유 요청 승인

사용자가 만든 에이전트에서 **팀에 공유 요청 (관리자 승인)** 을 고르면 목록에 `· 공유 요청 중` 이 붙습니다.

1. 에이전트 고르기 목록에서 `공유 요청 중` 인 에이전트를 고릅니다.
2. 노란 안내 상자에서 지시문·도구를 확인합니다(필요하면 **수정**).
3. **공개 승인**(워크스페이스 사람들이 실행 가능) 또는 **돌려보내기**(만든 사람만 봄)를 누릅니다.

자동화 흐름의 공유 요청도 같은 방법으로 흐름 편집기에서 결정합니다([자동화 흐름](/admin/platform/automation.md#공개와-공유-승인)).

## ITO 기본 에이전트 설치

<figure><img src="img/platform/a-agents-templates.png" alt="ITO 기본 에이전트 창 — 경보 진단(웹훅·설치됨), 서비스 요청 분류 보조(감시·새 요청 감시), 변경 영향 리포트(웹훅·CI 변경 알림), 주간 운영보고 초안(예약·매주 월요일 08:00) 카드"><figcaption>ITO 기본 에이전트 — 설치하면 트리거까지 함께 만들어집니다</figcaption></figure>

| 템플릿 | 트리거 | 하는 일 | 필요 |
|---|---|---|---|
| 경보 진단 | 웹훅 · 모니터링 경보 | 비슷한 과거 장애·서비스 요청·지식 문서와 운영 매뉴얼로 원인 후보와 확인 순서 정리 | PMS-X 커넥터, 문서 RAG 운영 매뉴얼 |
| 서비스 요청 분류 보조 | 감시 · 새 요청 감시 | 새 요청의 유형·우선순위·대상 화면·담당 후보 의견 | PMS-X 커넥터 |
| 변경 영향 리포트 | 웹훅 · CI 변경 알림 | 변경 내용으로 영향받는 화면·SQL·테이블과 볼 테스트 정리 | AX-NAVI 커넥터, PMS-X 커넥터 |
| 주간 운영보고 초안 | 예약 · 매주 월요일 08:00 | 처리 기한 현황과 요청 현황으로 보고 초안 | PMS-X 커넥터 |

1. **ITO 기본 에이전트**를 누릅니다.
2. 카드의 **설치**를 누르면 입력 칸이 열립니다.
3. **모델 별칭**을 고르고, **PMS-X SM 프로젝트 ID**(PMS-X 프로젝트 ID, `pmsx__projects` 도구로 확인)를 넣습니다.
4. **설치**를 누릅니다. 웹훅 템플릿이면 **웹훅 연결 정보** 창에 주소와 토큰이 **한 번만** 보입니다 — 모니터링 도구·CI 설정에 바로 넣으세요.

> **참고** 템플릿 도구는 모두 읽기 전용이고, 조치는 사람에게 제안만 합니다. 이미 설치한 템플릿은 `설치됨` 으로 표시되고 다시 설치할 수 없습니다.

## 외부 에이전트 가져오기

<figure><img src="img/platform/a-agents-external.png" alt="외부 에이전트 가져오기 창 1단계 — 종류·주소·인증·연결 시험·이름·공개 범위 4단계 표시와 A2A 에이전트·LangGraph 서버·OpenAI 호환 채팅·일반 HTTP 네 가지 선택 상자"><figcaption>외부 에이전트 가져오기 — 4단계로 등록합니다</figcaption></figure>

다른 프레임워크로 만든 에이전트를 플랫폼 에이전트(`외부` 종류)로 등록합니다. 등록하면 실행 기록, 흐름의 '에이전트 실행' 노드, 에이전트 평가, MCP `agents__run` 에서 다른 에이전트처럼 씁니다.

1. **외부 에이전트 가져오기**를 누릅니다.
2. **종류** — A2A 에이전트 · LangGraph 서버 · OpenAI 호환 채팅 · 일반 HTTP 중 고르고 **다음**.
3. **주소·인증**

| 칸 | 내용 |
|---|---|
| 주소 | `http(s)://` 주소 |
| LangGraph | 어시스턴트(그래프) 이름 또는 ID, 대화마다 스레드로 이어 묻기 |
| OpenAI 호환 | model 값(서버가 요구할 때만) |
| 일반 HTTP | 요청 본문 템플릿(JSON, `{{input}}` 자리에 질문), 응답에서 답을 꺼낼 경로(예: `data.answer`) |
| 인증 | 없음 · Bearer 토큰 · API 키 머리글(머리글 이름) + 비밀값 |
| 시간 제한 (초) | 1~600 |
| 사내 주소만 허용 | 기본 켜짐. **끄면 사외 주소도 부릅니다(관리자만)** |

4. **연결 시험** — 작은 입력으로 한 번 불러 답을 꺼낼 수 있는지 봅니다(저장하지 않음). `연결됨 · N초` 또는 실패 이유가 나옵니다.
5. **이름·공개 범위** — 이름, 설명, 사용, 누가 쓰나, 자세히 기록, (관리자) A2A 로 다시 공개를 정하고 **가져오기**를 누릅니다.

> **주의** 외부 에이전트가 모델을 직접 부르면 플랫폼의 예산·개인정보 보호를 거치지 않습니다. 외부 에이전트에는 게이트웨이 가상 키(`hx-`)를 주고 모델 주소를 플랫폼의 `/v1` 로 두게 하세요.
> **참고** 비밀값은 시크릿 저장소에 보관하고 다시 보여 주지 않습니다. 고칠 때 비워 두면 기존 값을 유지합니다.
> **참고** 누가 가져올 수 있는지는 서버 설정 `agents.externalImport` 로 정합니다(`all` = 누구나 '내 에이전트'로, `admin` = 관리자만). 설정 파일은 [운영](/admin/operations.md)을 보세요.

외부 에이전트를 고르면 **수정** 대신 같은 창이 2단계(주소·인증)부터 열립니다.

## 트리거 — 웹훅 · 예약 · 감시

에이전트를 고르면 아래 **트리거 — 사람 대신 깨우기** 카드에 그 에이전트의 트리거가 보입니다.

<figure><img src="img/platform/a-agents-trigger-edit.png" alt="트리거 추가 창 — 종류(웹훅)·이름·실행 계정, 에이전트에 줄 입력 템플릿, 중복 키·중복 무시(분)·시간당 최대 실행, 결과 알림 주소·알림 형식, 사용 스위치"><figcaption>트리거 추가 창</figcaption></figure>

### 트리거 추가

1. **트리거 추가**를 누릅니다.
2. **종류**를 고릅니다(만든 뒤에는 바꿀 수 없음).

| 종류 | 깨우는 때 | 추가 칸 | 입력 자리표시 |
|---|---|---|---|
| 웹훅 — 경보·CI 가 부름 | 외부 시스템이 웹훅 주소를 부를 때 | 없음(저장하면 주소·토큰 발급) | `{{body}}`, `{{body.필드}}` |
| 예약 — cron | 정한 시각 | cron(분 시 일 월 요일, 서버 현지 시간). 예: `0 8 * * 1` = 매주 월요일 08:00 | `{{now}}` |
| 감시 — 새 항목마다 | 읽기 도구 결과에 새 항목이 생길 때 | 감시할 허브 도구(읽기 전용), 도구 인자(JSON), 목록 위치, 항목 ID 필드, 간격(분), 한 번에 최대 | `{{item}}`, `{{item.필드}}` |

3. 공통 칸을 채웁니다.

| 칸 | 내용 |
|---|---|
| 이름 | 예: 모니터링 경보 |
| 실행 계정 (비우면 나) | 이 계정 권한으로 실행. 그 계정의 예산·개인정보 규칙·도구 정책이 그대로 걸립니다 |
| 에이전트에 줄 입력 | 자리표시를 넣은 지시 문장 |
| 중복 키 · 중복 무시 (분) | 예: `{{body.alertId}}` 가 같으면 N분 동안 한 번만 |
| 시간당 최대 실행 | 1~600 |
| 결과 알림 주소 · 알림 형식 | Teams·Slack 수신 웹훅 등(선택), 형식 Teams · Slack · JSON |
| 사용 | 끄면 깨우지 않습니다 |

4. **저장**합니다. 웹훅이면 **웹훅 토큰 — 지금 한 번만 보입니다** 창에 주소, 토큰, 시험용 curl 예시가 나옵니다.

> **참고** 감시 트리거는 처음 감시할 때 이미 있는 항목을 기준선으로만 기록하고 깨우지 않습니다.
> **참고** 승인이 필요한 도구는 승인함에서 결정되면 자동으로 이어서 실행합니다. 경보 본문은 데이터로만 다루도록 지시문에 적어 두세요.
> **참고** 웹훅 토큰은 `X-HNIX-Token` 머리글, `Authorization: Bearer`, 또는 주소 뒤 `?token=` 으로 보냅니다.

### 트리거 줄의 버튼

| 버튼 | 하는 일 |
|---|---|
| **지금 실행** | 시험 본문(`{test: true}`)으로 바로 한 번 깨웁니다. 실행되면 결과가 오른쪽에 열립니다 |
| **기록** | 깨운 기록 — 시각, 경로, 결과(`실행` · `건너뜀` · `한도` · `오류`), 실행 보기, 알림 결과, 중복 키·내용 |
| **토큰 재발급** | 웹훅만. 새 토큰을 한 번 보여 주고 옛 토큰은 못 쓰게 됩니다 |
| **수정** | 설정 변경. 결과 알림 주소는 비워 두면 기존 주소를 유지합니다 |
| **삭제** | 트리거와 깨운 기록을 지웁니다 |

줄 아래에 웹훅 주소(또는 cron·다음 시각, 감시 도구·간격·본 항목 수), 마지막 깨운 시각과 결과, 시간당 최대, 중복 규칙이 보입니다. 실행 기록 표에서 트리거로 돈 실행에는 `트리거` 꼬리표가 붙습니다.

> **주의** 토큰을 잃어버리면 다시 볼 수 없습니다. **토큰 재발급** 후 외부 시스템 설정을 새 토큰으로 바꾸세요.
