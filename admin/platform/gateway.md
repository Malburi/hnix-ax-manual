# LLM 게이트웨이 설정

> 사내 모든 AI 호출이 지나는 관문을 설정합니다 — 개인정보 보호 규칙, 경로 규칙·예산, 모델 별칭, 모델 연결, 요청 로그. **대상**: 시스템 관리자(설정), 감사자(조회). **메뉴**: AI 통제 › LLM 게이트웨이.

## 화면 구성

<figure><img src="img/platform/a-gateway-overview.png" alt="LLM 게이트웨이 개요 탭 — 위에 개요·내 키·개인정보 보호·경로 규칙 · 예산·모델 별칭·모델 연결·요청 로그 탭, 6단계 흐름 상자(상자마다 열기), 가운데 오늘 요청·토큰·비용·개인정보 처리·정책 차단·평균 응답 타일, 아래 모델 연결 상태·모델 별칭·설정 점검 카드"><figcaption>개요 탭 — 흐름 그림, 오늘 수치, 모델 연결 상태, 설정 점검</figcaption></figure>

화면 위의 탭으로 오갑니다. 주소 뒤에 `?tab=` 을 붙여 바로 열 수도 있습니다(예: `/gateway?tab=pii`).

| 탭 | 하는 일 | 보이는 사람 |
|---|---|---|
| **개요** | 흐름 그림, 오늘 수치(0시부터), 모델 연결 상태, **설정 점검**, 시험 호출 | 모두(관리자는 전체 수치) |
| **내 키** | `hx-` 키 발급·폐기. 관리자·감사자는 **전체 보기** 스위치로 모든 사람의 키를 봅니다 | 모두 |
| **개인정보 보호** | 개인정보를 가리기·가명·차단·탐지만 | 시스템 관리자·감사자 |
| **경로 규칙 · 예산** | 조건에 따라 다른 별칭으로 돌리거나 막기, 기간별 한도 | 시스템 관리자·감사자 |
| **모델 별칭** | 사용자가 부르는 이름(별칭)과 실제 모델 연결, 폴백 순서 | 모두(추가·수정은 시스템 관리자) |
| **모델 연결** | 실제 모델이 있는 곳(모델 서버) 등록, 서버에 떠 있는 모델 불러오기 | 시스템 관리자·감사자 |
| **요청 로그** | 게이트웨이를 지난 요청 기록(본문 없음) | 모두(관리자·감사자는 전체) |

> **참고** 감사자는 모든 탭을 볼 수 있지만 **추가·수정·삭제** 버튼이 보이지 않습니다. 설정 변경은 시스템 관리자만 합니다.

`내 키` 탭과 키로 기존 앱을 연결하는 방법은 [LLM 게이트웨이 — 내 키와 모델](/user/platform/gateway.md)을 보세요.

## 처음 켤 때 — 개요의 설정 점검

개요 탭 오른쪽 **설정 점검** 카드는 처음 설치한 뒤 무엇이 비었는지 보여 줍니다. 줄을 누르면 해당 탭으로 갑니다.

| 점검 항목 | 완료 조건 | 고치는 탭 |
|---|---|---|
| 모델 연결 등록 | 켜진 모델 연결이 하나 이상 | 모델 연결 |
| 사내 로컬 모델 연결 | **사내 로컬** 로 표시한 연결이 켜져 있음 | 모델 연결 |
| 대화 모델 별칭 | 종류 '대화' 별칭이 하나 이상 | 모델 별칭 |
| 의미 검색 모델 별칭 | 종류 '의미 검색용' 별칭이 하나 이상(문서 의미 검색에 필요) | 모델 별칭 |
| 개인정보 규칙 켜기 | 켜진 규칙이 하나 이상 | 개인정보 보호 |
| 사내 모델로 보내는 경로 규칙 | '다른 모델로 보내기' 경로 규칙이 하나 이상 | 경로 규칙 · 예산 |
| 예산 한도 | 예산이 하나 이상 | 경로 규칙 · 예산 |
| 내 키 발급 | 내 키가 하나 이상 | 내 키 |

- 초록 ✓ 는 **완료**, 노란 ! 는 **할 일** 입니다.
- 위쪽 6단계 흐름 상자(앱·IDE·에이전트 → 개인정보 보호 → 경로 규칙·예산 → 모델 별칭 → 모델 연결 → 요청 로그·사용량)도 상자의 **열기**를 누르면 해당 탭으로 갑니다. 상자 아래 꼬리표에 지금 개수(예: `규칙 6개 켜짐`)가 보입니다.
- **모델 연결 상태** 카드는 최근 24시간 시도 기준으로 `정상` · `문제` · `기록 없음` · `꺼짐` 을 보여 주고, 문제가 있으면 마지막 오류 시각과 내용을 적습니다.

### 시험 호출

개요 맨 아래 **시험 호출** 카드에서 문장 하나를 실제로 보내 봅니다.

1. **모델 별칭**을 고르고, 필요하면 **데이터 등급**을 고릅니다(비우면 워크스페이스 기본).
2. 문장을 넣고 **보내기**를 누릅니다.
3. 오른쪽에 요청한 별칭, 찾은 개인정보, 경로 규칙으로 바뀐 별칭, 보낸 곳(사내/외부), 폴백, 걸린 시간·토큰, 모델로 나간 문장, 답이 나옵니다.

> **주의** 시험 호출도 실제 요청과 똑같이 기록·집계됩니다. 외부 모델이면 비용이 듭니다.

## 모델 연결 등록

<figure><img src="img/platform/a-gateway-providers.png" alt="모델 연결 탭 — 이름·형식·주소·위치·API 키·시간 제한·사용 열이 있는 표, 행마다 서버 모델·수정·삭제 버튼, 오른쪽 위 모델 연결 추가 버튼"><figcaption>모델 연결 탭 — 사내 로컬 모델 서버 두 곳이 등록된 모습</figcaption></figure>

1. **모델 연결** 탭에서 **모델 연결 추가**를 누릅니다.
2. 칸을 채웁니다.

| 칸 | 내용 |
|---|---|
| 이름 | 구분용 이름(예: `claude`, `local-vllm`) |
| 형식 | **Anthropic (Claude API)** 또는 **OpenAI 호환 (vLLM·Ollama 등)** |
| 주소 | 모델 서버 주소(예: `http://10.0.0.5:8000/v1`) |
| API 키 | 모델 회사 키. 로컬 모델은 비워도 됩니다. 수정할 때 비워 두면 기존 키를 유지합니다 |
| 사내 로컬 | 켜면 제한(restricted) 등급 데이터를 받을 수 있고 비용을 0으로 집계합니다 |
| 시간 제한(초) | 5~3600초. 기본 600초 |
| 사용 | 끄면 이 연결로 보내지 않습니다 |

3. **저장**을 누릅니다.

> **참고** API 키는 마스터키로 암호화해 저장하며 화면·API 어디에도 다시 표시하지 않습니다. 표의 **API 키** 칸에는 `등록됨` 만 보입니다.
> **주의** 행의 **삭제**는 연결과 저장된 API 키를 함께 지웁니다. 이 연결을 대상으로 쓰는 별칭은 `(삭제됨)` 으로 표시되니 먼저 별칭을 고치세요.

음성 인식·음성 합성 서버(사내 Whisper 계열 등)도 **OpenAI 호환** 형식으로 먼저 등록한 뒤 별칭을 만듭니다.

행의 **서버 모델**을 누르면 **서버 모델 불러오기** 창에 그 모델 서버에 지금 떠 있는 모델이 나옵니다. 골라서 **고른 모델을 별칭으로 추가**를 누르면 별칭이 생깁니다. 종류는 이름으로 짐작한 것이니 맞는지 보고 고치세요.

## 모델 별칭 만들기

클라이언트(앱·IDE·에이전트·PMS-X)는 별칭(예: `hnix-smart`)만 압니다. 실제 모델과 폴백 순서는 여기서 바꿉니다.

1. **모델 별칭** 탭에서 **별칭 추가**를 누릅니다(모델 연결이 하나도 없으면 눌리지 않습니다).
2. **별칭**, **종류**(대화 · 의미 검색용 · 음성 인식 · 음성 합성)를 정합니다.
3. **대상**에 모델 연결과 모델 이름(예: `qwen3-32b`)을 넣습니다. **+** 로 여러 줄을 두면 앞에서부터 시도하고 실패하면 다음으로 넘어갑니다(폴백).
4. **설명**, **사용**을 정하고 **저장**합니다.

- 표의 대상 꼬리표가 **초록**이면 사내 로컬, **파랑**이면 외부입니다.
- 문서함의 의미 검색에는 **의미 검색용** 별칭이, 현업 창구의 말로 묻기에는 **음성 인식** 별칭이 필요합니다.

> **참고** [모델 평가](/admin/platform/observe.md#모델-평가)의 **업무 별칭에 반영**을 쓰면 권장 모델의 대상이 업무 별칭으로 그대로 옮겨집니다.

## 경로 규칙

<figure><img src="img/platform/a-gateway-policies.png" alt="경로 규칙 · 예산 탭 — 위 경로 규칙 표(순서·이름·조건·동작·사용)와 시뮬레이터 줄, 아래 예산 표(이름·대상·기간·한도·이번 기간 사용·소진율·초과 시)"><figcaption>경로 규칙 · 예산 탭 — 위는 경로 규칙과 시뮬레이터, 아래는 예산</figcaption></figure>

순서가 작은 규칙부터 보고 **처음 맞는 규칙 하나만** 적용합니다.

1. **경로 규칙 · 예산** 탭의 **경로 규칙** 카드에서 **규칙 추가**를 누릅니다.
2. 조건을 정합니다. 비운 조건은 '상관없음'입니다.

| 칸 | 내용 |
|---|---|
| 이름 · 순서 | 순서 숫자가 작을수록 먼저 봅니다 |
| 데이터 등급 ≥ | **공개** < **사내** < **기밀** < **제한(사내 모델만)** (`public` < `internal` < `confidential` < `restricted`). 고른 등급 이상이면 맞음 |
| 개인정보 | 상관없음 · 포함된 요청 · 없는 요청 |
| 요청 모델 | 이 별칭으로 부른 요청만(여러 개 가능) |
| 워크스페이스 | 이 워크스페이스의 요청만 |
| 동작 | **다른 모델로 보내기**(→ 보낼 모델) 또는 **차단**(→ 안내 문구) |

3. **저장**합니다.

**시뮬레이터**로 저장한 규칙을 확인합니다 — 요청 모델·워크스페이스·데이터 등급·개인정보 여부를 고르고 **어디로 가나?** 를 누르면 최종 별칭, 맞은 규칙, 시도할 대상 순서가 나옵니다. `(등급상 차단)` 이 붙은 대상은 데이터 등급 때문에 건너뜁니다.

> **참고** 제한(restricted) 등급 데이터는 경로 규칙과 상관없이 **사내 로컬** 연결로만 갑니다.

## 예산

1. **예산** 카드에서 **예산 추가**를 누릅니다.
2. **이름**, **대상**(전체 · 워크스페이스 · 사용자), **기간**(월 · 일), **금액 한도($)** 와 **토큰 한도** 중 하나 이상, **초과 시 차단**을 정합니다.
3. **저장**합니다.

- 표의 **소진율** 막대는 80% 이상이면 노랑, 100%면 빨강입니다.
- **초과 시** 가 `차단` 이면 한도를 넘은 요청을 막고(요청 로그 결과 `차단`, 개요의 정책 차단에 `예산 초과`), `기록만` 이면 막지 않습니다.
- 예산은 화면에서 수정 버튼이 없습니다. 바꾸려면 지우고 다시 만듭니다.

게이트웨이를 지나는 모든 요청에 적용됩니다.

| 처리 | 동작 |
|---|---|
| 가명화(응답에서 복원) | 모델에는 `[전화번호_1]` 같은 토큰만 보내고, 응답이 오면 원래 값으로 되돌립니다 |
| 가리기(***) | `****` 로 가립니다(되돌리지 않음) |
| 요청 차단 | 해당 값이 있으면 요청을 막습니다 |
| 탐지만 | 바꾸지 않고 건수만 남깁니다 |

- **기본** 규칙 5개(주민등록번호 · 휴대폰·전화번호 · 카드번호 · 사업자등록번호 · 이메일)는 내장 탐지기(형식·체크섬 검사)를 씁니다. **처리** 를 바꾸거나 **사용** 을 끌 수 있지만 지울 수는 없습니다.
- 표의 **처리**·**사용**은 바꾸는 즉시 저장됩니다.

### 사용자 정의 규칙(정규식)

1. **사용자 정의 규칙**을 누릅니다.
2. **이름**(예: 사번), **정규식**(예: 사번이 `EMP` + 숫자 6자리면 `EMP\d{6}`), **처리**, **방향**(양방향 · 요청 · 응답)을 넣고 **저장**합니다.

### 규칙 시험

**규칙 시험(저장하지 않음)** 칸에 문장을 넣고 **시험**을 누르면 찾은 종류별 건수와 바뀐 문장이 나옵니다. 차단 규칙에 걸리면 차단 안내가 나옵니다.

## 요청 로그

요청·응답 본문은 저장하지 않습니다. 사용량·결과·개인정보 탐지 건수만 남깁니다.

| 열 | 내용 |
|---|---|
| 시각 · 사용자 · API | API 종류와 `스트림` 여부 |
| 모델 | 요청한 별칭 → 실제 모델 |
| 결과 | `성공` · `오류` · `차단` + HTTP 상태. 마우스를 올리면 오류 내용 |
| 입력/출력 · 비용 · 지연(첫 토큰) | |
| 개인정보 | 찾은 종류와 건수 |
| 폴백 | 2회 이상 시도했으면 횟수. 마우스를 올리면 시도 순서 |

오른쪽 위 **전체 결과** 목록으로 성공·오류·차단만 고르고, **새로 고침**으로 다시 읽습니다. 최근 300건, 쪽당 20건입니다.

## 자주 묻는 질문

**Q. 개요의 비용이 0원입니다.** 모든 요청이 사내 로컬 모델로 갔으면 0원입니다(사내 비율이 함께 표시됨). 외부 모델 비용은 [단가표](/admin/platform/observe.md#단가표)를 기준으로 계산합니다.

**Q. 기밀 문서가 외부 모델로 나가지 않게 하려면?** 경로 규칙에서 `데이터 등급 ≥ 기밀` → 사내 별칭으로 보내기를 두고, 문서함·워크스페이스의 데이터 등급을 맞게 정합니다.
