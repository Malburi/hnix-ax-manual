# 문서 컬렉션 관리

> 운영 매뉴얼·절차서를 담는 문서 컬렉션을 만들고, 데이터 등급·임베딩을 정하고, 새 판·옛 판을 정리합니다. 채팅·현업 창구·에이전트가 이 문서를 근거로 답합니다. **대상**: 시스템 관리자(모든 컬렉션), 워크스페이스 관리자·구성원(자기 워크스페이스). **메뉴**: AI 통제 › 문서 RAG.

## 화면 구성

<figure><img src="img/platform/a-docs.png" alt="문서 RAG 화면 — 위 검색 칸, 왼쪽 컬렉션 카드(운영 매뉴얼 · 기본 워크스페이스 · 문서 8 · 의미 검색(hnix-embed) · internal), 오른쪽 문서 표(제목·청크·크기·상태·올린 사람)와 빠진 임베딩 채우기·문서 올리기·컬렉션 삭제 버튼, 옛 판 꼬리표"><figcaption>문서 RAG — 컬렉션과 문서 목록. 같은 이름의 옛 문서에는 '옛 판' 꼬리표가 붙습니다</figcaption></figure>

| 영역 | 하는 일 |
|---|---|
| 검색 칸 | 질문이나 낱말로 찾기, 컬렉션 고르기(비우면 모든 컬렉션). 결과에 키워드·의미 순위가 나옵니다 |
| **컬렉션** 카드 | 컬렉션 목록 — 워크스페이스 · 문서 수 · 검색 방식(`의미 검색(별칭)` 또는 `키워드만`) · 데이터 등급. **새 컬렉션** |
| **문서 — <컬렉션>** 카드 | 문서 표, **빠진 임베딩 채우기** · **문서 올리기** · **컬렉션 삭제** |

문서 표의 열:

| 열 | 내용 |
|---|---|
| 제목 | 제목, 원본 파일 이름, `옛 판` 꼬리표 |
| 청크 | `임베딩된 청크 / 전체 청크` |
| 크기 | 파일 크기 |
| 상태 | `검색 가능` · `키워드만`(임베딩이 빠짐) · `오류`(마우스를 올리면 이유) |
| 올린 사람 | 이름 · 날짜 |

> **참고** 시스템 관리자·감사자는 모든 워크스페이스의 컬렉션을 봅니다. 그 밖의 사람은 자기가 속한 워크스페이스의 컬렉션만 봅니다. 만들기·올리기·지우기는 시스템 관리자와 그 워크스페이스의 **워크스페이스 관리자 · 구성원**이 합니다(**보기만**은 볼 수만 있음).

문서를 찾고 올리는 기본 사용법은 [문서 RAG — 매뉴얼 찾기·올리기](/user/platform/docs.md)를 보세요.

## 컬렉션 만들기

<figure><img src="img/platform/a-docs-new.png" alt="새 컬렉션 창 — 이름, 워크스페이스(기본 워크스페이스), 임베딩 모델(hnix-embed), 데이터 등급(워크스페이스 기본값), 설명, 취소·만들기 버튼"><figcaption>새 컬렉션 창</figcaption></figure>

1. **컬렉션** 카드의 **새 컬렉션**을 누릅니다.
2. 칸을 채웁니다.

| 칸 | 내용 |
|---|---|
| 이름 | 예: 인사시스템 운영 매뉴얼 |
| 워크스페이스 | 컬렉션이 속할 곳. 이 워크스페이스 구성원이 봅니다 |
| 임베딩 모델 | 게이트웨이의 켜진 **임베딩** 별칭. 비우면 **키워드 검색만** 합니다 |
| 데이터 등급 | **공개 · 사내 · 기밀 · 제한(사내 모델만)**. 비우면 워크스페이스 기본값 |
| 설명 | 선택 |

3. **만들기**를 누릅니다.

> **주의** 임베딩 모델과 데이터 등급은 만든 뒤 화면에서 바꿀 수 없습니다. 바꾸려면 새 컬렉션을 만들어 문서를 다시 올리세요.
> **참고** 데이터 등급은 임베딩 요청에도 붙습니다. `restricted` 컬렉션의 문서는 사내 로컬 모델로만 임베딩되고, 라우트 규칙도 이 등급으로 판단합니다([LLM 게이트웨이 설정](/admin/platform/gateway.md)).
> **참고** 시스템 관리자에게는 모든 워크스페이스가 나옵니다. 그 밖의 사람에게는 내가 구성원(보기만 제외)인 워크스페이스만 나옵니다.

임베딩 별칭이 없으면 먼저 게이트웨이 **모델 별칭** 탭에서 종류 **임베딩** 별칭을 만드세요.

## 문서 올리기

1. 컬렉션을 고르고 **문서 올리기**를 누릅니다. 여러 파일을 한꺼번에 고를 수 있습니다.
2. 파일마다 `청크 N개, 임베딩 M` 이 뜹니다. 경고가 있으면 첫 경고가 노란 알림으로 나옵니다.

받는 형식: 텍스트·Markdown·HTML·CSV·JSON·XML·SQL·소스 코드(java·js·ts·py·properties·log)·Word(docx)·PDF·한글(HWP·HWPX). EUC-KR 파일도 됩니다.

> **주의** 스캔한 이미지 PDF 는 글자가 없어 찾을 수 없습니다. 글자 인식(OCR)을 거쳐 올리세요.

## 새 판 관리 — 같은 이름의 문서

이미 있는 파일 이름으로 다시 올리면 **같은 이름의 문서가 있습니다** 창이 뜹니다.

| 고르기 | 결과 |
|---|---|
| **새 판으로 바꾸기** | 새 문서를 넣고 같은 이름의 옛 문서를 지웁니다. 알림에 `새 판으로 바꿈(옛 판 N개 정리)` |
| **따로 추가** | 옛 문서를 두고 새 문서를 추가합니다. 옛 문서에 `옛 판` 꼬리표가 붙습니다 |
| 창 닫기(Esc) | 올리지 않습니다 |

> **참고** 고친 매뉴얼을 다시 올릴 때는 **새 판으로 바꾸기**를 쓰세요. 옛 판이 남아 있으면 검색·답변 근거에 옛 내용이 섞입니다.

## 옛 판 정리

`옛 판` 꼬리표는 같은 이름의 더 새 문서가 있다는 뜻입니다(목록은 최근 것부터, 이름별 첫 번째가 최신 판).

1. 문서 표에서 `옛 판` 이 붙은 행을 찾습니다.
2. 행 끝 **삭제**를 누르고 확인합니다.

문서를 지우면 그 문서의 검색 색인(키워드·임베딩)도 함께 지워집니다.

## 빠진 임베딩 채우기

임베딩 모델이 잠시 멈췄거나 컬렉션을 만든 뒤 임베딩 모델 서버를 붙였으면, 청크가 `3/8` 처럼 덜 채워지고 상태가 `키워드만` 이 됩니다.

1. 컬렉션을 고릅니다(임베딩 모델이 있는 컬렉션에만 버튼이 보입니다).
2. **빠진 임베딩 채우기**를 누릅니다.
3. `문서 N개, 청크 M개 임베딩` 이 뜨고 표가 새로 고쳐집니다.

## 컬렉션 삭제

1. 컬렉션을 고르고 **컬렉션 삭제**를 누릅니다.
2. `컬렉션과 문서를 모두 삭제할까요?` 에서 확인합니다.

> **주의** 되돌릴 수 없습니다. 이 컬렉션을 근거로 쓰는 [현업 창구](/admin/platform/desk.md)·에이전트가 있으면 먼저 근거를 바꾸세요.

문서 추가·삭제와 컬렉션 만들기·삭제는 [감사 로그](/admin/platform/system.md)에 `docs.` 행위로 남습니다.
