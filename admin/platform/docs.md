# 문서함 관리

> 운영 매뉴얼·절차서를 담는 문서함을 만들고, 데이터 등급·의미 검색 모델을 정하고, 새 버전·이전 버전을 정리합니다. 채팅·현업 창구·에이전트가 이 문서를 근거로 답합니다. **대상**: 시스템 관리자(모든 문서함), 워크스페이스 관리자·구성원(자기 워크스페이스). **메뉴**: AI 통제 › 문서 검색.

## 화면 구성

<figure><img src="img/platform/a-docs.png" alt="문서 검색 화면 — 위 검색 칸, 위 안내 줄, 왼쪽 문서함 카드(운영 매뉴얼 · 기본 워크스페이스 · 문서 5 · 이전 버전 10 · 의미 검색(hnix-embed) · 사내)와 새 문서함 버튼, 오른쪽 문서 표(제목·조각·크기·상태·올린 사람·삭제)와 빠진 의미 색인 채우기·문서 올리기·문서함 삭제 버튼, 최신 문서 앞의 '이전 버전 N개' 꼬리표(▸ 로 펼침)"><figcaption>문서 검색 — 문서함과 문서 목록. 같은 이름의 옛 문서는 최신 문서 아래로 접히고 '이전 버전 N개' 꼬리표가 붙습니다</figcaption></figure>

| 영역 | 하는 일 |
|---|---|
| 검색 칸 | 질문이나 낱말로 찾기, 문서함 고르기(비우면 모든 문서함). 결과에 키워드·의미 순위가 나옵니다 |
| **문서함** 카드 | 문서함 목록 — 워크스페이스 · 문서 수 · 검색 방식(`의미 검색(별칭)` 또는 `키워드만`) · 데이터 등급. **새 문서함** |
| **문서 — <문서함>** 카드 | 문서 표, **빠진 의미 색인 채우기** · **문서 올리기** · **문서함 삭제** |

문서 표의 열:

| 열 | 내용 |
|---|---|
| 제목 | 제목, 원본 파일 이름. 같은 이름의 옛 문서가 있으면 `이전 버전 N개` 꼬리표가 붙고 왼쪽 ▸ 로 펼치면 옛 문서(`이전 버전` 꼬리표)가 보입니다 |
| 조각 | `의미 색인한 조각 / 전체 조각` |
| 크기 | 파일 크기 |
| 상태 | `검색 가능` · `키워드만`(의미 색인이 빠짐) · `오류`(마우스를 올리면 이유) |
| 올린 사람 | 이름 · 날짜 |

> **참고** 시스템 관리자·감사자는 모든 워크스페이스의 문서함을 봅니다. 그 밖의 사람은 자기가 속한 워크스페이스의 문서함만 봅니다. 만들기·올리기·지우기는 시스템 관리자와 그 워크스페이스의 **워크스페이스 관리자 · 구성원**이 합니다(**보기만**은 볼 수만 있음).

문서를 찾고 올리는 기본 사용법은 [문서 검색 — 매뉴얼 찾기·올리기](/user/platform/docs.md)를 보세요.

## 문서함 만들기

<figure><img src="img/platform/a-docs-new.png" alt="새 문서함 창 — 이름, 워크스페이스(기본 워크스페이스), 의미 검색 모델(hnix-embed), 데이터 등급(워크스페이스 기본값), 설명, 취소·만들기 버튼"><figcaption>새 문서함 창</figcaption></figure>

1. **문서함** 카드의 **새 문서함**을 누릅니다.
2. 칸을 채웁니다.

| 칸 | 내용 |
|---|---|
| 이름 | 예: 인사시스템 운영 매뉴얼 |
| 워크스페이스 | 문서함이 속할 곳. 이 워크스페이스 구성원이 봅니다 |
| 의미 검색 모델 | 게이트웨이의 켜진 **의미 검색용** 별칭. 비우면 **키워드 검색만** 합니다 |
| 데이터 등급 | **공개 · 사내 · 기밀 · 제한(사내 모델만)**. 비우면 워크스페이스 기본값 |
| 설명 | 선택 |

3. **만들기**를 누릅니다.

> **주의** 의미 검색 모델과 데이터 등급은 만든 뒤 화면에서 바꿀 수 없습니다. 바꾸려면 새 문서함을 만들어 문서를 다시 올리세요.
> **참고** 데이터 등급은 의미 색인 요청에도 붙습니다. `restricted` 문서함의 문서는 사내 로컬 모델로만 의미 색인되고, 경로 규칙도 이 등급으로 판단합니다([LLM 게이트웨이 설정](/admin/platform/gateway.md)).
> **참고** 시스템 관리자에게는 모든 워크스페이스가 나옵니다. 그 밖의 사람에게는 내가 구성원(보기만 제외)인 워크스페이스만 나옵니다.

의미 검색용 별칭이 없으면 먼저 게이트웨이 **모델 별칭** 탭에서 종류 **의미 검색용** 별칭을 만드세요.

## 문서 올리기

1. 문서함을 고르고 **문서 올리기**를 누릅니다. 여러 파일을 한꺼번에 고를 수 있습니다.
2. 파일마다 `조각 N개, 의미 색인 M개` 이 뜹니다. 경고가 있으면 첫 경고가 노란 알림으로 나옵니다.

받는 형식: 텍스트·Markdown·HTML·CSV·JSON·XML·SQL·소스 코드(java·js·ts·py·properties·log)·Word(docx)·PDF·한글(HWP·HWPX). EUC-KR 파일도 됩니다.

> **주의** 스캔한 이미지 PDF 는 글자가 없어 찾을 수 없습니다. 글자 인식(OCR)을 거쳐 올리세요.

## 새 버전 관리 — 같은 이름의 문서

이미 있는 파일 이름으로 다시 올리면 **같은 이름의 문서가 있습니다** 창이 뜹니다.

| 고르기 | 결과 |
|---|---|
| **새 버전으로 바꾸기** | 새 문서를 넣고 같은 이름의 옛 문서를 지웁니다. 알림에 `새 버전으로 바꿈(이전 버전 N개 정리)` |
| **따로 추가** | 옛 문서를 두고 새 문서를 추가합니다. 옛 문서에 `이전 버전` 꼬리표가 붙습니다 |
| 창 닫기(Esc) | 올리지 않습니다 |

> **참고** 고친 매뉴얼을 다시 올릴 때는 **새 버전으로 바꾸기**를 쓰세요. 이전 버전이 남아 있으면 검색·답변 근거에 옛 내용이 섞입니다.

## 이전 버전 정리

`이전 버전` 꼬리표는 같은 이름의 더 새 문서가 있다는 뜻입니다(목록은 최근 것부터, 이름별 첫 번째가 최신 버전). 최신 문서 앞에 `이전 버전 N개` 가 붙어 있으면 왼쪽 ▸ 로 펼칩니다.

1. 문서 표에서 `이전 버전` 이 붙은 행을 찾습니다.
2. 행 끝 **삭제**를 누르고 확인합니다.

문서를 지우면 그 문서의 검색 색인(키워드·의미 색인)도 함께 지워집니다.

## 빠진 의미 색인 채우기

의미 검색 모델이 잠시 멈췄거나 문서함을 만든 뒤 의미 검색 모델 서버를 붙였으면, 조각이 `3/8` 처럼 덜 채워지고 상태가 `키워드만` 이 됩니다.

1. 문서함을 고릅니다(의미 검색 모델이 있는 문서함에만 버튼이 보입니다).
2. **빠진 의미 색인 채우기**를 누릅니다.
3. `문서 N개, 조각 M개 의미 색인` 이 뜨고 표가 새로 고쳐집니다.

## 문서함 삭제

1. 문서함을 고르고 **문서함 삭제**를 누릅니다.
2. `문서함과 안의 문서를 모두 삭제할까요?` 에서 확인합니다.

> **주의** 되돌릴 수 없습니다. 이 문서함을 근거로 쓰는 [현업 창구](/admin/platform/desk.md)·에이전트가 있으면 먼저 근거를 바꾸세요.

문서 추가·삭제와 문서함 만들기·삭제는 [감사 로그](/admin/platform/system.md)에 `docs.` 행위로 남습니다.
