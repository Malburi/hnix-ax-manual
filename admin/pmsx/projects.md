# 프로젝트와 멤버

> 로그인 계정을 등록하고, SI·SM 프로젝트를 만들고, 프로젝트마다 참여 인원과 프로젝트 역할·투입일·철수일을 정합니다. **대상**: 시스템 관리자(사용자·프로젝트), PMO(프로젝트 등록), PM(내 프로젝트 수정·인원). **메뉴**: 관리 › 사용자·역할 · 프로젝트 관리.

## 화면 구성

<figure><img src="img/pmsx/a-projects.png" alt="프로젝트 관리 — 왼쪽 프로젝트 목록(프로젝트 등록 버튼), 오른쪽 참여 인원 표(이름·아이디·소속·프로젝트 역할·투입 기간)와 인원 추가·프로젝트 수정·SM 인수인계 버튼"><figcaption>관리 › 프로젝트 관리 — SI 프로젝트를 고른 상태</figcaption></figure>

| 영역 | 하는 일 |
|---|---|
| **프로젝트** 목록 | 프로젝트 이름과 `SI 구축 · 고객사` / `SM 운영 · 고객사`. **프로젝트 등록**(시스템 관리자·PMO) |
| **참여 인원** 머리 | 고른 프로젝트 이름, 기간, **프로젝트 수정**, **SM 인수인계**(SI 프로젝트, 시스템 관리자·PM), **인원 추가** |
| 인원 표 | **이름 · 아이디 · 소속 · 프로젝트 역할 · 투입 기간** |
| 행 끝 아이콘 | ☰ **투입 체크리스트** · 🛡 **열람 범위**(협력사만) · ✎ 수정 · 👤✕ **참여 제외** |

## 사용자 등록

<figure><img src="img/pmsx/a-projects-users.png" alt="사용자·역할 — 아이디·이름·이메일·소속·인증·시스템 역할·상태·최근 로그인 목록"><figcaption>관리 › 사용자·역할 (시스템 관리자만)</figcaption></figure>

프로젝트에 사람을 넣으려면 먼저 PMS-X 사용자로 등록되어 있어야 합니다.

1. **관리 › 사용자·역할**에서 **사용자 등록**을 누릅니다.
2. 입력합니다.

| 칸 | 넣는 값 |
|---|---|
| 아이디 | 영문 소문자로 시작하는 3~30자(소문자·숫자·`._-`) |
| 이름 · 이메일 | 이메일은 알림 메일과 메일 접수 요청자 확인에 씁니다 |
| 소속 | 자사 · 협력사 · 고객 (공통코드 ORG_TYPE) |
| 인증 | **자체 (LOCAL)** 또는 **LDAP / AD** |
| 시스템 역할 | **시스템 관리자 (SYS_ADMIN)**, **PMO (PMO)** — 일반 사용자는 비웁니다 |
| 초기 비밀번호 | 자체 계정만. 9자 이상, 영문·숫자·특수문자 중 3종류 |

3. **저장**을 누르고, 아이디와 초기 비밀번호를 본인에게 따로 알려 줍니다.

> **참고** LDAP 사용자는 사내 디렉터리 비밀번호로 로그인하며, 아이디가 디렉터리 계정과 같아야 합니다. **LDAP 계정도 여기 미리 등록한 사용자만 로그인됩니다.** 서버의 LDAP 연결은 [계정 · 권한 · 로그인 연동](/admin/accounts.md)을 보세요.

**계정 관리**

| 하고 싶은 일 | 방법 |
|---|---|
| 정보·시스템 역할 수정 | 행의 ✎ → **사용자 수정** |
| 비밀번호를 잊었을 때 | **비밀번호 초기화** → **새 비밀번호** 입력 |
| 5회 실패로 잠긴 계정 | **잠금 해제** (상태 **잠김** → **사용**) |
| 퇴사·사용 중지 | **계정 잠금**. 잠긴 계정은 로그인할 수 없습니다 |
| 목록 받기 | **엑셀 내보내기** |

검색은 **아이디·이름·이메일 검색** 후 **조회**.

## 프로젝트 만들기

1. **관리 › 프로젝트 관리**에서 **프로젝트 등록**을 누릅니다.

<figure><img src="img/pmsx/a-projects-create.png" alt="프로젝트 등록 창 — 유형·프로젝트명·고객사·계약 MM·시작일·종료일·PM·방법론 템플릿"><figcaption>프로젝트 등록</figcaption></figure>

2. 입력합니다.

| 칸 | 설명 |
|---|---|
| **유형** | SI(구축) 또는 SM(운영). 메뉴 구성이 달라집니다 |
| **프로젝트명** · **고객사** | 필수 |
| **계약 MM** | 홈의 MM 비교에 씀 |
| **시작일** · **종료일** | 필수. 인원 추가 때 투입일·철수일 기본값 |
| **PM** | 필수. 저장하면 이 사람이 프로젝트 관리자로 참여 인원에 자동 추가됩니다 |
| **방법론 템플릿** | 고르면 WBS를 템플릿으로 바로 만들 수 있습니다(SI) |

3. **저장**을 누릅니다. 새 프로젝트는 참여 인원(처음에는 PM)의 상단 **프로젝트** 선택 목록에 나타납니다.

**프로젝트 수정**: 프로젝트를 고르고 기간 옆 **프로젝트 수정**(시스템 관리자·PM).

> **참고** SI 프로젝트를 운영으로 넘길 때는 SM 프로젝트를 새로 만들지 말고 **SM 인수인계** 마법사를 쓰면 화면 분석 자산과 인원이 함께 넘어갑니다 — [인수인계와 구현 명세](/user/pmsx/handover.md#인수인계-마법사).

## 멤버 추가 — 역할 · 투입일 · 철수일

<figure><img src="img/pmsx/a-projects-member.png" alt="인원 추가 창 — 사용자 검색, 프로젝트 역할, 투입일, 철수일"><figcaption>인원 추가 — 투입일·철수일은 프로젝트 기간으로 미리 채워집니다</figcaption></figure>

1. 왼쪽에서 프로젝트를 고르고 **인원 추가**를 누릅니다.
2. **사용자**에 이름이나 아이디를 넣어 고릅니다.
3. **프로젝트 역할**을 고릅니다.

| 프로젝트 역할 | 주로 하는 일 |
|---|---|
| 프로젝트 관리자 (PM) | 프로젝트 전체. WBS·베이스라인·인력 편성·승인 |
| 파트 리더 (PL) | WBS 편집, 작업 배분, 분석 확정, 작업일지 승인 |
| 분석 담당 (ANALYST) | As-Is 화면 분석·보정 |
| 개발자 (DEV) · 품질 담당 (QA) | 개발·테스트·결함 |
| 운영 담당 (OPERATOR) | SM 서비스 요청·장애·변경 처리 |
| 협력사 (PARTNER) | 허용된 범위의 As-Is 분석, 작업일지 |
| 고객 담당자 (CUSTOMER) | 고객 요청 창구, 산출물·변경 승인 |

4. **투입일**과 **철수일**을 확인합니다. 철수일은 투입일 이후여야 합니다.
5. **저장**을 누릅니다.

> **참고** 투입일·철수일은 [인력 편성 / 투입 계획](/user/pmsx/resource.md#인력-편성-투입-계획)에서 월 MM을 영업일 비율로 채우는 기준이 됩니다. 같은 인원 추가는 인력 편성 화면에서도 할 수 있습니다.

| 하고 싶은 일 | 방법 |
|---|---|
| 역할·기간 바꾸기 | 행의 ✎ → **참여 정보 수정** |
| 프로젝트에서 빼기 | 👤✕ **참여 제외** → 확인 |
| 이미 참여 중인 사람 | "이미 참여 중인 사용자입니다."가 뜹니다 |

### 투입 체크리스트

1. 행의 ☰(**투입 체크리스트**)를 누릅니다.
2. 보안 서약서·PC 반입 같은 투입 항목을 체크합니다. 위에 `n / m 완료`가 보입니다.
3. 항목이 더 필요하면 **항목 추가**에 쓰고 **추가**, 그리고 **저장**.

> **참고** 기본 항목은 공통코드 **투입 체크리스트(ONBOARD_ITEM)**에서 옵니다.

### 협력사 열람 범위

협력사 인력은 여기서 고른 시스템·메뉴의 As-Is 분석만 볼 수 있습니다.

1. 협력사 인원 행의 🛡(**열람 범위**)를 누릅니다.
2. **허용 시스템**을 고릅니다.
3. **허용 메뉴**를 고릅니다. 비워 두면 허용 시스템의 모든 메뉴를 봅니다.
4. **저장**을 누릅니다.

## 자주 묻는 질문

**Q. 인원 추가에서 사용자가 검색되지 않아요.** 아직 사용자로 등록되지 않았습니다. 시스템 관리자가 **사용자·역할**에서 먼저 등록하세요. 사용자 조회 권한이 없는 화면에서는 **사용자 ID**를 직접 넣는 칸이 나옵니다.

**Q. PM으로 참여시켰는데 관리 메뉴가 안 보여요.** 역할은 로그인할 때 정해집니다. 로그아웃 후 다시 로그인하고, 상단에서 그 프로젝트를 고르세요. 관리 메뉴 중 **사용자·역할**은 시스템 관리자 전용입니다.
