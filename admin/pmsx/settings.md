# 기준 정보 — 코드 · 용어 · 방법론 · 템플릿 · 처리 기한

> 화면 콤보·상태값과 공휴일을 정하는 공통코드, 프로젝트 표준 용어, WBS를 만드는 방법론 템플릿, 고객사 엑셀 양식, SM 처리 기한 정책을 관리합니다. **대상**: 시스템 관리자(편집), PM(일부 편집·조회), 운영 담당(처리 기한 정책 조회). **메뉴**: 관리 › 공통코드·용어 · 방법론 템플릿 · 엑셀 템플릿 매핑 · 처리 기한 정책·업무 캘린더.

| 메뉴 | 시스템 관리자 | PM | PMO·운영 담당 |
|---|---|---|---|
| 공통코드·용어 | 편집 | 조회("조회만 가능합니다. 변경은 시스템 관리자에게 요청하세요.") | — |
| 방법론 템플릿 | 편집 | 조회 | — |
| 엑셀 템플릿 매핑 | 편집 | 편집 | — |
| 처리 기한 정책·업무 캘린더 (SM 프로젝트) | 편집 | 편집 | 조회 |

## 공통코드

<figure><img src="img/pmsx/a-settings-codes.png" alt="공통코드·용어 — 왼쪽 코드 그룹 목록(분석 상태·감리 점검 항목·DB 종류·화면 요소 유형·기술 등급·공휴일·투입 체크리스트·소속 구분·프로젝트 유형·화면 기술), 오른쪽 코드 표"><figcaption>관리 › 공통코드·용어 › 공통코드</figcaption></figure>

| 영역 | 하는 일 |
|---|---|
| **코드 그룹** | 그룹 이름·그룹 코드. **시스템** 표시가 붙은 그룹은 PMS-X가 쓰는 그룹이라 삭제할 수 없습니다. **+**로 그룹 추가 |
| 그룹 머리 | 그룹 이름·코드·설명, ✎ **그룹 수정**, 🗑 **그룹 삭제** |
| 코드 표 | **코드 · 코드명 · 정렬 · 사용 · 속성1 · 속성2**, 행 끝 ✕(행 삭제) |
| 버튼 | **코드 추가** · **엑셀 내보내기** · **엑셀 가져오기** · **일괄 저장** |

PMS-X가 쓰는 시스템 그룹:

| 그룹 | 쓰는 곳 |
|---|---|
| 분석 상태 (ANALYSIS_STATUS) | As-Is 화면 분석 상태 |
| 감리 점검 항목 (AUDIT_ITEM) | 산출물·추적성 › 감리 체크리스트 |
| DB 종류 (DB_TYPE) · 화면 기술 (UI_TECH) | 시스템 등록 |
| 화면 요소 유형 (ELEMENT_TYPE) | 뷰어의 요소 타입 |
| 기술 등급 (GRADE) | 인력 풀·인력 편성의 등급 |
| 공휴일 (HOLIDAY) | 영업일 계산(WBS 기간·투입 MM·처리 기한) |
| 투입 체크리스트 (ONBOARD_ITEM) | 프로젝트 인원의 투입 체크리스트 기본 항목 |
| 소속 구분 (ORG_TYPE) | 사용자 소속(자사·협력사·고객) |
| 프로젝트 유형 (PROJECT_TYPE) | SI · SM |

**코드 고치기**

1. 왼쪽에서 그룹을 고릅니다.
2. 표에서 바로 고치거나 **코드 추가**로 행을 만듭니다. 코드는 영문 대문자·숫자·`_` 1~30자, 코드명은 필수입니다. **사용**을 끄면 콤보에서 빠집니다.
3. **일괄 저장**을 누릅니다. 저장하지 않고 다른 그룹으로 가려 하면 "저장하지 않은 코드 변경이 있습니다."가 뜹니다(**변경 버리기**).

엑셀로 한꺼번에 넣으려면 **엑셀 내보내기**로 양식을 받아 고친 뒤 **엑셀 가져오기** → **검증** → **n행 반영**.

## 공휴일

공휴일 그룹(HOLIDAY)의 코드는 날짜(`YYYY-MM-DD`), 코드명은 공휴일 이름입니다. **사용**이 켜진 날짜는 영업일에서 빠집니다 — WBS 기간·종료일, 투입 계획 MM, 처리 기한 계산 모두에 적용됩니다.

<figure><img src="img/pmsx/a-settings-holiday.png" alt="공휴일(HOLIDAY) 그룹 — 2026-01-01 신정 등 날짜 코드와 공휴일 이름, 사용 여부"><figcaption>공휴일 그룹 — 코드 칸에 날짜(YYYY-MM-DD)를 넣습니다</figcaption></figure>

1. **관리 › 공통코드·용어**에서 **공휴일** 그룹을 고릅니다. 처리 기한 정책 화면의 **공휴일 편집** 버튼으로도 옵니다.
2. 해마다 다음 해 공휴일(대체공휴일·선거일 포함)을 넣습니다.

> **참고** 공휴일 그룹의 코드는 **실제 날짜**만 받습니다(`2027-02-30` 같은 없는 날짜는 저장되지 않음). 많이 넣을 때는 **엑셀 내보내기** → 엑셀에서 행 추가 → **엑셀 가져오기**가 편합니다. 엑셀이 코드 칸을 날짜로 바꿔 놓아도 `2027-01-01` 로 읽습니다. (1.3.6 에서는 화면이 날짜 코드를 형식 오류로 막아 엑셀로만 넣을 수 있었습니다 — 1.3.7 에서 고쳤습니다.)

## 용어 사전

<figure><img src="img/pmsx/a-settings-terms.png" alt="용어 사전 탭 — 용어·약어·정의 검색, 엑셀 내보내기·엑셀 가져오기·용어 추가 버튼, 용어·영문 약어·도메인·정의 목록"><figcaption>관리 › 공통코드·용어 › 용어 사전</figcaption></figure>

1. **용어 사전** 탭에서 **용어 추가**를 누릅니다.
2. **용어 · 영문 약어 · 도메인 · 정의**, **동의어**(쉼표로 구분)를 넣고 저장합니다. 동의어는 본문 용어 찾기와 연결 추천에 함께 쓰입니다(예: 사원 — 직원, 임직원, 사번).
3. 많으면 **엑셀 가져오기**로 넣습니다.

**화면·테이블과 연결하기**

<figure><img src="img/pmsx/a-settings-term-relations.png" alt="용어 '사원'의 연결 창 — 동의어, 연결된 화면, 추천 테이블·컬럼과 연결 버튼"><figcaption>용어 연결 — 추천은 이름·코멘트 문자열 일치</figcaption></figure>

1. 용어 행 끝의 🔗(**화면·테이블 연결**) 아이콘을 누릅니다.
2. **연결됨** 목록과 **추천 (이름·코멘트 일치)** 목록이 보입니다.
3. 맞는 것만 **연결**하고, 틀린 것은 **연결 해제**합니다. "추천은 문자열 일치입니다 — 확인한 것만 연결하세요."

> **참고** 연결은 현재 프로젝트의 As-Is 시스템 기준입니다. 테이블 정의서 컬럼 탭의 **표준용어**에 나타납니다. 업무 메모를 쓰는 역할(PM·PL·분석 담당 등)도 화면에서 연결할 수 있습니다.

## 방법론 템플릿

<figure><img src="img/pmsx/a-settings-methodology.png" alt="방법론 템플릿 — SI 표준(분석·설계·구현·시험·이행) 5개 단계, 단계별 작업·가중치·기간(일)·필수 산출물 표"><figcaption>관리 › 방법론 템플릿 — 단계·작업·필수 산출물</figcaption></figure>

1. 왼쪽에서 템플릿을 고르거나 **템플릿 추가**를 누릅니다.
2. **템플릿 이름**을 넣습니다. 위에 `작업 기간 합 n일`이 보입니다.
3. 단계마다 단계명과 작업 행(**작업 · 가중치 · 기간(일) · 필수 산출물**)을 넣습니다. 필수 산출물은 입력 후 `Enter`로 여러 개.
4. **작업 추가**, **단계 추가**로 늘립니다.
5. **저장**을 누릅니다. 템플릿을 지우려면 **삭제**.

> **참고** 프로젝트 등록 때 고른 방법론으로 WBS를 만듭니다(**WBS / 간트 › 생성·가져오기 › 방법론 템플릿으로 생성**). 이미 만든 WBS는 템플릿을 고쳐도 바뀌지 않습니다.

## 엑셀 템플릿 매핑

<figure><img src="img/pmsx/a-settings-excel.png" alt="템플릿 등록 창 — 템플릿 이름, 데이터셋, 양식 파일(.xlsx), 시트 이름, 데이터 시작 행, 필드 → 열 매핑 표, 공통 값 → 셀"><figcaption>템플릿 등록 — 고객사 양식에 데이터를 채우는 위치</figcaption></figure>

고객사 엑셀 양식에 필드와 셀 위치를 연결해 두면, 각 화면의 **엑셀 내보내기 › 고객사 템플릿**과 산출물 출력의 **고객사 템플릿 (엑셀)**에서 그 양식으로 채워 내려받습니다.

1. **템플릿 등록**을 누릅니다.
2. **템플릿 이름**과 **데이터셋**(어느 화면의 목록인지)을 고릅니다.
3. **양식 파일 (.xlsx)**을 올리고 **시트 이름**, **데이터 시작 행**(머리글 아래 첫 데이터 행 번호)을 넣습니다.
4. **필드 → 열 매핑**: 필드마다 열 문자(A~)를 적습니다. 비워 둔 필드는 내보내지 않습니다. **A열부터 자동 채우기**로 한 번에 채울 수 있습니다. 최소 한 필드는 매핑해야 합니다.
5. **공통 값 → 셀**: 양식 위쪽 칸에 넣을 **프로젝트명 · 시스템명 · 출력 일시 · 출력자**의 셀 주소(예: `C3`). 필요 없으면 비웁니다.
6. **저장**을 누릅니다.

목록에서 **양식 내려받기**, 수정(✎ — **양식 파일 교체 (선택)**), 삭제를 합니다.

## 처리 기한 정책·업무 캘린더

<figure><img src="img/pmsx/a-settings-sla.png" alt="처리 기한 정책·업무 캘린더 — 순서·정책명·적용 대상·응답 목표·해결 목표·업무시간 표(P1 긴급 24x7 30분/4시간 등)와 공휴일 목록"><figcaption>SM 프로젝트를 고른 상태에서만 보이는 메뉴</figcaption></figure>

요청이 생기면 **순서가 빠른 정책부터** 맞춰 보고 처음 맞는 정책을 적용합니다.

1. 상단에서 SM 프로젝트를 고르고 **관리 › 처리 기한 정책·업무 캘린더**를 엽니다.
2. **정책 추가**(또는 행의 수정)를 누릅니다.
3. 입력합니다.

| 칸 | 설명 |
|---|---|
| **정책명** · **순서** | 이름과 맞춰 보는 순서 |
| **요청 유형** · **우선순위** | 적용 대상. 비우면 전체("모든 요청") |
| **응답 목표** · **해결 목표** | 시간·분. 0보다 커야 하고 해결 목표가 응답 목표보다 짧을 수 없습니다 |
| **24시간·365일 (업무시간 무시)** | 긴급 건처럼 늘 시간이 흐르는 정책 |
| **업무 시작** · **업무 종료** · **업무 요일** | 업무시간 기준 계산. 종료가 시작보다 늦어야 합니다 |

4. **저장**을 누릅니다.

> **참고** 목표 시간은 업무시간 기준으로 세고, 보류(고객 대기) 시간은 빼고 셉니다. 공휴일은 아래 **업무 캘린더 (공휴일)**에 보이며 계산에서 빠집니다(편집은 **공휴일 편집** → 공통코드 HOLIDAY).

> **주의** 정책을 바꾸거나 지워도 이미 접수된 요청의 기한은 바뀌지 않습니다.
