# 문제 해결

> 자주 생기는 문제를 증상으로 찾아 확인할 곳과 해결 방법을 봅니다. **대상**: 시스템 관리자(사용자에게서 문의를 받은 사람).

문의를 받으면 먼저 **언제·누가·어느 화면에서·무엇을 눌렀더니·어떤 글이 떴는지**를 받아 두세요. 화면 캡처가 있으면 가장 빠릅니다.

## 접속·로그인

| 증상 | 확인 | 해결 |
|---|---|---|
| 다른 PC 에서 화면이 안 열림 | 서버에서는 열리는지(`server.ps1 status`) → Windows 방화벽 규칙 `HNIX AX *` → 사내 방화벽·라우팅 → 사용자 PC 프록시 예외 | 접속 대역(`allowedSubnets`)에 사용자 대역이 있는지, 프록시 예외에 서버 주소 추가 |
| 로그인하면 "계정이 잠겼습니다" | 비밀번호 5회 실패 | 플랫폼은 15분 뒤 저절로 풀림. PMS-X 는 관리 › 사용자에서 **잠금 해제** |
| 비밀번호를 잊음 | 로컬 계정인지 사내 계정인지 | 플랫폼 **사용자 · 워크스페이스 › 사용자 › 수정**에서 새 비밀번호, PMS-X **비밀번호 초기화**. 사내 AD·SSO 계정은 회사 계정 담당에게 |
| 사내 계정으로 로그인 안 됨 | `hnix-ax.local.yaml` 의 `auth.ldap` / `auth.oidc`, 환경 변수 비밀번호, 플랫폼 로그 | → [계정 · 권한 · 로그인 연동](/admin/accounts.md). 디렉터리가 응답 없으면 잠시 503 |
| PMS-X 에서 "라이선스가 유효하지 않습니다" | PMS-X 관리 › 시스템의 라이선스 | 새 라이선스 적용 → [시스템 — AI · 연동 · 알림 · 감사](/admin/pmsx/system.md) |
| PMS-X 에 로그인했는데 프로젝트가 안 보임 | 그 사람이 프로젝트 멤버인지 | 프로젝트 멤버로 추가 → [프로젝트와 멤버](/admin/pmsx/projects.md) |
| 레이크 분석가가 데이터가 적게 보인다고 함 | 분석가의 **소속**과 행 제한 규칙 | 정상일 수 있음(소속 행만 보임) → [거버넌스](/admin/datalake/governance.md) |

## 설치·서비스

| 증상 | 확인 | 해결 |
|---|---|---|
| 설치 중 "모델 … 을 풀지 못했습니다" | `.zip.001`·`.002` 조각이 모두 같은 폴더에 있는지, `SHA256SUMS.txt` 와 대조 | 빠진 조각을 다시 받음 |
| "모델 … 이 없습니다 — 인터넷으로 받습니다" 뒤 멈춤 | `model.chatModel` 에 적은 모델 파일이 설치 폴더 옆(또는 `packages\`)에 있는지 | 모델 파일을 넣고 `install` |
| 포트가 이미 쓰이는 중 | 다른 프로그램이 8700·8080·8790·5432 를 쓰는지 | 설치 프로그램을 다시 실행해 포트 변경. DB 포트는 `database.port` |
| 제품이 DB 에 못 붙음 | `status` 의 PostgreSQL 줄, 서비스 `hnix-ax-postgresql`, `data\pgsql\log` | 서비스 시작. 디스크 여유 확인 |
| PMS-X 가 3분 넘게 안 뜸 | `apps\pmsx\pmsx-*\logs`, 메모리 | 처음엔 시연 데이터를 채우느라 오래 걸림. 메모리가 모자라면 `pmsx.heap` 조정 |
| 설치 파일이 실행되자마자 지워짐 | 백신·EDR 기록 | 게시자 기준 예외 → [서버 설치 7번](/admin/install-server.md) |
| 진행 창에서 스크립트 실행이 막힘 | 그룹 정책의 PowerShell 실행 정책 | 서명 인증서를 신뢰 목록에 넣거나 보안 담당과 실행 정책 조정 |
| 다시 설치했더니 LDAP 설정이 사라짐 | 설정을 `hnix-ax.yaml` 에 넣었는지 | `hnix-ax.local.yaml` 로 옮김(설치가 지우지 않음) |

## AI·모델

| 증상 | 확인 | 해결 |
|---|---|---|
| AI 답이 엉뚱하거나 짧음 | 게이트웨이 **요청 로그**에서 어느 모델이 답했는지 | CPU 작은 모델의 한계 — `qwen3.5:4b`, GPU 서버(`model.gpu`), 조직 API 키 → [LLM 게이트웨이 설정](/admin/platform/gateway.md) |
| 답이 너무 느림 | 요청 로그의 지연, **AI 사용 현황 › 품질 · 지연** | 동시 사용자가 많으면 GPU 서버. CPU 서버에서 IDE 첫 질문은 1~3분 걸릴 수 있음 |
| "예산을 넘었습니다"(429) | **LLM 게이트웨이 › 경로 규칙 · 예산** | 예산 조정 또는 다음 기간까지 대기 |
| "정책에 막혔습니다" | 게이트웨이 경로 규칙·개인정보 규칙, 요청 로그의 차단 사유 | 규칙이 의도대로인지 확인. 기밀 등급 데이터는 사내 모델로만 감 |
| IDE 채팅에 "모델 응답 불완전" | 게이트웨이 **모델 별칭** `hnix-code` 의 대상이 `…-ctx32k` 인지, `qwen3.5:4b` 모델 파일 | 4b 모델 파일을 넣고 `install`. `model.contextLength` 를 32768 아래로 줄이지 않음 |
| 문서 검색이 의미로 안 찾고 낱말로만 찾음 | 문서함 상태 '키워드만', 의미 검색용 별칭 | **문서 검색 › 빠진 의미 색인 채우기** → [문서함 관리](/admin/platform/docs.md) |
| 창구·채팅 답에 옛 내용이 나옴 | 같은 이름 문서에 '이전 버전' 표시가 있는지 | 이전 버전을 지우거나 새 버전으로 바꾸어 다시 올림 |

## 도구·승인·연동

| 증상 | 확인 | 해결 |
|---|---|---|
| 에이전트가 "승인 대기"에서 멈춤 | **승인함** | 다른 관리자가 승인(본인 요청은 본인이 못 함). 승인되면 15초 안에 이어서 실행 |
| 승인했는데 실행이 안 됨 | 같은 인자로 다시 불렀는지, 하루 기한 | 승인은 **같은 인자로 한 번** 쓸 수 있습니다 |
| MCP 서버 연결 문제 알림 | **MCP 허브 › 서버**의 마지막 오류 | 대상 서버 상태·서비스 계정 비밀번호 확인 후 **동기화** |
| 외부 도구가 "스키마 변경"으로 막힘 | **MCP 허브 › 도구 승인** | 바뀐 설명·인자를 확인하고 다시 승인 |
| 고객 ITSM 티켓이 안 들어옴 | **고객 ITSM 연동**의 동기화 기록, 웹훅 수신 | 연결 시험, 고객 쪽 계정 권한 → [연동](/admin/platform/integrations.md) |
| 자동 실행(트리거)이 안 깨어남 | 에이전트 자동 실행의 **기록**, 웹훅 주소·토큰 | **지금 실행**으로 시험, **토큰 다시 만들기** 후 보낸 쪽 설정 갱신 |
| 현업 창구 마이크가 "HTTP 주소에서는 막습니다" | 접속 주소가 https 인지 | HTTPS 를 붙이거나 브라우저 정책에 주소 추가 → [현업 창구 만들기](/admin/platform/desk.md) |

## AX-NAVI IDE

| 증상 | 확인 | 해결 |
|---|---|---|
| 승인 화면에 "사용 허가가 없습니다" | **AX-NAVI 관리 › 사용 허가** | 허가 주기 |
| "기기는 2대까지입니다" | 그 사람의 기기 목록 | 안 쓰는 기기 끊기(본인은 **내 AX-NAVI 기기**) |
| 승인 코드 만료 | 10분 안에 승인했는지 | IDE 에서 다시 로그인 |
| IDE 채팅에 허브 도구가 안 보임 | IDE 상태 표시줄 **AX-NAVI** | **연결 다시 받기** |
| IDE 가 실행되자마자 지워짐 | 백신·EDR | 게시자 기준 예외 → [개인 PC 배포 4번](/admin/install-pc.md) |

## 그래도 안 되면

1. `server.ps1 status` 결과, 해당 제품 로그(최근 100줄), 문제가 난 시각을 모읍니다.
2. 플랫폼 **현장 연결 점검** 결과를 캡처합니다.
3. 설정 파일·로그를 보낼 때는 비밀번호·키 값을 지우고 보냅니다.
